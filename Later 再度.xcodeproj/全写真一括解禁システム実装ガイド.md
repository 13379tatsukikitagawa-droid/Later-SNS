# 📸 全写真一括解禁システム - 完全実装ガイド

## 🎯 目的

1日の撮影セッション（1〜5枚）で撮った**すべての写真**を、共通の解禁時刻で**同時に解禁**するシステムの完全実装。

---

## ✅ 実装された機能

### 1. 一括解禁管理 (Grouped Unlock)

#### グループ化
- 1日（セッション）を1つの単位として管理
- 目標枚数（1〜5枚）を達成してロックがかかるまでを1セッション
- **個別の写真ごとに解禁時間を計算せず、セッション全体で1つの解禁時刻を共有**

#### 同一解禁時刻
```swift
// ❌ 個別の解禁時刻（使用しない）
photo1.unlockDate = now + 24時間
photo2.unlockDate = now + 25時間
photo3.unlockDate = now + 26時間

// ✅ 一括解禁時刻（正しい実装）
sessionManager.targetUnlockTime = now + ランダム(12〜48時間)
// → すべての写真がこの1つの時刻を参照
```

---

### 2. 解禁時刻のランダム設定 (Secret Random Span)

#### スパンの決定
```swift
// ロックがかかった瞬間から
let minSeconds: TimeInterval = 12 * 3600  // 12時間 = 43,200秒
let maxSeconds: TimeInterval = 48 * 3600  // 48時間 = 172,800秒

// ランダムな遅延時間を計算
let randomDelay = TimeInterval.random(in: minSeconds...maxSeconds)

// 仮の解禁時刻を設定
var proposedUnlockTime = now.addingTimeInterval(randomDelay)
```

#### 計算ロジック
- **最短**: 12時間後
- **最長**: 48時間後
- **ランダム幅**: 36時間（12〜48時間の範囲）

---

### 3. 解禁タイミングの制約 (Active Window)

#### 制限時間帯チェック
夜22:00〜朝9:00の間に解禁時刻が来ないように調整：

```swift
private func adjustUnlockTimeToActiveWindow(_ date: Date) -> Date {
    let calendar = Calendar.current
    let hour = calendar.component(.hour, from: date)
    
    // 夜22:00〜朝9:00の間かチェック
    let isInRestrictedWindow = hour >= 22 || hour < 9
    
    if isInRestrictedWindow {
        // 翌朝9:00を基準にする
        var components = calendar.dateComponents([.year, .month, .day], from: date)
        
        // 深夜の場合（0:00〜8:59）は同じ日の9:00
        // 夜の場合（22:00〜23:59）は翌日の9:00
        if hour >= 22 {
            // 翌日に進める
            if let nextDay = calendar.date(byAdding: .day, value: 1, to: date) {
                components = calendar.dateComponents([.year, .month, .day], from: nextDay)
            }
        }
        
        // 朝9:00に設定
        components.hour = 9
        components.minute = 0
        components.second = 0
        
        guard let morningNine = calendar.date(from: components) else {
            return date
        }
        
        // 9:00からランダムな時間を追加（0〜3時間）
        let randomSeconds = Int.random(in: 0...(3 * 3600))
        return morningNine.addingTimeInterval(TimeInterval(randomSeconds))
    }
    
    return date
}
```

#### 調整例
```
元の解禁時刻: 2026-05-23 23:30  → 調整後: 2026-05-24 09:00〜12:00のランダムな時刻
元の解禁時刻: 2026-05-23 02:15  → 調整後: 2026-05-23 09:00〜12:00のランダムな時刻
元の解禁時刻: 2026-05-23 15:00  → 調整なし（そのまま）
```

### 5. 技術的実装

#### フラグ管理

**DailyPhotoSessionManager** がシングルトンで管理：

```swift
@Observable
class DailyPhotoSessionManager {
    static let shared = DailyPhotoSessionManager()
    
    // MARK: - ストレージキー
    private let sessionDateKey = "photoSessionDate"
    private let sessionLockTimeKey = "photoSessionLockTime"
    private let sessionUnlockTimeKey = "photoSessionUnlockTime"  // ← 一括解禁時刻
    private let photoCountKey = "photoSessionPhotoCount"
    private let isLockedKey = "photoSessionIsLocked"
    
    // MARK: - プロパティ
    var sessionDate: String?           // セッション日付
    var sessionLockTime: Date?         // ロック時刻
    var targetUnlockTime: Date?        // 一括解禁時刻（すべての写真がこれを参照）
    var photoCount: Int = 0            // 撮影枚数
    var isSessionLocked: Bool = false  // ロック状態
}
```

#### UserDefaultsへの保存
```swift
private func saveSession() {
    let defaults = UserDefaults.standard
    
    defaults.set(sessionDate, forKey: sessionDateKey)
    defaults.set(photoCount, forKey: photoCountKey)
    defaults.set(isSessionLocked, forKey: isLockedKey)
    
    // ロック時刻を保存（TimeInterval形式）
    if let lockTime = sessionLockTime {
        defaults.set(lockTime.timeIntervalSince1970, forKey: sessionLockTimeKey)
    }
    
    // 一括解禁時刻を保存（TimeInterval形式）
    if let unlockTime = targetUnlockTime {
        defaults.set(unlockTime.timeIntervalSince1970, forKey: sessionUnlockTimeKey)
    }
}
```

### 撮影から解禁までの完全フロー

```

   ↓

   → photoCount = 2
   ↓
9. 目標未達成のため、ロックされない
   ↓
10. 写真を撮影（3枚目）
    ↓

    → photoCount = 3
    ↓

    ↓

    - 現在時刻: 2026-05-22 14:30
    - ランダム遅延: 28時間 (12〜48時間の範囲)
    - 仮の解禁時刻: 2026-05-23 18:30

    ↓

    ↓
15. isSessionLocked = true
    ↓
16. UserDefaultsに保存
    ↓
17. DailyGoalLockOverlay を表示（演出）
    ↓
18. ユーザーがギャラリーを開く
    ↓
19. SecretPhotoGalleryView
    ↓
20. ForEach(todayPhotos) { photo in
        PhotoGridItem(
            photo: photo,
            isUnlocked: sessionManager.arePhotosUnlocked()
        )
    }
    ↓
21. sessionManager.arePhotosUnlocked()
    → Date() >= targetUnlockTime?
    → 2026-05-22 15:00 >= 2026-05-23 18:30?

    ↓

    ↓
    ⏰ 時間が経過...
    ↓
23. 解禁時刻到達: 2026-05-23 18:30
    ↓
24. sessionManager.arePhotosUnlocked()
    → Date() >= targetUnlockTime?
    → 2026-05-23 18:30 >= 2026-05-23 18:30?
    → true
    ↓
```
