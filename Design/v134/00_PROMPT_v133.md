# Lattag v133 へのデザイン移行（Claude Code 向け）

このフォルダ（`design/v133/`）にある **v133 のデザイン** に、いまのアプリの見た目と触感を合わせてください。
方向は「**毎日見る画面は BeReal の骨組み、大事な3つの瞬間（9:00・撮る・ひらく）は Opal の演出**」です。

> **最初は Phase 0（調査と報告）だけ** を行い、コードは変えずに報告して止まってください。
> 私が報告を読んで「Phase 1 へ進んで」と言ってから実装を始めます。

## 1. 守ること（いちばん大事）

1. **変えるのは見た目・文言・動き・触感だけ。** CloudKit・Firebase（uid）・Cloudflare（友だち・申請・チャット・写真）・撮影・現像・解禁・24:00 で消える処理・7日で消える処理などの **中の仕組みは変えない**。見た目のために中の仕組みを変える必要が出たら、**実装せずに報告して止まる**。
2. **進め方は Phase ごと。** 各 Phase の終わりにビルドが通ることを確認し、「何を変えたか」「実機で何を確かめてほしいか」を短く報告する。次の Phase は私の OK を待つ。
3. **使われていない古い画面やコードを見つけても、勝手に消さない。** 一覧にして報告する。
4. **iOS 26 の新しい API には `if #available(iOS 26.0, *)` を付け、それより前の iOS ではふつうの見た目に戻す。**（いまの Deployment Target を Phase 0 で確認）
5. **ライムは押せる物だけ。** ガラス（Liquid Glass）は浮いている操作だけ。背景にガラスや写真を敷かない。
6. **写真は縦。** ななめにしない。撮った直後に写真を見せない（ミルク色のフィルムだけ見せる）。

### 時期の注意
12/10〜12/17 に実験（即時確認あり／なしの切りかえ）を行う予定です。
- **Phase 1〜3 は 12/7 までに TestFlight に出せる状態** を目標にしてください。間に合わない Phase は実験後に回します。
- 実験期間中は UI を変えません。
- 実験用に「すぐ見られるモード」などの切りかえがあれば、v133 の画面でも同じように動くようにしてください。ない場合は Phase 0 の報告に書いてください。

## 3. デザインの決まり（トークン）

`reference/LattagTheme.swift` に同じ値があります。

### 色
| 名前 | 値 | 使う所 |
|---|---|---|
| bg | `#000000` | 土台（真っ黒） |
| surface1 | `#0E0E10` | カード |
| surface2 | `#151517` | 入力欄・小さいボタン |
| hairline | 白 8% | カードのふち（0.5〜1pt） |
| ink / ink2 / ink3 | `#F5F5F7` / `#A3A3AB` / `#66666E` | 文字（強い／弱い／もっと弱い） |
| **lime** | `#C8F25A` | **押せる物だけ**（#ボタン・主ボタン・新しい投稿の丸） |
| limeInk | `#0B0D06` | ライムの上の文字・# |
| badge | `#FF4F98` | 通知の数だけ |
| stamp | `#FF9A3C` | 写真の日付スタンプだけ（少しにじませる） |
| タグの # | ピンク `#FF7EB6`・空色 `#6FC6FF`・黄 `#FFD84D`・ライム | タグの「#」の記号だけ |
| milk | `#ECEAE3 → #D2CEC3` | 中身の見えないフィルム |

### 字（3種類だけ）
| 役割 | 書体 | ルール |
|---|---|---|
| 英語の大見出し・大きい数字 | **Barlow Condensed ExtraBold**（PostScript名 `BarlowCondensed-ExtraBold`） | 大文字。白→灰のグラデ（上36%まで白→下 `#8C8C94`）。1画面に1つまで |
| UI 全部（日本語・英語） | **システム書体**（SF Pro＋ヒラギノ角ゴ） | 見出し 22〜30pt heavy／本文 14〜15.5pt semibold／小さい字 11.5〜12.5pt |
| 写真の日付スタンプ | **Space Mono Bold**（`SpaceMono-Bold`） | 写真の上だけ。例 `'26 11 25` |
| ロゴ | `LattagWordmark.svg` | 文字では組まない |

### 形
- 写真の角丸 24／カード 22〜24／大きいボタン 18（高さ 56）／シート上端 34／丸ボタン 64
- タップできる所は 44pt 以上
- 写真の比率は 3:4（縦）

### 光（あかり）のルール
- 画面上の光は **「今日のこり時間」だけ** を表す：9:00 がいちばん明るく、24:00 で消える（不透明度 = 0.18 + 0.62 ×（のこり時間 / 15時間））
- 0:00〜9:00 は「消灯」：光はなし
- 意味のない光るぼかしは置かない

## 4. 画面ごとの指示

スクショの番号を見ながら進めてください。文言は「5. 言葉」の表が正解です。

### 4-1. 共通ヘッダー（`20_home_top`）
- 左：**ともだち追加ボタン**（人＋のアイコン・40pt の丸・ピンクの数バッジ）→ 4-7 のシートを開く。いまの左上ベル（お知らせ）の役割はここに移す（友だち申請はシート、Trip の承認は Trip タブのバッジへ）
- 中央：ロゴ（高さ 25pt）
- 右：自分のアバター（40pt・白 28% の細い輪）→ Profile
- 上端は iOS 26 のスクロールの端のぼかし（黒→透明＋うすいぼかし）

### 4-2. 下のバー：iOS 26 型（`20_home_top`, `21_home_scrolled_tabbar_min`）
- 左：タブ（**Friends｜Trip**）をガラスのカプセルに。選んでいるタブは白 10% の背景
- 右：**#レンズ**（64pt、`HashLensView`）＝撮る。0:00〜9:00 と、今日 3 枚撮りきった後は鍵付きのグレー
- タブの上：**今日のフィルム**（アクセサリ）＝ 3 つの枠＋文言＋カウントダウン。タップで 4-8 のシート
  - 0 枚：「今日のフィルム／24:00の消灯まで、あと3枚」＋ 24:00 までの残り時間
  - 1〜2 枚：「今日のフィルム 1/3／あしたの9:00にひらく」＋ あした 9:00 までの残り時間
  - 消灯中：「消灯中／あかりがつくまで」＋ 9:00 までの残り時間
- 下にスクロールするとタブが小さくなり、アクセサリはタブと#の間に入る（短い文言「消灯まで」「ひらくまで」「9:00まで」＋時間だけ）
- 実装：`TabView` ＋ `.tabBarMinimizeBehavior(.onScrollDown)`、アクセサリは `.tabViewBottomAccessory`、ガラスは `.glassEffect()`（iOS 26 未満はマテリアル）

### 4-3. Home ＝ Friends タブ（`20`〜`23`, `28`）
上から順に：
1. **あなたのきのう**（カード1段）：ぼかしたサムネ3枚の重なり＋鍵／「あなたのきのう」／「今日を1枚撮ると、1枚ひらく」／右にライムの「撮る」
   - ひらいた写真はサムネがはっきりして、ライムの細い輪
   - 文言は 2 行：1行目「1枚のせた · 1枚は自分だけ」、2行目「あと2枚は、撮るたびにひらく」（全部ひらいたら「きのうは、ぜんぶひらいた」）
   - 3枚撮った後は右のボタンが「また明日」（グレー）
2. **ともだちの丸**（ストーリーの丸・64pt）：ライムの輪＝新しい投稿／点線＋色うすめ＝まだひらいていない。最後に「＋ 呼ぶ」（→ 招待）。タップでストーリー（4-6）
3. 見出し「**きのう**」＋ `11.25 WED`（Barlow）＋ 右に「3人がのせた」
4. **投稿**：アバター＋名前＋「16:42に撮った」／写真（3:4・角丸24・左右に 10pt の余白）
   - 写真の上：複数枚なら上に細いバー。左上にガラスの小さいチップ「⏱ 16h20m 待った」（撮った時刻からひらいた時刻までの時間）。右下に日付スタンプ
   - 写真の左右タップで前後の写真
   - 写真の下：タグ（#だけに色）＋あれば曲のチップ
   - その下：「◯◯に返信」の入力欄 ＋ **#で返すボタン2つ**（例 #エモい #天才）。押すと白くなり、下に「あなたのタグは、◯◯だけに見えます」
5. **まだひらいていない**：小さいカード（アバター・名前・「きのう 19:20」・その人のタグ・右にぼかした写真と鍵）
6. 最後：小さい#レンズ＋「**きのうは、ここまで。**」「あしたの9:00に、また。」（無限スクロールにしない）

### 4-4. 消灯（0:00〜9:00）（`24_home_night_lights_out`, `10_lock_night_live_activity`）
- Home の中身を強くぼかして暗くし、スクロールさせない（夜ふかしさせない）
- まんなか：「消灯中」／大きいカウントダウン（Barlow 86pt）／「9:00に、あかりがつく。きのうの3枚は、いま仕上げ中。」／ミルク色のフィルム3枚
- #は鍵。押すと warning の振動だけ
- できれば消灯中はフィードを読み込まない（通信と電池の節約）

### 4-5. 9:00（`11_lock_0900_notification`, `12_goodmorning_0900`）
- **通知**（1日1回だけ）：「あかりがつきました。今日の1枚を撮ると、きのうがひらきます。」
- **Live Activity**（ActivityKit・できればこの Phase で、無理なら後回し）：1枚目を撮った瞬間に始めて、あした 9:00 で終える。ロック画面：#レンズ＋「あかりがつくまで／あと 0:14:12」＋小さいフィルム3枚＋ライムの進みバー。Dynamic Island（コンパクト）：左に小さい#レンズ、右にライムで残り時間
- **GOOD MORNING 画面**：9:00 以降に初めてアプリを開いたとき（または通知から）1日1回だけ出す
  - 上から光がふわっと広がる（1.6秒）＋ 触感「あかり」
  - 大見出し「GOOD MORNING」（Barlow 84pt・2行）＋「11.26 · THU」
  - ミルク色のフィルム3枚（撮った時刻つき・下から順に出る・表面に光が流れる）
  - 「きのうの3枚が、仕上がりました。」「今日を1枚撮るたびに、1枚ずつひらきます。」
  - 下に #レンズ（84pt）＋「撮って、ひらく」→ タグ画面。小さく「あとで」→ Home

### 4-6. ストーリー（`25_story`, `26_story_pending_friend`）
- ともだちの丸から開く。全画面の写真、上にバー（1枚 4.8秒で進む）、名前と「16:42に撮った · 16h20m 待った」、×
- 左タップで前、右タップで次。最後まで行ったら次の人
- 下：返信の入力欄＋#で返すボタン
- まだひらいていない人：写真を強くぼかして、タグだけ見せる。「◯◯は、まだひらいていません」

### 4-7. ともだちシート（`27_friends_sheet`）
- 大見出し「FRIENDS」＋×。切りかえ「リクエスト 2｜ともだち｜さがす」
- 大きい四角ボタン3つ：**ふってつながる**（既存の仕組み）／**QRを見せる**／**リンクで呼ぶ**（→ 招待）
- リクエスト：アバター・名前・「@riko_6982 · 共通のともだち 3人」・ライム「承認」・×
- 一番下：「ともだちの数は、どこにも出ません。」

### 4-8. 今日のフィルム（シート）（`29_todays_film_sheet`）
- 「TODAY'S FILM」＋ミルク色のフィルム（撮った分）と空の枠＋進みバー（撮った時刻 → あした 9:00）＋大きいカウントダウン＋「中身は、あしたの9:00まで見えない」

### 4-9. タグ画面（撮る前）（`30_tag_before_shooting`）— 白と黒だけ
- 開いたらキーボードが出ている（既存どおり）
- 左上×、右上にフィルム3枚の残り（使った分は白）＋「のこり3枚」
- 小さく日付「11.26 THU」、大きく今日のお題「今日は、どんな日？」（既存の毎日かわるお題を使う）
- 入力欄：えらんだタグは白いチップ（×で外す）。**タグは2つまで**（3つ目は warning＋横にゆれる）
- 候補は2列で横に流れ続ける（1列目は感情のことば、2列目は場面のことば）。タップで追加、使ったものはうすくなる
- その下：「曲をつける」「場所 目黒区」（既存の機能につなぐ）
- 白い横長ボタン「撮る」

### 4-10. 撮影（`31`〜`33`）
- 上に小さくロゴ（うすく）。ファインダーは左右 8pt・角丸 30・3:4。上に戻る（→タグ）・フィルムの残り・フラッシュ。右下に日付スタンプ（時刻つき）
- 初回だけ、ファインダーの上に「音量ボタンの長押しでも撮れます」（ガラスのチップ・4秒で消える。ボタンの位置を光らせる表現は使わない：機種で位置がちがうため）
- ファインダーの下：場所＋タグ2つのチップ
- シャッター：白い輪（90pt）。**1.5秒の長押しで撮る**。押している間、まんなかの丸がちぢみ、ライムの輪が満ち、振動がだんだん強くなる（`HoldToConfirm`）。途中で離すと戻って「もう少し長く」
- 左に「#」（→タグ）、右にカメラ切りかえ（内カメラ）
- 撮れた瞬間：白く光る → ファインダーが黒くなる → **ミルク色の板**がフィルム枠へ飛んで入る（0.6秒）＋触感「カシャッ」「トン」。**写真そのものは見せない**
- その日の写真で、きのうの写真がまだひらいていなければ → 4-11 へ。そうでなければ Home へ
- 音量ボタン：既存の仕組みがあればそれを使い、押しはじめ／離したを長押しのはじまり／おわりにつなぐ。ない場合は `onCameraCaptureEvent`（iOS 18〜）の began／ended を使う（Phase 0 で相談）

### 4-11. ひらく（`34`〜`36`）
- 上から光（弱め）。「YESTERDAY · 11.25 · 17:12」＋「1 / 3」（Barlow）
- **チェキ**（白い枠・下が広い・角丸 6）の中で写真がミルク色から現像される（`FilmDevelop`）
  - 何もしなくても 9秒でひらく。**写真をおさえている間は 1.4秒の速さ**でひらき、振動がだんだん強くなる
  - 下に細い進みバー＋「おさえると、はやくひらく」
  - ひらいたら：触感「トトトン」→ 下から「あと2枚は、今日撮るたびにひらきます」＋ ライム「**のせる**」／グレー「**自分だけ**」
- どの写真がひらくか・いくつひらくかは **既存の仕組みのまま**（撮った枚数ぶん・ランダム）
- のせる → 4-12 へ。自分だけ → Home

### 4-12. シェアカード（`40`〜`42`）
- 「ストーリーにのせる」画面。9:16 のカードを3種類から選ぶ（Film／Time／Clean）
  - Film：チェキ風の写真＋「見ないで待った」＋大きく「15H 58M」＋「SHOT 17:12 ----- OPENED 9:10」＋小さいアイコンとロゴ＋日付
  - Time：写真いっぱい＋大きく「15H 58M」＋「見ないで待った1枚」
  - Clean：白い台紙＋写真＋タグ＋日付スタンプ＋ロゴ＋ lattag.app
- 「待った時間」は（あした側の開いた時刻 − 撮った時刻）
- 下：ライム「ストーリーにのせる」（Instagram ストーリーへの共有）＋保存ボタン
- 写真はチェキの質感のまま書き出す（既存の決まり）

### 4-13. 招待（`43_invite`）
- 大見出し「INVITE」＋「ぼかした1枚を送る。ひらくのは、いっしょに。」
- 送る写真を4枚から選ぶ
- 「こう届きます」：LINE 風のふきだしの見本（文面＋ぼかした写真のリンクプレビュー）
- ライム「リンクを送る」＋コピー
- リンクの形と文面の仕組みは **既存のまま**（文面だけ「5. 言葉」に合わせる）。リンクプレビューにぼかした写真を出すにはサーバー側の画像が必要なので、**今回は見本だけ**でよい（Phase 0 で実現方法を一言）

### 4-14. Profile（`50`, `51`）
- 上：下向き矢印（閉じる）・@id・設定
- アバター（86pt）＋名前（28pt heavy）＋「@tatsuki · 2026年11月から」＋タグ3つ
- ボタン：「編集」（グレー）・ライム「プロフィールを送る」（→招待）・QR
- **「11月、見ないで待った 312h」**（Opal の「取りもどした時間」にあたる数字・自分だけに見える）＋右に日ごとの小さな棒グラフ（今日は白）。撮った時刻とひらいた時刻が保存されていれば計算する。なければ Phase 0 で報告
- 「NOVEMBER」の月カレンダー（日〜土・3:4 のマス・その日の写真・今日は白い枠・未来はうすい枠）
- 「7 DAYS」：最近7日の写真の横スクロール。右上に「あと3日」などの残り日数
- **「◯日れんぞく」などの連続記録の数字は出さない**

### 4-15. Trip（`60_trip`）

### 4-16. ウィジェット（`70_widget_homescreen`）

  - 中：ともだちが「のせた」きのうの写真いっぱい＋「れなのきのう」＋「11H 03M 見ないで待った」＋右下に小さい#レンズ
  - 小：#レンズ＋フィルム3枠＋「ひらくまで」＋大きい残り時間＋ライムの進みバー

### 4-17. はじめての設定（Opal 型：1画面に1問）（`02`〜`09`）
1. サインイン：アイコン＋まわりにミルク色のフィルム／「きのうを、共有するSNS。」／「撮った写真は、あしたの9:00にひらく。」／Apple でサインイン／メールは届かない旨・規約・13歳以上
2. 質問「撮った写真、すぐに見返す？」（3択・押したら 0.5秒後に次へ。答えは保存しなくてよい）
3. 理由（まじめなトーン）：「すぐ見ると、自分の顔ばかり気になってしまう。」＋「だからLattagは、撮った写真をあしたの9:00まで見せません。撮り直しも、加工もできません。」
4. 名前「なんて呼べばいい？」＋ @id（使えるかの表示）
5. タグ「あなたを、3つの#で。」（3つえらぶと次へ）
6. 通知「9:00に、あかりで知らせます。」「1日1回だけ。ほかの通知は送りません。」＋通知の見本
7. 大きい #レンズ（176pt）のまわりに刻印の輪（ゆっくり回る）＋「長押しで、はじめる」（1.6秒・振動だんだん強く → 「ブイッ」で白く光って Home へ）
- 上に5つに分かれた進みバーと戻るボタン（1 枚目と最後は進みバーなし）
- 既存の順番（サインイン→名前→アイコン・タグ→ともだち提案→通知）に「質問」「理由」を足す形でよい。ともだち提案は既存のまま残す

### 4-18. オープニング（`01_opening`）
- 黒い画面でアイコンがふくらむ → 左へ動いて小さくなる → 右にロゴが左から現れる → 右上に小さく「9:00」（1.7秒）

## 5. 言葉（UX コピー）

### 使う言葉／使わない言葉
| 使う | 使わない |
|---|---|
| 撮る | 撮影する |
| ひらく | 解禁・現像（画面の文言では） |
| のせる | 投稿する |
| 自分だけ | 非公開 |
| あかり／消灯 | アンロック／ロック |
| #で返す | いいね・リアクション |
| 長押し | ながおし・ロングタップ |
| 16:42に撮った | 16:42に撮影 |
| ともだち | 友達・フレンド |

- **分かち書きはしない**（×「あなたの きのう」→ ○「あなたのきのう」）
- ボタンは動詞で終える（撮る・のせる・送る）。「OK」は使わない
- 英語の大見出しは1画面に1つまで

### 主な文言
| 場所 | 文言 |
|---|---|
| あなたのきのう | あなたのきのう／今日を1枚撮ると、1枚ひらく |
| あなたのきのう（夜） | 9:00に、あかりがついたら撮れる／ボタン「9:00から」 |
| フィードの見出し | きのう／3人がのせた |
| 投稿の時刻 | 16:42に撮った／16h20m 待った |
| #で返した後 | あなたのタグは、ようこだけに見えます |
| まだの人 | まだひらいていない |
| フィードの最後 | きのうは、ここまで。／あしたの9:00に、また。 |
| 今日のフィルム | 今日のフィルム 1/3／あしたの9:00にひらく |
| 消灯 | 消灯中／9:00に、あかりがつく。きのうの3枚は、いま仕上げ中。 |
| 9:00 の通知 | あかりがつきました。今日の1枚を撮ると、きのうがひらきます。 |
| GOOD MORNING | きのうの3枚が、仕上がりました。／今日を1枚撮るたびに、1枚ずつひらきます。／撮って、ひらく／あとで |
| タグ画面 | 今日は、どんな日？／ことばを入れる／曲をつける／撮る |
| 撮影 | 長押しで撮る／そのまま…／もう少し長く／音量ボタンの長押しでも撮れます |
| ひらく | おさえると、はやくひらく／あと2枚は、今日撮るたびにひらきます／のせる／自分だけ |
| シェア | ストーリーにのせる／見ないで待った |
| 招待 | ぼかした1枚を送る。ひらくのは、いっしょに。／リンクを送る |
| 招待の文面 | たつきの「きのう」が届いています。あなたも1枚撮ると、あしたの9:00にいっしょにひらきます。 |
| ともだち | ふってつながる／QRを見せる／リンクで呼ぶ／承認／ともだちの数は、どこにも出ません。 |
| Profile | 11月、見ないで待った／自分だけに見える数字／7日で消える。えらんだ1枚は1年のこる |

英語版（言語設定）がある場合：ひらく＝opens、あかり＝lights on、待った＝waited。「16h20m」の書き方はそのまま使える。

## 7. 触感

`reference/LattagHaptics.swift` に実装があります。

| 瞬間 | 感じ | 指定 |
|---|---|---|
| タグをえらぶ・切りかえ | コツ | `UISelectionFeedbackGenerator` |
| ふつうのボタン | トン | `.light` |
| #で返す | ポン | `.light`（強さ 0.7） |
| 撮る（長押し中） | だんだん強く | `CHHapticEngine` continuous、強さ 0.15→1.0・鋭さ 0.3→0.8 |
| 撮れた | カシャッ | `.rigid`(1.0) → 0.07秒後 `.light`(0.6) |
| フィルムに入った | トン | `.medium` |
| 9:00 あかり | ふわ×3 → ふくらむ | transient(soft)×3・0.12秒おき → continuous 0.8秒（強さ 0.2→0.7→0） |
| ひらく（おさえている間） | だんだん強く | 撮ると同じ長押しパターン |
| ひらいた | トトトン | `.success` |
| のせた | トトン | `.success` |
| できない | トン、トン | `.warning` |
| はじめる | ブイッ | `.heavy` ＋ continuous 0.35秒 |
| ふってつながる | ブルブル | continuous 0.5秒 ×2 |

- スクロールでは振動させない。同じパターンを別の意味で使わない
- 設定に「振動」のオン／オフを置く（`hapticsEnabled`）

## 9. 終わりのチェック

- [ ] 字は3種類だけ（Barlow Condensed・システム書体・Space Mono）
- [ ] ライムは押せる物だけ。ピンクは通知の数だけ。オレンジは日付スタンプだけ
- [ ] ガラスは浮いている操作だけ。背景は黒
- [ ] 写真はすべて縦。撮った直後に写真を見せていない
- [ ] 振動は表の瞬間だけ。スクロールで鳴らない。オフにできる
- [ ] 連続記録・いいねの数・ともだちの数がどこにも出ていない
- [ ] フィードは「きのうは、ここまで。」で終わる
- [ ] 分かち書きが残っていない
- [ ] タップできる所は 44pt 以上
- [ ] iOS 26 未満でも崩れない
- [ ] 中の仕組み（CloudKit・Firebase・Cloudflare・解禁・消える処理）を変えていない
