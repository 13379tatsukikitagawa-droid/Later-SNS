# v60 ── Friend を「友だちの チェキの 壁」に する(モック v58)

> v54 / v56 の Friend 画面(12席の ダイヤル・全員の 一覧)の **見た目を この v60 で 置きかえ**ます。
> 申請・承認・チャット・ブロック などの しくみ(v56)は そのまま 使います。
>
> 見本:
> - `later_v58.html`(下の デモボタン「ともだち 3人にする」→ Friend)
> - `later_v58_friend_preview.png`
> - `MockReference/screens/F11〜F17`
> - コード: `mock/src/v58.js` / `v58.css`

## 1. ねらい

- **友だちの 顔(写真)で わかる**。今は 頭文字の 色丸だけで、だれが だれか わからない。
  - 全部の 丸・カードに **その 友だちの プロフィール写真**を 出す。
  - 名前は **手書き**で 出す。
- **親しみやすく**: 友だち 1人 = チェキ 1枚。部屋の 壁に 貼った 写真の ように、少し 傾けて 貼る。
- **今 動いている 感じ**(没入感):
  - いま 撮った 人が 流れる
  - 撮った 人は 緑の 輪
  - まだの 人は 手を ふって 「つついて」と 合図する
- 数(友だち数・フォロワー数)は 今までどおり 出さない。

## 2. 画面の 並び(上から)

背景は 今の まま(自分の チェキを ぼかして 敷く)。上の 帯は `‹ Friend`(Instrument Serif 44pt)と 白い `Add`。

### ① NOW(いま)

- ガラスの 帯(高さ 40・角丸 20)。
- 左に 緑の 点(ゆっくり 光る)と `NOW`(Space Mono 9pt 緑)。
- 右に「**[写真の 丸] あや が 17:05 に 撮った**」が 横に 流れる(26秒で 1周・両はしは フェード)。
- だれも 撮って いない ときは `まだ だれも 撮って いない ・ さいしょの 1枚に なろう`。

### ② Requests(届いた 申請)── ある ときだけ

- 見出し `Requests` + 赤い 点。`あとで` に した 人が いれば 右に `あとで 2 ›`。
- 申請は **小さな チェキ**(幅 132・±2° 傾け・横に スクロール)。中身は 次の とおり。
  - 申請者の 写真
  - 届いた 時間(オレンジの 印字)
  - 手書きの 名前
  - `@id`
  - 黒地に 黄緑の **`✓ 承認`** と `あとで`
- 承認すると:
  1. チェキが 少し 浮いて → 回りながら 下へ 落ちて 消える(0.52秒)
  2. 下の 壁に その 人の チェキが **上から 貼られる**(−12° → 0、0.7秒)
  3. `success`

### ③ Today(ストーリー)

- 横に スクロールする 丸(70pt)。最初は 黄緑の `+ Add`。
- **撮った 人が 先**。その次に まだの 人を 並べる。
- 丸の 中は 写真(56pt)。まわりの 輪は **3つに 分かれていて、撮った こま数だけ 緑**に なる。
- 撮った 人: 輪の 下に 最後に 撮った 時刻の ピル(緑地 `17:05`)。
- まだの 人:
  - 写真を 少し 暗く・色を 抜く。
  - 右下に **黄緑の 手の ボタン**が 2.4秒ごとに 手を ふる。
  - 押すと すぐ **つつく**(1日 1回)。押した あとは 灰色に なる。
- 撮った 人の 丸を 押すと、④ の 友だちの カードを 開く。

### ④ Friends(チェキの 壁)

- 見出し `Friends` と、右に 検索(`さがす`、名前で しぼる)。
- **2列の チェキ**。右の 列は 24pt 下げて 互い違いに し、1枚ずつ −2.5° 〜 2.6° 傾ける。

| 部品 | 内容 |
|---|---|
| 紙 | #F4F1EA・内側 8pt・下 12pt |
| テープ | 上に。撮った 人は **黄緑**、まだの 人は 白 |
| 写真 | プロフィール写真(縦 1.08 の 比)。まだの 人は 彩度を 下げる |
| 時刻 | 写真の 右下に 最後に 撮った 時刻(オレンジの 印字) |
| タグ | 写真の 左上に はみだして よく 使う タグの シール(−6°) |
| 名前 | 手書き(Caveat / 日本語は Klee One 28pt) |
| こま | 名前の 下に 今日の こま 3つ(撮った ぶん 緑)、または `まだ` |
| ボタン | 右下に 丸 32pt の **チャット**(黒)と、まだの 人には **つつく**(黄緑の 手) |

- 押すと 少し 縮んで まっすぐに なる(0.96 倍・0°)。離すと ⑥ の カードを 開く。
- 開いた とき: チェキが 1枚ずつ 上から 回りながら 貼られる(70ms ずつ・`tick`)。

### ⑤ もっと つながる

- 左に キャラの 群れの 丸(76pt)。右に `もっと つながる` / `となりで ふる ・ QR ・ リンク`。
- 下に 今の Shake / QR / Link の 3つ。Shake を 押すと 群れが ゆれて → つながる 演出(`bumpBurst`)。

### ⑥ You(自分の チェキ)

- 今の 自分の チェキ(タグの シール・QR に 裏返る)を そのまま いちばん 下に。

## 3. 友だちの カード(チェキを 押すと 下から)

- 後ろを 黒 70% + ぼかし。下から 紙ではない 黒い パネル(角丸 34)が 上がる。
- パネルの 上から **大きな チェキ**(幅 206・−3°)が はみだして のる。
  - テープ・写真・日付の 印字・手書きの 名前
  - 左右に タグの シール 2枚(ポンと 貼られる・`tick`)
  - チェキが 下から 回転して 飛んでくる(0.62秒)
  - チェキを 押すと 少し 傾く
- `@rena_6996 ・ since Oct 12`
- **TODAY**: 3つの こま。
  - 撮った こまは ぼかした 写真 + 時刻の 印字 + 🔒(あした 9:00 まで)。まだの こまは 点線。
  - 下に 一言:
    - 撮った とき: `あした 9:00 に ひらく` / `今日 1枚 撮ると、あした 見られる`
    - まだの とき: `まだ 撮って いない ・ つついて 合図しよう`
- ボタン 4つ(高さ 64・角丸 20)。

| ボタン | 色 | 押すと |
|---|---|---|
| **Chat** | 紙色 | 1対1 チャット |
| **つつく** | 黄緑 | 押した あとは 灰色の `つついた` |
| **Trip** | 黒 | New trip を 開き、この 友だちを Who に 入れた 状態に する |
| **more** | 黒 | 友だちを やめる / ブロック / 報告 |

## 4. つつく

- 手の アイコンが ゆれて(0.56秒)、**ピンクの ハートが 5つ 上へ** 飛ぶ。`heart`(ドクン)。
- `○○ を つついた ・ 撮ってね の 合図`。相手には「ゆい が つついたよ」の 通知(1日 1回 まで)。
- 同じ 人に 2回目を 押すと `warn` で ゆれるだけ。

## 5. ほかの 画面の 友だちの 丸も 写真に

- Home の 横スライドの Friends ページ:
  - 丸は 写真。
  - 4人目 以降は **`+2 みんな`** の 丸に まとめて 1列に 収める(下の YESTERDAY が 隠れない ように)。
- Later yesterday の Friend カードの 丸も 写真に する。

## 6. データ

- 友だちの プロフィール写真は `users/{uid}.photoPath`(チェキの 写真)の **サムネイル(200px)**を 使う。一覧では 大きな 写真は 落とさない。
- 「よく 使う タグ」は 本人が Profile で 選んだ タグの 1つ目。
- NOW は 友だちの 投稿の `createdAt` を 新しい 順に 8件(Firestore の リアルタイム 読み取りは この 8件 だけ)。

## 7. 完了の 条件

- どの 丸・カードでも、友だちの 写真と 名前で だれか わかる。
- 撮った 人 / まだの 人が、輪・テープの 色・手の ボタンで ひと目で わかる。
- チェキを 押すと 友だちの カードが 開き、Chat / つつく / Trip / more が 動く。
- 申請を 承認すると、その 人の チェキが 壁に 貼られる。
- 数(友だち数 など)は どこにも 出ない。
