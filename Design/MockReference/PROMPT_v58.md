# v58 ── Trip を「旅の フィルム 1本」に(Once ふう ・ QR の パスで みんなを 呼ぶ)(モック v56)

> Trip は **サブ機能**。ポップに しすぎず、Once(once.film)の ように **写真が 主役で 静か**に する。
> v56(Trips の しくみ)と v57(横スライド)は そのまま 使い、**Trip の 見た目 と 作り方**だけを この v58 で 置きかえる。
>
> 見本:
> - `later_v56.html`(下の デモボタン「ともだち 3人にする」→ Home を 横に 2枚 はらう → `New trip`)
> - `later_v56_trip_preview.png`
> - `MockReference/screens/T01〜T07`
> - コード: `mock/src/v56.js` と `style.css` の 末尾「v56」
>
> サーバー(Firebase の `groups` ・ 23枚の 予約 ・ 9:00 解禁)の しくみは v56 の まま。

## 1. 考え方

- **Trip 1つ = 写ルンです 1本**。表紙の 写真・行き先・日にち・23こまの フィルム・カウンター窓で「旅の フィルム」に 見せる。
- 色は 黒 と 紙色 #F4F1EA が 中心。黄緑は 少しだけ、赤と 金は 帯だけ。ステッカーや 太い 影は 使わない。
- 参加は **パス(チケット)**の QR と KEY で。「旅の チケットを 配る」感覚で、作りたく なる・配りたく なる 形に する。

## 2. Home の Trip ページ(横スライドの 2枚目)

### Trip が ない とき(T01)

- 背景は #0E0E0F。上に、旅の 写真 3枚を チェキの 扇に 並べる(−8° / 0 / 8°、紙の ふち、少し 色を おさえる)。
- `02 / 04 ・ TRIP`(Space Mono 9pt)。その下に **`Take a trip, together.`**(Instrument Serif 40pt。`together.` は Italic 黄緑)。
- その下に `旅行 ・ 合宿 ・ イベント。1日 23枚を、みんなで。`(13pt 灰)。
- ボタン:
  - 紙色の `New trip`(高さ 56、右に 黒い 丸の +)
  - 丸い **QR で 参加**(スキャン)

### Trip が ある とき(T05)

- **表紙の 写真を 全面に**敷く(チェキの 色)。下に 向かって 黒く なる グラデ。
- 上の 列: `TRIP ・ DAY 1 / 3`(Space Mono 9.5pt)。右に ガラスの 丸 2つ。
  - **QR**: パスを 見せる
  - **⋯**: 設定
- **行き先**: `Kyoto`(Instrument Serif 64pt)。下に `京都 ・ 11.15 — 11.17`(Space Mono 9.5pt)。
- **カウンター窓**: 写ルンです の 枚数窓の 形。丸 58pt・黒・内側に 影。中に `03`(Space Mono 22pt 紙色)。
  - 撮るたびに 数字が 上から 落ちてくる。
  - 横に `SHOTS TODAY` / `3 / 23` と、メンバーの 小さな 丸。
- **23こまの フィルム**:
  - 上下に パーフォレーション(穴)。23こまを 横 1列に 並べる。
  - 撮った こまは 撮った 人の 色(自分は 黄緑)。
  - **次の こまだけ 白い 枠が ゆっくり 点滅**する。
  - 1・5・10・15・20 の 番号を オレンジの 印字で 出す。
- `あした 9:00、みんなで 現像`(Space Mono 8.5pt 灰)。
- ボタン:
  - 紙色の **`📷 Shoot for trip`**
  - 丸い チャット(未読 数)
- 撮った とき:
  - 白く 光る(0.48秒)
  - `shutter` → こまが 光って 入る → `tick`
  - 23枚目の 後は `warn` +「今日の 23枚が うまりました ・ あした 9:00 に 現像」

## 3. New trip(作る)= Trip の 設定画面と 同じ 画面(T02・T03)

- 下から 全画面で 出る(0.5秒)。背景は #0B0B0C。上に ✕ と `NEW TRIP`(変える ときは `TRIP SETTINGS`)。
- **いちばん 上に パス(チケット)の 見本**を 固定で 出す。下の 項目を 変えると **その場で パスが 変わる**。
- 項目は 次の 4つ。見出しは Instrument Serif 26pt。

| 項目 | 内容 |
|---|---|
| **Cover** | 写真 62 × 80 を 横に 並べる。選んだ 写真は 紙色の 輪で 3pt 浮く。最後に カメラロール |
| **Where** | 入力欄(Instrument Serif 34pt・下線だけ・`どこへ?`)。下に 候補: 京都 / 沖縄 / 修学旅行 / 卒業旅行 / 合宿 / ライブ遠征。押すと 英語名(Kyoto など)が パスに 入る |
| **When** | 12日分の 日付(6列 × 2段)。**はじまりの日 → おわりの日 の 順に 押す**。両はしは 黄緑、間は うすい 黄緑。右上に `3 DAYS` |
| **Who** | 友だちの 丸(52pt)。押すと 黄緑の ✓。最後に `あとで QR`(作ったあと パスで 呼べる)。右上に `4 PEOPLE` |

- その下に 決まりを 小さな 枠で 3つ: `1日 23枚 ・ みんなで` / `あした 9:00 に 現像` / `7日で きえる`。
- 下に 固定の **`Create trip →`**(紙色・高さ 58)。行き先が 空なら うすく して 押せない。
- バイブ:
  - 表紙を 選ぶ: `sel`
  - 日付の はじまり: `tick`
  - 日付の おわり: `click`
  - 友だちを 入れる: `pop`
  - 友だちを 外す: `soft`

## 4. 作った あと = パスが 印刷される → QR で みんなを 呼ぶ(T04)

- `Create trip` を 押すと、まず パスが 少し 沈んで 浮く(印刷の 感じ)。
  - QR が **上から 1行ずつ 印刷される**(12段)。
  - `projector`(ジジジ)→ `success`。
- 続けて パスの 画面:
  - 背景は 黒 92% + ぼかし。上に `YOUR TRIP IS READY`。
  - パスは 下から **すべりこむ**(8° → −2° → 0°、0.76秒)。QR は 14段で 現れる。
- **パス(チケット)の 形**:
  - 上半分は 表紙の 写真を 暗くして、次を のせる。
    - `LATER ・ TRIP PASS`
    - 行き先(54pt)と 日本語名
    - `FROM NOV 15 → TO NOV 17 ・ DAYS 3`(Space Mono)
    - メンバーの 丸と `4 aboard ・ 23 / day`
  - 真ん中は **ミシン目**(点線 + 左右の 半円の 切りかき)。
  - 下半分は 紙色で、次を のせる。右はしには 白 / 赤 / 金の 帯。
    - **QR**
    - `KEY` と **`#maple308`**(Inter 900。数字だけ 緑。v46 の KEY の 形)
    - `SCAN TO JOIN ・ あした 9:00 に 現像`
- 下に 3つの ボタン:
  - `Share`: リンクと KEY を 共有シートで 送る
  - `Save`: パスを 画像で 写真に 保存
  - `Copy key`: KEY を コピー
- その下に `Start the trip`。
- **QR の 中身は 招待リンク**(`https://later.app/t/<key>`)。読み取ると Trip の 参加画面に なる。友だちで ない 人は、まず 友だち申請(v56)。
  - QR は CoreImage の `CIQRCodeGenerator`(誤り訂正 M)で 作る。
  - パスの 画像は `ImageRenderer` で 作る。
- Trip ページの QR ボタン、⋯ の「パスを 見せる」、Later yesterday の Trips から、**いつでも 同じ パスを 出せる**。

## 5. ⋯ = Trip の 設定(T06)

- アクションシートに、次の 4つ。
  - `パスを 見せる(QR ・ KEY)`
  - `行き先 ・ 日にち ・ 表紙 ・ メンバーを 変える` → 3章と **同じ 画面**を `TRIP SETTINGS` として 開き、今の 値を 入れておく。下に `Trip を おわる` / `ぬける`(2回 押しで 確定)
  - `チャット`
  - `Trip を おわる`(赤・2回 押しで 確定。写真は 7日 のこる)
- メンバーを 外す・Trip を 終えるのは、作った 人だけ。ほかの 人には `ぬける` だけ 出す。

## 6. Later yesterday の Trips(T07)

- カードも 同じ 形の 小さい版(270 × 230)。
  - 表紙の 写真
  - `DAY 1 / 3`
  - 行き先(40pt)
  - 日付
  - 23こまの フィルム
  - `3/23`
  - 紙色の 撮る ボタン と チャット
- 最後に 点線の `New trip`。

## 7. 完了の 条件

- Trip が ない とき、Home の Trip ページに `Take a trip, together.` と `New trip` が 出る。
- New trip で 行き先 ・ 表紙 ・ 日にち ・ 友だちを 変えると、上の パスが その場で 変わる。
- 作ると パスが 印刷されて 出て、QR と KEY が 表示される。Share / Save / Copy key が 動く。
- QR を 別の 端末で 読むと、その Trip の 参加画面が 開く。
- Trip ページで 撮ると、カウンター窓と フィルムの こまが 1つ 進む。23枚で 止まる。
- ⋯ から 同じ 画面で 設定を 変えられる。終える・ぬけるは 2回 押しで 確定する。
