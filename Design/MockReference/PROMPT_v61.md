**FilmArcs(白い 弧 ×3 = 今日の 残り フィルム)**

- 半径 **約 160pt**(レンズの 中心から。外枠 **321 × 321**)、3本。1本 = 1枚 ぶん。
- **残って いる 弧**: 白 `#FFFFFF`、太さ **2.7pt**、丸い 端、ふんわり 光る。
- **使った 弧**: うすい ベージュ `#DCD2C4`、同じ 太さ。変わる とき 0.4秒 で 色が 移る。
- 弧の 間は すきま(約 30°)。3本で ぐるっと 1周 する 形(`MEASURED_SPEC.md` の `svg#ofl.ofa` の path を そのまま 使う)。
- SwiftUI では `Circle().trim(from:to:)` + `StrokeStyle(lineCap: .round)`。

**まわる 物の 注意**

- 回転は **GPU に まかせる**(`rotationEffect` + `drawingGroup()`)。毎フレーム 計算を しない。
- 画面が 見えて いない(別ページ・背面)とき は **アニメーションを 止める**。
- 「視差を 減らす」(Reduce Motion)が オンの とき は、息・波紋・回転を **止める**。静止画の ままで 見た目は 同じ に する。

## 9. 横スライド(いちばん 大事な 仕組み)

**ページ(左から 順に)**: `0 Camera` → `1 Friends` → `2 Trip` → `3 Mondo` → `4 Yesterday`。

**ふるまい**

- 指で **横に はらう** と 次の ページへ。**縦に スクロール すると 今まで どおり 下の 写真へ**(縦と 横を 取りちがえない)。
- 横と みなす 条件: **横に 8pt 以上 動き、かつ 横が 縦の 1.2倍 より 大きい**。縦に 10pt 先に 動いたら 横は あきらめる。
- 端(0 と 4)を こえて ひっぱる と **ゴムの ように 重く なる**(動きの 35% だけ 進む)。端で はなすと バイブ `soft`。
- はなした とき の きまり方: `次の ページ = round(−(今の 位置 + 速さ × 160) / 幅)`。ただし **1回で 動けるのは ±1ページ まで**。
- ばね の 動き: 硬さ **0.0009**、減衰 **0.05**(モックの 物理)。SwiftUI なら `.spring(response: 0.42, dampingFraction: 0.82)` を 目安に、モックと 並べて 合わせる。
- 速さ(フリック)が あれば その 勢いを 引きつぐ。

**3D の 見え方(動いて いる 間)**

- 中心から の 距離 `d`(ページ数)に 対して:
  - 回転: **Y軸 −d × 14°**(`perspective 900`)
  - 拡大: `1 − 0.08 × min(1, |d|)`
  - 透明度: `1 − 0.45 × min(1, |d|)`
- 止まったら すべて 元の 形(回転 0、scale 1、透明度 1)。

**ページが 変わった とき**

- バイブ `sel`(コツッ)。
- ナビピルの 光る ボタンが うつる(§10)。
- 新しい ページの 中身が **下から ふわっと 入る**:各 パーツ `translateY 18pt → 0`、透明度 0 → 1、**0.48秒**、`cubic-bezier(.3, 1.35, .5, 1)`、**120ms 後から 60ms ずつ ずらす**。入り始めの 260ms 後に バイブ `tick`。
- カメラ(ページ 0)に もどる ときは この 入場 アニメは しない。

**実装の メモ**

- `ScrollView(.horizontal)` + `.scrollTargetBehavior(.paging)` + `.scrollTransition` で 3D を つける のが 簡単。足りない ときは `DragGesture` で 自作して よい(モックの 数値に 合わせる)。
- 親の 縦 `ScrollView` と ぶつかる ので、`simultaneousGesture` を 使い、**方向の 判定は 上の 条件**で そろえる。
- 「ほかの ページに いる 間 は、カメラの 位置を 測りなおさない」(四すみボタンの 位置が ずれる 原因)。
- 外の 縦スクロールの 動き(カードが 上へ 流れて 薄く なる 視差)は **ページ 全体に かける**(いままでの 動きを 引きつぐ)。

## 15. 実装メモ(重さ ・ 小さい 端末 ・ アクセシビリティ)

- **重さ**: ぼかし(40 / 50pt)と 回転が 多い。`drawingGroup()` で 1枚の 絵に まとめ、ぼかしは **事前に 画像に して 貼る**(毎フレーム ぼかさない)。回転は `TimelineView` ではなく `rotationEffect` + 一度きりの `withAnimation(.linear(duration:).repeatForever(autoreverses: false))`。
- **ページ外**: 見えて いない ページの アニメは 止める。Home 自体が 背面の ときも 止める。
- **小さい 端末**(幅 375): 左右の 物は 端から の 距離で 置く。レンズ(193)と 輪(488)は **固定の 大きさ**(縮めない)。ステッカーが カードの 外へ はみ出す のは OK。
- **大きい 端末**(幅 402): カードの 幅だけ のびる。レンズ ・ ボタンの 大きさは 同じ。
- **Dynamic Type**: ラベル ・ ボタンの 文字は 固定の 大きさ(`.fixedSize` か 固定フォント)。大きくすると 壊れる ため。
- **VoiceOver**: 四すみは「Yesterday」「Trip」「Mondo」「Friends」+ 状態(ロック中 / 申請 N 件)。レンズは「撮る。あと N 枚」。ナビピルは「ページ、2 / 5、Friends」。
- **Reduce Motion**: 息・波紋・回転・ふわふわ・3D の かたむきを 止める。ページの 切りかえは ふつうの スライドだけ。
- **ダークモード**: このカードは 昼夜 とも 同じ 色。システムの 設定に 左右されない。
