## 0. しらべて 報告(コードは まだ 変えない)
1. Mondo に 関わる もの を ぜんぶ 一覧に(View ・ Model ・ Store ・ CloudKit の 型 ・ Firebase の コレクション ・ ウィジェットの 種類 ・ ライブ アクティビティ ・ 通知 ・ はじめての 説明 ・ 使いかた ・ 設定 ・ 文字列)。**ファイル名と 行**。
2. いまの タブの 作り(Friends | Mondo)と、**Trip に 今 どこから 入って いるか**。
3. Trip の 一覧を 出す ために 読む データ(名前 ・ 日にち ・ メンバー ・ 枚数 ・ 表紙)と、その 読み方(全部 読んで いないか)。
4. 色の 定義の 場所(`Color` の 拡張 ・ Asset)。
5. Friends の リアクション(すき など)の しくみが **今 あるか**。

**ここで 止まって 報告**。

## 1. Mondo を なくす
- 画面 ・ タブ ・ 入口 ・ はじめての 説明 ・ 使いかた の 項目 ・ ウィジェットの 種類 ・ 通知 ・ 文字列を **消す**(古い 画面は のこさない ・ v98)。
- **データは 消さない**:CloudKit の Production の 型は 消せない ので そのまま(読まない ・ 書かない だけ)。Firebase の Mondo の データも 今は 消さない(一覧を 報告に のせる)。
- ウィジェットの 種類を 消すと、置いて いた 人の Mondo ウィジェットは 消える。それで よい。
- 「使いかた」の「ぜんぶ 見る」は **Friends → Trip**(約 30秒)。

## 2. 外がわ(上 ・ 下の タブ)
- 下の タブは **2つ:Friends | Trip**。ガラスの 台(iOS 26 は `.glassEffect()`)に、**ライムの つまみ**(108 × 58pt ・ 角丸 29)が ばねで すべる(`.spring(response: 0.46, dampingFraction: 0.62)`)。えらんだ 方の 字と 絵は 黒 `#111113`。
- Trip の 絵は **チケット**(ミシン目 つき)。地球の 絵は 使わない。
- いま えらんで いる タブを もう一度 押す → いちばん 上へ スクロール。
- 上は 今の まま:左 = お知らせ(ベル ・ 数の 丸は **ピンク**)・ まんなか = タイトル(`Friends` / `Trip`)+ 小さな 字 ・ 右 = アイコン(ライムの ふち)。
  - Friends の 小さな 字:`きのう ・ 3人が 公開 ・ 2人 まだ`
  - Trip の 小さな 字:`いま 1 ・ これから 2 ・ おわった 2`
- タブを かえた 時:中身が 下から 14pt ・ 透明 → ふつう(ばね ・ 部品ごとに 40ms ずらす)。

## 3. ポップの きまり(全体)
### 3-1. 色(CLAUDE.md の「新しい 色を 作らない」を この 3色 だけ ゆるめる)
| 名前 | 色 | 使う 所 |
|---|---|---|
| `lime` | `#C8F25A` | 主な ボタン ・ 今日 ・ えらんだ タブ(今まで どおり)|
| `pink` | `#FF7AB6` | お知らせの 数 ・ すき ・ ステッカー ・ Trip の 色 |
| `sky` | `#6EC8FF` | つつく ・ すごい ・ ステッカー ・ Trip の 色 |

- **ポップ 3色は 面 ぜんぶを ぬらない**(ステッカー ・ タグ ・ 線 ・ 小さな 面 だけ)。字の 色に しない(読み にくい)。
- **Trip の 色**:作った 時に pink → sky → sun → lime の 順で きまる。Trip の 設定で かえられる(4つの 丸)。

### 3-3. 動き(ぷにっ)
- 押す:0.93 へ 縮む(0.08秒)→ はなすと `.spring(response: 0.38, dampingFraction: 0.55)` で もどる。`ButtonStyle` 1つに まとめて、押せる 物 ぜんぶに。
- ステッカーを 押した 時(リアクション):その ステッカーが 上に 70pt 飛んで 消える(0.4 → 1.25 → 1 ・ くるっと ・ 0.7秒)。
- 9:00 の LIVE の 点は 1.2秒で 点滅。フィルムの 絵は ゆっくり 上下(2.4秒)。**画面の 外では 止める**。
- **Reduce Motion**:跳ねる ・ 飛ぶ ・ 点滅 ・ 上下を ぜんぶ 止める(ふつうに 出る だけ)。
- バイブ:タブ = `sel` ・ 押す = `pop` ・ 撮る = `shutter` ・ リアクション = `heart` ・ つつく = `knock` ・ 週を かえる = `notch`。

## 4. Friends(作りなおし ・ 上から 順に)
### 4-1. 今日の あなた(カード 1枚)
- 角丸 30 ・ 地 `#151517` に 左上 ライム 16% ・ 右下 ピンク 14% の ぼんやりした 光(画像を 1回 作って 置く)。
- 左:チェキ(幅 118 ・ -6° ・ 上に sun の テープ ・ 右上に pink の 星)。
  - まだ 0枚:紙の 中に カメラの 絵 ・ 下の 字「まだ 0枚」。**押すと 撮影**。
  - 撮った:今日の 1枚を **ぼかして**(9:00 まで 見せない)・ 下の 字「今日の 1枚」。撮った 時に チェキが ぽんっと 出る(0.7 → 1.08 → 1)。
- 右:`TODAY'S ROLL`(ライム ・ Space Mono)・ 見出し「今日の 1枚を 撮ろう」/「あと 2枚 撮れる」・ ●○○ `0 / 3` ・ 🔒「9:00 に ひらく ・ あと 22:25」(1行 ・ 1分ごと)・ `撮る`(lime)。
- 前の 大きな 空の カード(扇の 3枚)は **消す**。
### 4-2. 友だちの 列(横に すべる)
- さいしょに `さがす`(虫めがね)。つづけて 友だち:丸 52 ・ まわりの 輪 60。
  - 公開 した 人:その 人の 色の 輪(友だちごとに pink / sky / sun / lime を 順に わりふる)+ 右下に 小さな `#` ステッカー。押す → フィードの その 人へ スクロールして ゆれる。
  - まだ の 人:点線の 輪 ・ アイコンは うすく。押す → 「まだ 撮って いません」。
### 4-3. きのうの 1枚(フィード)
- 見出し `きのうの 1枚` + `9:00 OPEN`(sun の タグ)。
- 1人 1枚:上に アイコン ・ 名前 ・ 時刻 ・ `…`(44pt)。下に **大きな チェキ**(余白 10 / 46 ・ 字 26pt)。**1枚ごとに ±1.5° 交互に かたむける**。チェキの 角に ステッカー 1つ(かさならない 位置)。1枚目 だけ 左上に テープ。
- その 下:リアクション 3つ(すき = pink の ハート ・ いいね = sun の 星 ・ すごい = sky の きらり)+ 数 ・ 右に `チャット`。
  - **0 の 5 で リアクションの しくみが 無い なら**、この 3つは 作らず `チャット` だけ(報告して、たつきさんが きめる)。
### 4-4. まだ の 人
- 1枚の カード に まとめる:`まだ の 人 2人` ・ 1行ずつ(アイコン 40 ・ 名前 ・「まだ 公開して いません」・ `つつく`(sky ・ 小))。押すと「つついた」に かわる。
- **前の「まだ 公開して いません」+ 大きな 灰色の 面 は 消す**(スクショ 2枚目の 下)。
### 4-5. さいご
- 4色の フィルムの コマ(pink ・ sun ・ sky ・ lime)が ゆっくり 上下 + ステッカー 2つ ・ `END OF ROLL` ・「きのうの フィルムは ここまで」・「あした 9:00 に、また みんなの 1枚が ひらきます」。v106 の 絵を この 形に 置きかえる。

## 5. Trip(新しい タブ)
### 5-1. 週の 帯(上の カード)
- 見出し:`<` ・ `11月 11/16 〜 11/22` ・ (今週で ない 時だけ `今週` の ライムの 小さな ボタン)・ `>`。帯を 横に すべらせても 週が かわる(`notch`)。
- 7つの 日(月〜日):曜日 10.5pt ・ 数字 19pt 太字。**今日 = ライムの 面**(字は 黒)。Trip が ある 日は 下に 小さな 点。押した 日は 白い ふち。
- その 下に **Trip の 線**(高さ 18 ・ Trip の 色 ・ はじまり / おわりの 日は 角丸 9)。2日 以上 なら 線の 中に 名前。**同じ 日に 2つ 以上 → 段を ふやす(3段 まで ・ それ 以上は `+2`)**。
- 日 / 線を 押す → 下の その Trip の カードへ スクロールして ゆれる。Trip が ない 日 → 「11/23 は Trip なし ・ 新しい Trip で 作れます」。
### 5-2. ボタン 2つ(横に 半分ずつ)
- `+ 新しい Trip`(lime)・ `KEY で 入る`(ghost)。今 ある 作る 画面 ・ KEY の 画面へ。
### 5-3. いま(旅の 途中 ・ 0〜いくつでも)
- 見出し `いま` + `● LIVE`(pink ・ 点が 点滅)。
- 大きな カード(高さ 236 ・ 角丸 30 ・ **Trip の 色の ふち 3pt**):表紙の 写真 + 下が 暗く なる 影。左上 `DAY 2 / 3`(Trip の 色の タグ)・ 右上に テープ。下:英字の 名前(Space Mono ・ Trip の 色)・ 名前 34pt ・ 日にち ・ メンバーの 丸(4人 まで + `+2`)・ `14 / 23枚` と 線(Trip の 色)・ 右に `>` の 丸(Trip の 色)。押す → その Trip の 画面。
### 5-4. これから
- 見出し `これから 2`。1行の カード:左に 日の ブロック(56 × 62 ・ Trip の 色 ・ 曜日 / 日 / 月)・ 名前 ・「11/24 〜 11/26 ・ 3日 ・ 5人」・ 右に 表紙の 小さな チェキ(5° かたむけ)・ 右上に `あと 4日`(タグ)。近い 順。
### 5-5. おわった(アルバム)
- 見出し `おわった アルバム`。2列:チェキが 2枚 重なった 束(Trip ごとに ±2.5°)・ 下の 字に 名前 ・ 右上に Trip の 色の `#` ステッカー ・ 下に `10/27 ・ 41枚`。新しい 順。押す → その Trip の アルバム。
- いちばん 下に 小さく「Trip は 旅の あいだ みんなで 1日 23枚。おわったら アルバムに なります」。
### 5-6. まだ 0件
- `#` の ステッカー ・「まだ Trip が ありません」・「旅の あいだ、みんなで 1日 23枚」・ ボタン 2つ。
### 5-7. 読みこみ(重さ)
- 一覧に 要るのは **名前 ・ 日にち ・ 色 ・ メンバー ・ 枚数 ・ 表紙の サムネ だけ**。写真の 本体は 読まない(v106)。
- 週の 帯は 前後 4週 だけ 作る(すべったら 足す)。

## 6. ほかの 画面(かるく そろえる)
- お知らせ(v108)・ 友だちの カード(v105)・ Trip の 画面の 上 ・ Trip の 設定(**色を えらぶ 4つの 丸を 足す**)・ 送る 文の シート:ボタンを `PopButton` に、見出しを 20pt 太字に、数の 丸を pink に。**形や 流れは かえない**。

## 7. 守る こと
- キャラクター(顔 ・ 人の 絵)は 使わない。ステッカーは 形と 字 だけ。
- ポップ 3色は 4つの 所(ステッカー ・ タグ ・ Trip の 色 ・ 数の 丸 / リアクション)だけ。
- 写真は v107 の 焼いた もの を 出す だけ(表示で フィルターを かけない)。
- 押せる 物は 44pt 以上。字は 部品を 重ねない(`VStack` / `HStack` で 並べる)。
- データ(Mondo の 型 ・ Firebase)は 消さない。

## 8. 確かめる こと
1. どこにも「Mondo」の 字 ・ 地球の 絵が 出ない(設定 ・ 使いかた ・ ウィジェット ・ 通知 も)。
2. タブを 押すと ライムの つまみが ばねで すべる ・ 2回 押すと 上へ。
3. Friends:0枚 → 撮る → チェキが 出て ぼける ・ ●○○。まだ の 人に 大きな 灰色の 面が ない。
4. Trip:今日が ライム ・ 大阪の 線が 3日 ・ 次の 週へ → 今週 ボタン ・ 日を 押すと カードが ゆれる。
5. Trip が 0件 の 時の 画面。
6. Reduce Motion で 跳ねない。390pt の シミュレータで モックと 見くらべる(`★ v97 Friends` `★ v97 Trip`)。
