## 1. 大きな 丸(いちばん 上に いる 時)
- 丸 **74pt**。色は 今と 同じ(友だち `#FF9CC8` ・ Trip `#7CCBFF` ・ きのう `#FFD84D`)。
- **ぷっくり**:左上が 明るい グラデーション(左上 = 色 + 白 46% → まんなか = 色 → 右下 = 色 + 黒 10%)・ 下の ふちに うすい かげ(内がわ 5pt ・ 黒 13%)・ 左上に 小さな つや(白 55% の だ円 26×13 ・ -24°)。
- ふち ミルク `#FAFAF7` 4pt。下に **その 色の 光**(`0 16 28 -8` ・ 色の 70%)。
- 絵 31pt(線 2.3)・ 名前 14pt 太字 `#FAFAF7`。押せる 所 104×112pt。
- 数の 丸(バッジ)24pt ・ まわりに 黒い ふち 3pt。
- ゆっくり 上下に うく(4pt ・ 3.6秒 ・ 0.5秒ずつ ずらす)。画面外 ・ 小さい 列の 時 ・ Reduce Motion では 止める。
- 押すと 0.9 → ばねで もどる。
- グラデーション ・ つや ・ 光は **画像 か 1回だけの 描画**(毎コマ 計算しない)。

## 2. 小さな 列(スクロール 中)
- Home を **150pt より 下に** スクロール したら、大きな 丸は ふわっと 消え(0.25秒 ・ 0.86倍)、画面の 下 まんなかに **小さな 列** が 下から 出る(ばね 0.5秒 ・ 40pt 下 + 0.7倍 から)。上に もどると 逆。切りかわる 時に バイブ `notch`。
- 形:黒い カプセル(`#161618` 94% ・ 角丸 32 ・ ふち 白 12% ・ 影)・ 下から 26pt(安全領域の 上)。
- 中:小さな 丸 **46pt × 3**(同じ 色 ・ 同じ 絵 21pt ・ ミルクの ふち 2.5pt ・ 名前なし)+ 灰色の 丸 38pt の **↑(上へ もどる)**。間 12pt。
- 友だちの 数の 丸(18pt)は 小さな 丸にも 出す。
- 押した 時:大きな 丸と **同じ 行き先**(友だち ・ Trip = その ページへ / きのう = きのうの 画面)。↑ は Home の いちばん 上へ なめらかに。
- 押せる 大きさは 46pt(44pt 以上)。VoiceOver の 名前は 大きな 丸と 同じ。
- Home の 下の 中身は、小さな 列に かくれない ように 下に 110pt の 余白。
- 作り方:`safeAreaInset(.bottom)` では なく、Home の 上に 重ねた 1つの View(`HomeMiniDock`)。スクロール位置は `onScrollGeometryChange`(iOS 18)か `PreferenceKey` で 取り、**しきい値を またいだ 時だけ** 状態を 変える(毎コマ 変えない)。
