# PROMPT v122 ・ Home の 横スライド:Friends ページを しぼる

> Home の 横スライドの **Friends ページ**(Camera の となり)の 中身を **上書き**する(v87 の この ページ)。Home の 下の Friends の かたまり(v121)と Friends 画面(v110)は そのまま。
> モック `mock/lattag_v109.html` ・ 元コード `mock/src/v108.js` `v108.css`
> 見本 `screens/v122_friends_page.png`

## 0. なぜ しぼるか
- 前は 1ページに 10こ あった:絵の 丸 ・ `01 / 03` ・ `?` ・ `0 FRIENDS` ・ タイトル ・ まわる 丸(知らない 人の 字)・ 2行の 説明 ・ 4つの ボタン(QR / 読む / @ID / リンク)・ 申請 ・ 「Friends を ひらく」。
- どれを 押せば いいか わからない。**1ページ = やる こと 1つ**に する。

## 1. 友だちが 0人の 時(上から)
1. `Friends`(50pt セリフ ・ 左)。右上に 小さな `?`(はじめての 説明を もう1回 ・ v99)。
2. 説明 **1行**:「毎朝 9:00 に、きのうを 見せあう」(14pt 太字 ・ 灰色 `#A9A9B0`)。
3. 絵:まんなかに **自分の 丸い 写真**(112pt ・ ライムの 輪)、左右に **点線の 空きの 丸**(78pt ・ `+`)。知らない 人の 丸は 出さない。動かさない。
4. (申請が ある 時 だけ)申請の 行(v119 と 同じ 部品:写真 ・ 名前 ・ ピンクの「確認」)。この 時は 絵を 少し 小さく(自分 100pt ・ 空き 70pt)。
5. **ライムの 大きな ボタン 1つ「友だちを よぶ」**(高さ 60 ・ 角丸 30 ・ 人 + の 絵 ・ 17pt 太字 ・ 段 6pt `#97C235` ・ 押すと 4pt しずむ)→ **Friends の さがす 画面**(v94 の 1つの 入口。QR ・ リンク ・ @ID は そこに ある)。
6. 小さな 字:「QR ・ リンク ・ @ID で つながる」(12.5pt ・ 灰色)。

**消す もの**:左上の 絵の 丸 ・ `01 / 03` ・ `0 FRIENDS` ・ まわる 丸と 輪 ・ 4つの ボタン ・ 白い「Friends を ひらく」。

## 2. 友だちが いる 時(上から)
1. `Friends` + 右上に `?`。
2. 状態 1行:撮った 人が いる → ライムの 点 +「2人 撮った ・ 9:00 に ひらく」/ いない →「きょうは まだ だれも 撮って いない」。
3. 友だちの 丸の 列(今の 部品:輪 = 撮った 枚数 ・ まだの 人は つつく ・ 最後に「よぶ」)。
4. (申請が ある 時 だけ)申請の 行。
5. **ライムの 大きな ボタン 1つ「Friends を ひらく →」**(きのうの 画面の Friends タブへ ・ 今と 同じ 行き先)。

**消す もの**:3つの 数字の 箱(撮った / まだ / 9:00)= 丸の 輪と 状態の 行で わかる。

## 3. きまり
- 字は ぜんぶ 1行。ライムの 面は この ページに 1つ(v119 ③)。
- 中身は 下の 色の 丸(v121)に かからない 高さに おさめる(`VStack` ・ 決めうちの 位置で 置かない)。
- Trip の ページは 今の まま。
