## B. Lattag yesterday(BeReal × setlog)

### B-1. 参考に した こと
- **BeReal**:**今日 撮るまで 友だちの きのうは 見えない**(ロック)。写真に 反応を 返す(RealMoji の かわりに「撮って かえす」)。

- Lattag の 決まり(3枚 ・ 9:00 に ひらく ・ 7日で 消える)と あわせて、**シンプル** に。

## C. ME = 縦線を 重ねた デザイン

### C-1. 考え方
- **1日 = 1本の 縦の 帯、1枚 = 1本の 線**。撮った 枚数だけ 線が **少し ずれて 重なる**(0枚の 日は 細い 灰色の 線)。60日 並べると **自分だけの バーコード** に なる。
- 線の **高さ = 撮った 時間**(朝は 低く ・ 夜ほど 高い)。★ で のこした 1枚は 線の 上に 白い 点。

### C-2. 画面(地 `#0B0C0D`)

| 部品 | 値 |
|---|---|
| 上 | もどる(ガラスの 丸 44)・ `ME`(Inter 900 46 ・ -0.06em)+ その 右に **3本の 縦線**(黄緑 5 ・ 白 4 ・ 緑 `#24A03C` 5 ・ 高さ 34 ・ すきま 1)・ 右に `YOUR 60 DAYS` + 年 |
| **バーコード** | 左右 16 ・ 高さ 236 ・ 角丸 28 ・ `#121315`。中の 線の 場所 326 × 150。1日の 幅 = 326 / 60。1枚 = 幅 2.2 ・ 角丸 1.1 の 線を 1.3pt ずつ ずらして 重ねる。色:1本目 `#24A03C` → 2本目 `#3BD35A` → 3本目 `#C8F25A`(不透明 .62 / .76 / .90)。高さ = 40 + (撮った 時 - 7) / 16 × 104。0枚の 日 = 幅 1 ・ 高さ 26 ・ 白 16%。左上に `● 1日 = 1本 ・ 1枚 = 1本の 線`、右上に 選んだ 日(Inter 900 20)、下に `60 DAYS AGO ・ 30 ・ YESTERDAY` |
| なぞる | バーコードを **指で なぞると** 白い 縦の 線(2pt ・ 光)が ついてきて、1日 ごとに バイブ `tick`。選んだ 日が 下に 出る |
| 数字 | 3つ 横:`106 SHOTS`(黄緑)・ `48 DAYS` ・ `19 KEPT ★`(Inter 900 24 + Space Mono 9)|
| 選んだ 日 | `月 11/16`(Instrument Serif 34)+ `MON ・ NOV 16 ・ 3 SHOTS`(黄緑)。3枚の 写真(3:4 ・ 角丸 14)。撮って いない 所は **縦の しま模様**(`#16171A` / `#121315` ・ 6pt ずつ) |
| この 1週間 | **縦の フィルム** 7本(幅 72 ・ 左右に 送り穴 ・ 上に 曜日 + 日 ・ 3枚を 縦に)を 横に スクロール。★ は 黄緑の 丸 |
| 説明 | `線の 高さ = 撮った 時間(高い ほど 夜)。白い 点 = ★ で のこした 1枚。` |

- 描き方:SwiftUI の `Canvas` で 60日 × 3本を 1回で 描く(軽い)。なぞるのは `DragGesture(minimumDistance: 0)` → 日の 番号。
