## 1. 「Friends」の 表記を そろえる

- いままで:頭の **F だけ 緑 ・ 斜体**(`::first-letter`)。→ **やめる**。
- これから:**全部の 字を 同じ 書体 ・ 同じ 色**(Instrument Serif 400 ・ 白)。斜体に しない。
- 場所:Home 下の Friends カード(32pt)・ Friends 画面の 題(`Friends` `Requests`)・ 横スライドの Friends ページ ・ Lattag yesterday の 見出し。
- SwiftUI:`Text("Friends")` を 1つの `Text` で。`Text("F").foregroundColor(...) + Text("riends")` の ような 分け方は しない。

## 2. 四すみの かぎ:ボタンに ぴったり 沿わせる

実機で かぎが ボタンから はなれて 見えた(左上は YESTERDAY の 左 ・ 右下は FRIENDS の 下)。原因は かぎを **画面 / ファインダーの 座標** で 置いた こと。

- かぎは **ボタンの 子(`.overlay(alignment:)`)** に する。ボタンの 外に 別の View で 置かない。
- 形:ボタン(78 × 78 ・ 角丸 26)と **同じ 中心の 角丸**。かぎの 角丸 = 26 + 5 = **31**、大きさ **30 × 30**、線 **2.5pt**、白 92%(鍵の ボタンは 白 40%)。
- 位置:ボタンの 外側の 角から **5pt 外**(左上の ボタン = 左上の 角、右上 = 右上、左下 = 左下、右下 = 右下)。
- SwiftUI の 作り方(1つの Shape で):
  ```swift
  struct CornerBracket: Shape {          // 1つの 角だけの 弧 + 2本の 線
      var corner: UIRectCorner; var radius: CGFloat = 31; var length: CGFloat = 30
      func path(in r: CGRect) -> Path { … }  // r = ボタンを 5pt ひろげた 四角
  }
  button
    .overlay { CornerBracket(corner: .topLeft).stroke(.white.opacity(0.92), style: .init(lineWidth: 2.5, lineCap: .round)).padding(-5) }
  ```
- 入る 動き(v69 と 同じ):ボタンが 止まった 0.38秒 後に、かぎが 外へ 14pt + 1.5倍 → ぴたっと 止まる。**動きの 基準も ボタン**。
- 確かめ:どの 端末幅(375 / 390 / 440)でも、かぎと ボタンの すきまが **上下左右 同じ 5pt**。

## 3. かざりの シール:ボタンに 重ねない

- シール(左上の キラッ ・ 右上の 波線 ・ レンズの ふちの 花)は **レンズの 中心から の 位置** で 置く(画面の 端からでは ない)。
  | シール | 大きさ | 中心(レンズの 中心から) |
  |---|---|---|
  | キラッ(黒い 4つ星) | 35 × 35 | (-153, -219) |
  | 波線 | 47 × 23 | (+148, -220) |
  | 花(ピンク) | 36 × 36 | (+73, -72)・ レンズの ふちに 貼った シール |
- **ボタン ・ かぎ ・ 上の チップから 8pt 以上 はなす**。重なる 端末(幅 375 など)では シールを 出さない(`ViewThatFits` か 幅で 判定)。
- 浮かぶ 動き(ゆっくり 上下 ・ 少し 回る)は 今まで どおり。

## 4. まんなか = 本物の カメラの レンズ(いちばん 大事)

ねらい:**透明な ガラスの 丸 → 黒い 本物の レンズ**。ひと目で「カメラ」と わかる 強さ。ただし 写ルンですの 本体は 描かない。にせの 数字(f値 ・ ISO ・ mm)も 書かない。

### 4-1. 大きさ

- 直径 **312pt の 座標で 作って 0.71倍(= 約 222pt)**。押して いる 間は 0.68倍。
- まわりに 黒い 影(半径 26pt 外まで 55% → 0)で 背景の 写真から 浮かせる。

### 4-3. ガラスの 反射(コーティングの 色)

ガラスの 円(直径 226 の 座標)で 切った 中に:
1. 左上:**紫の 光** `rgba(140,110,255,.42)` の だ円(幅 44% ・ 高さ 30% ・ 左 22% ・ 上 14%)
2. 右下:**黄緑の 光** `rgba(200,242,90,.32)`(幅 36% ・ 高さ 26%)
3. **ゆっくり 回る 色の 帯**:円すいグラデーション(青 14% と 紫 14% の 細い 帯 2本)・ 16秒で 1回転
4. 左上の **白い ハイライト**(白 34% → 0 ・ -24° 傾ける)
5. 右上の **小さな 光の 点** 12pt
- SwiftUI:`Circle().fill(RadialGradient…)` を 重ねる + `AngularGradient` を `rotationEffect`(`TimelineView(.animation(minimumInterval: 1/30))`)。**ぼかし(blur)は 使わない**(グラデーション だけで 作る)。

## 5. 重さ

- レンズは **全部 Shape と グラデーション**(画像 ・ ぼかし なし)。動かない 部分(ふち ・ 胴 ・ ギザギザ ・ 刻印 ・ ガラス)は 1つの View に まとめて `.drawingGroup()`。
- 動く のは 色の 帯 1つ ・ 刻印の 回転 ・ しぼり ・ 光 だけ。Home が 見えて いない ときは 色の 帯を 止める。
- ガラス(Liquid Glass)の 数は 増えない(レンズは ガラスを やめた ので 1枚 減る)。
