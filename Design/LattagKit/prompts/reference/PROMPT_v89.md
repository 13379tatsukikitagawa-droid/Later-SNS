## A. Home:黄緑の # の 上でも スクロール(**3回目** ・ これで 終わらせる)
- いまの 実機:**黒い 所** は スクロール できるが、**黄緑の # の 上** から なぞると 動かない。
- つまり **# の 帯(黄緑)に 何かが 付いて いる**(ジェスチャー ・ Button ・ contentShape ・ 当たり判定の ある Shape)。
- やる こと(この 順):
  1. # の 帯を 描いて いる View を 探して、**付いて いる 物を ぜんぶ 報告**(`.onTapGesture` `.gesture` `.simultaneousGesture` `.highPriorityGesture` `.onLongPressGesture` `Button` `.contentShape` `.onContinuousHover` `UIViewRepresentable`)。
  2. # の 帯は **ただの 絵** に する:`.allowsHitTesting(false)`。# に 付いて いた 動き(押すと 光る など)が あれば、**ScrollView の 外側の 1つの `SpatialTapGesture`(`.simultaneousGesture` ではなく `.onTapGesture(coordinateSpace:)`)で 位置を 見て** 動かす。DragGesture は 使わない。
  3. 形を `HomeHeroScroll_example.swift` に そろえる(たての ScrollView が 外 ・ 横は `ScrollView(.horizontal)` + `.paging` ・ 押せる のは レンズの 丸 だけ)。
  4. **UI テスト 3本**(左の 帯 ・ 右の 帯 ・ レンズの 上 から 上へ なぞる → `Today` が 見える)を 書いて、**3本 とも 通る まで** 直す。テストの 結果を 報告に 入れる。
- 横スライド ・ レンズを 押して 撮る ・ アイコンの 1回 / 2回 タップ は 今まで どおり 動く こと。

## B. オープニング:なめらかに(カクつかない)
- いまの 実機:動きが 途中で 止まる / ガタつく。**ねらいは 120fps(ProMotion)で 1コマも 落とさない** こと。
- やる こと:
  1. `Info.plist` に **`CADisableMinimumFrameDurationOnPhone` = `YES`**(これが ないと iPhone Pro でも 60fps まで)。
  2. **重い 仕事を オープニングの 間に しない**:Firebase の 読みこみ ・ 画像の 読みこみ ・ Home の 地球儀(Canvas)・ カメラの 準備は **オープニングが 終わる(2480ms)まで 待つ** か、**メイン スレッドの 外**(`Task.detached` / `.task(priority: .utility)`)。起動の 中で `await` で 待たない。
  3. 動きは **1つの 時計** で:`TimelineView(.animation)` か `keyframeAnimator` に まとめる(`DispatchQueue.main.asyncAfter` を 重ねない)。
  4. 変えて よい のは **`scaleEffect` ・ `offset` ・ `opacity` ・ `rotationEffect` だけ**(`frame` の 大きさ ・ `font` の 大きさ ・ `blur` の 半径を 毎コマ 変えない)。アイコン 132 → 78 は 132 で 描いて `scaleEffect(78/132)`。文字の 横すべりは `mask` の `offset`。
  5. アイコン ・ 文字 ・ 光は `.drawingGroup()`(1枚の 絵に して GPU で 動かす)。光(ぼかし)は 前もって 作った 画像を 使う。
  6. Home が ひらく 丸は `Circle().scaleEffect(...)` を mask に(半径を 変えない)。
  7. フォント(Inter)は 起動の 最初に 登録 済み に しておく(はじめての 文字で 引っかからない)。バイブは `prepare()` しておく。
  8. 最後に **Instruments の「Animation Hitches」** で はかり、ヒッチ 0 を 確かめて 報告。
- 見た目 ・ 時間割り は v72 / v88 C の まま(変えない)。
