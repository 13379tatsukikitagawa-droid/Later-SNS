- SwiftUI:アイコン ・ 文字 ・ 9:00 ・ 光は `keyframeAnimator`(この 表を そのまま)。文字の 1文字ずつは `ForEach` + delay。Home の 丸い mask は `.mask { Circle().frame(width: r*2).position(c) }` を `withAnimation(.timingCurve(.7,0,.2,1, duration: 0.72))`。

## 5. 出す とき ・ 出さない とき

- **アプリを 起動した とき だけ**。ほかの アプリから 戻った とき(`scenePhase` が active に 戻る)は 出さない。
- **0.6秒 たったら タップで とばせる**(すぐ 1760ms の「ひらく」へ)。
- 通知 ・ ウィジェット ・ リンクから 開いた ときは **短い 版**:0〜330ms の あと すぐ 1760ms へ(文字 ・ 9:00 を 出さない)。
- はじめての 設定(オンボーディング)へ 進む 人は、「ひらく」の 代わりに オンボーディングの 1枚目へ フェード。
- Reduce Motion:動かさず 最後の 組み(アイコン + Lattag + 9:00)を 0.6秒 見せて、フェードで Home。
