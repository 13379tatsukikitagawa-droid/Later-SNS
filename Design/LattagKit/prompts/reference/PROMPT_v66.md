# Lattag v66 ・ まんなかを カメラの 絵だけに ・ 上と 下を ガラスに ・ はじめての 日も 同じ Home に

> **v64 → v65 の あとに 重ねる 差分** です。ここに 書いた 所だけ 変えます。
> 見本:モック `lattag_v63.html`、画像 `MockReference/screens/HomeMain/`(`M01` 正解 / `M02` 4つの 状態 / `M03` 前と あと / `M08` はじめての 日 / `M09` はじめての 日の 前と あと)。
> 元コード:`MockReference/mock/src/v63.js` と `v63.css`。

## 1. まんなかの ボタン = カメラの 絵だけ

- 「Shoot」と「3 LEFT」の **文字を 消す**。のこり 枚数は **ふちの 白い 弧 3本だけ** で 伝える。
- まんなかに **カメラの 絵**(線の 絵。自前の ベクター):
  - 大きさ **幅 67 × 高さ 52pt**(ガラスの 直径 201pt の 約 1/3)。
  - 線 白、太さ **3.2pt**、角は 丸く。形:角丸の 本体(上に ファインダーの 出っぱり)+ **レンズの 丸**(半径 10.7pt)+ レンズの 中の **白い 丸**(半径 4.8pt、絞り)+ 右上に **ライムの 点**(半径 2.2pt、`#C8F25A`、フラッシュ)。
  - 影:黒 28%(y4、ぼかし14)。
- **押している 間**:レンズの 中の 白い 丸が **scale 0.45 に しまる**(絞りが しまる)。0.3秒 `(.3,1.5,.5,1)`。ほかの 動き(ボタンが 縮む ・ ピント ・ 白い 光 ・ 線)は v64 / v65 の まま。
- **3枚 撮りおわり**(Yesterday):前日の 写真の 窓の 上に **写真が 重なった 絵**(54pt、白い 線)だけ。文字は なし。
- **VoiceOver**:「撮る。あと 3 枚」/「Yesterday を ひらく」(絵だけ なので 必ず つける)。
- SF Symbols を 使う 場合は `camera`(線)/ `photo.on.rectangle.angled` に 近い 見た目。ただし 太さと 大きさは 上の 数値に 合わせる。

## 3. 下(今日を撮る)

- 月の **形(大きな 半円)は 残す**。中身を 変える。
- **黒い すりガラス**:黒 62% + うしろを ぼかす **26pt**(彩度 1.7)。**うしろの 画面が すけて 見える**(スクロール すると カードや 写真が ぼやけて 通る = iOS 26 の スクロール端の 見え方)。
- **点の 地球(キャンバス)と 内側の 緑の 光は 消す**。
- ふち:v65 の ガラスの ふち(光が 当たる 側だけ 明るい、太さ 1.4pt)。上に ゆっくり 光の すじ(白 16%)。
- 影:黒 45%(y −20、ぼかし46、広がり −16)。
- 中身(上から 20pt、中央):
  - 1行目:**カメラの 絵**(26 × 20pt、白い 線 1.8pt)+ **「今日を撮る」**(Inter **800 21pt**、白)。間 9pt。
  - 2行目:**3本の 短い バー**(14 × 6pt、角丸 3、間 4pt。のこり = ライム `#C8F25A`、使った = 白 20%)+「のこり 3こま」(Space Mono 700 10.5pt、白 70%)。間 7pt、上との 間 7pt。
- 文字の 変わり方(今と 同じ):0枚「今日を撮る」/ 1 ・ 2枚「もう1枚 撮る」/ 3枚「9:00に、ひらきます」(カメラの 絵は 消す、2行目は「あした 9:00 に ひらく」)。
- 押した とき:4pt 上がって scale 1.015、黒 66% に。

## 4. はじめて ログイン した 日も、いつもの Home と 同じ 形に

**前の 形(やめる)**:見出し「あしたの朝に、今日の1枚が ひらきます。」/「最初の1枚に、なります」の 白い カード / グループ(つくる ・ 参加する の 大きな 2つの ボタン)/「今日の film」…… **いつもの Home と 別の 画面** だった。

**新しい ルール**

- **はじめての 日も、2日目からと 同じ Home**(上の カメラカード → Today → Active → Yesterday → Friends)を 出す。**はじめて 専用の 画面 ・ 区画は 作らない**。
- 「はじめて かどうか」は **データで 決める**:`hasYesterday`(ひらける きのうの 写真が 1枚 以上 ある)が false の 間 = はじめての 日。
- データが ない 所だけ、**同じ 形の 空っぽ表示**に する:

| 区画 | はじめての 日 |
|---|---|
| カメラカード | そのまま。上の チップは「友だちを よぶ ADD ›」(友だち 0人)。四すみの Yesterday ・ Mondo は ロック |
| Today ・ Active | そのまま(空の 3こま ・ New trip) |
| **Yesterday** | 写真の 区画の かわりに **空っぽの カード**(下) |
| Mondo ・ Albums ・ On this day | **出さない**(見出しごと)。きのうの 写真が できたら 出る |
| Friends カード | そのまま(だれも いない とき の 形:キャラ + Shake / QR ・ ID / Link) |

**Yesterday の 空っぽの カード**(`M08` の まんなか)

- いつもの Yesterday と 同じ 位置 ・ 幅(左右 14pt)、角丸 30、地 `#161618`、白 8% の 線。内側 上 26 / 左右 22 / 下 22。
- 上:**チェキの 枠 3つ**(96 × 118pt、点線 白 28%、−10° ・ 0° ・ +10°、左右に 70pt ずらす、外側は 12pt 下)。まんなかの 1つだけ 実線 白 50% で、下に「TODAY'S 1ST」(Space Mono 700 9pt、ライム)。中に ライムの うすい 光。
- 「**Yesterday**」Instrument Serif 40pt、中央。
- 「今日 撮った 1枚が、あしたの 朝 9:00 に / ここで ひらきます。」Inter 500 13pt、白 66%、中央。
- 下に カウントダウンの ピル:「● 9:00 まで 21h 27m」(Space Mono 700 11pt、白 85%、ライムの 点が 2.2秒で 輪)。30秒ごとに 更新。

**横スライドの Yesterday ページ(はじめての 日)**

- 右上の 状態:`FROM TOMORROW`。チェキの 扇は **点線の 空の 枠**(写真 ・ 時刻 ・ 鍵 ・ タグは 出さない)。うしろの ぼかし写真も 出さない。
- 下の ボタン:「**撮ると、あした ひらく**」(白、右に 緑の 丸 + カメラ)→ 撮影へ。

**はじめての 合図**(説明は 最小限)

- はじめての 日:**まんなかの ボタン** に「ここから、1枚目」(0枚の とき)。
- 2日目から:今と 同じ(月の 上に「撮ると、きのうが 1枚 ひらく」)。

**消す もの**:はじめて 専用の 見出し ・「最初の1枚に、なります」カード ・ グループの つくる / 参加する ・「今日の film」区画 ・ HOW IT WORKS(はじめての 日だけ)の 説明。**グループ(Trip)を つくる 入口は Active の「New trip」と 四すみの Trip に 一本化**(v59 の とおり)。

## 5. 完了の 条件

- まんなかの ボタンに **文字が ない**(カメラの 絵だけ)。押すと 絞りが しまる。VoiceOver で「撮る。あと N 枚」と 読む。
- ヘッダーの プロフィールの 輪が 撮った 枚数 ぶん 緑に なる。「消灯まで」が すりガラス。
- 月が 黒い すりガラスで、うしろが すけて 見える。点の 地球が ない。
- **新しい アカウントで ログイン → 2日目と 同じ 形の Home** が 出る。はじめて 専用の 画面が 1つも 出ない。Yesterday に 空っぽの カード、Mondo ・ Albums ・ On this day は 出ない。
- 次の 日の 9:00 に きのうの 写真が ひらいたら、ふつうの Yesterday ・ Mondo ・ Albums に 切りかわる(アプリを 開きなおさなくても)。
- 実機の スクショ(ビフォー / アフター:Home と はじめての 日)を 見せて 完了。
