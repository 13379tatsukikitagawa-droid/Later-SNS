## 0. 決まり
- **字を 使わない**(上の 帯の `Mondo` だけ)。`世界の きのうが ここに ある。` ・ `2,431 SHOTS` ・ `タップで Mondo を ひらく` ・ `指で 地球を まわせます` は **消す**。
- 伝える のは 絵と 動き だけ:**地球 ・ 写真の ピン ・ 都市を むすぶ 弧 ・ 広がる 輪 ・ 黄緑の 丸い ボタン**。
- 読み上げ(VoiceOver)には ラベルを つける:地球 =「Mondo を ひらく。指で 地球を まわせます」・ ボタン =「Mondo を ひらく」。

## 1. 形(`Y10`)
| 部品 | 値 |
|---|---|
| 地 | 黒 + うすい 星(白 35〜65% の 1〜1.5pt の 点 8つ ・ 4秒で またたく)|
| **地球** | まんなか x 195 ・ y 272(画面の 上から)・ 半径 **178** ・ 傾き 23° ・ ゆっくり 回る(v77 の 球と 同じ 線 ・ 都市の 光)|
| 大気 | 地球の ふちの 外に 黄緑 22% → 緑 8% → 0 の 光の 帯 |
| **都市を むすぶ 弧** | 手前に ある 都市どうしを 黄緑の 点線(1.4pt ・ 3 / 5)で むすぶ。弧は 地球の 外へ ふくらむ(2点の 距離 × 0.35)。点線が 流れる(1.6秒)。奥へ 行くほど うすく |
| **写真の ピン** | 10都市に その 都市の 写真(36 × 46 ・ 角丸 9 ・ 黒 2 + 黄緑 1.5 の ふち)+ 下に 黄緑の 針(2 × 8)。都市の 少し 外側に 立つ。**手前ほど 大きく(0.55〜1倍)・ 奥へ 回ると 消える** |
| 輪 | 地球の まわりに 黄緑の 輪が 2本、時間を ずらして 広がって 消える(押せる 合図)|
| **ボタン** | 地球の 下(上 536)に **黄緑の 丸 68**(白っぽい 光の 輪 6pt)。中に **広げる アイコン**(↗↙ の 2本の 矢印 ・ 黒 2.4pt)。字は なし |

## 2. 動き
- 指で 左右 → 地球が 回る(v79 の まま ・ 18° ごとに `tick` ・ 慣性)。ピン ・ 弧も 一緒に 回る。
- **地球 か ボタンを タップ → ひらく**(`M23`):速く 回る(`rumble`)→ 地球が **その場で 2.6倍 + ぼかし + 消える**(近づく)・ 光 → `success` → Mondo の 中身。
- Reduce Motion:回転 ・ 弧の 流れ ・ 星を 止める。タップで すぐ ひらく。

## 3. 作り方
- 地球 ・ 弧は `Canvas`(`TimelineView(.animation(minimumInterval: 1/30))`)。写真の ピンは `ForEach` の 小さな View を 投影した 位置へ(`.position` ・ `.scaleEffect` ・ `.opacity` ・ `.zIndex`)。
- 写真は サーバーの 都市ごとの 代表 1枚(48px の 小さな 画像を 使う)。
