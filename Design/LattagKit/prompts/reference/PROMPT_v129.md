## 0. なにが あいまい だったか(たつきさん の スクショ)
1. 上に ボタンが 4つ(もどる ・ TRIP の 字 ・ 招待 ・ 設定)が かさなって、字が 写真に 埋もれて いた。
2. 「+ よぶ」が 表紙の 中で 小さく、押せると わかりにくい。
3. チャットが **右下の 丸 + 浮いた 吹き出し** の 2つ に わかれて、写真の 上に かさなって いた。
4. チャットを ひらいても **送れない**(見本 だけ)。

## 2. チャット(本当に 送れる)
### 見た目
- 上:もどる ・ Trip の 名前(セリフ 22)+「● 4人 ・ DAY 2 / 3」・ 右に メンバーの 丸。
- 吹き出し:相手 = `#1F1F23` ・ 自分 = **ライム**(字は 黒)。続けて 送った 物は 角を 小さく して 1つの かたまりに 見せる。名前は 相手の かたまりの 最初 だけ、丸い 写真は 最後 だけ。
- 時間は かたまりの 最後の 横に(10pt)。自分の 物には **既読 N**(読んだ 人の 数)。
- 日が かわる 所に `DAY 2 ・ 11/21(土)` の 札。だれかが 乗った ・ 撮った も 札で 出る(紙飛行機 / カメラの 絵)。
- 写真は チェキ(170pt ・ ±2°)、ステッカーは 76pt(±6°)。

### 送れる 物(下の 入力)
1. **字**(200字 まで)。リターンで 送る(日本語の 変換中は 送らない = `isComposing`)。字が ない 時は 送る ボタンを うすく。
2. **よく使う ことば**(入力の 上の 横スクロール):「はよ 撮って」「いま どこ?」「撮った!」「9:00 たのしみ」「おつかれ」。押すと すぐ 送る。字を 打って いる 間は かくす。
3. **ステッカー**(ステッカーの 絵 → 8つ)。
4. **写真**(写真の 絵 → **ひらいた 写真 だけ**)。**きょう 撮った 写真は 送れない**(あした 9:00 の 解禁を 守る ・ Lattag の 定義「解禁遅延型」)。一覧の 上に「ひらいた 写真 だけ 送れる(きょうの 分は あした 9:00 から)」と 書く。
- 送ると 下から ぽんっと 出る(0.38秒 ・ ばね)・ バイブ `pop`(ステッカーは `heart`)。
- 入力が 出たら 一覧の 下を 入力の 高さ に 合わせ、いちばん 下へ スクロール(`safeAreaInset(.bottom)` + `@FocusState` ・ v95)。

### データ(実機)
- メッセージ = 今 ある **`GroupChatMessage`**(Trip の 共有ゾーン)。種類 `text / sticker / photo / system`。写真は **ひらいた 写真の レコード参照**(コピーしない)。
- **既読** = メンバー ごとの `TripReadState`(同じ 共有ゾーン ・ `lastReadAt`)。ひらいて いる 間 と 閉じた 時に 更新(1秒に 1回 まで)。既読 N = 自分の メッセージより 後の `lastReadAt` の 人数。
- 新しい メッセージ = `CKDatabaseSubscription`(共有DB)+ 変更トークンで 差分 だけ(v106)。プッシュは v111 で 決めた `trip_members` → Worker → APNs(本文は「れな:はよ 撮って」・ 写真は「写真」と だけ)。
- 未読の 数 = 自分の `lastReadAt` より 後の 相手の メッセージ数(部屋の 下の バー と Home の Trip に 出す)。
- **モック だけ**:相手の「…(入力中)」と 自動の 返事。実機では 作らない(CloudKit で 入力中は 送らない)。

## 3. 作らない もの
- 写真を カメラロールから 送る ・ 動画 ・ 音声 ・ 消す / 編集(あとで 決める)。
- 新しい 色(Trip の 色 ・ ライム ・ ポップ 3色 だけ)。
