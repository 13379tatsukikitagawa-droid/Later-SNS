## 3. QR の 描き方(**ここが Lattag らしさ**)
- 中身:`https://lattag.app/u/<id>`(今 ある 友だち招待の URL が あれば それ)。**誤り訂正 H**(まんなかに アイコンを 置く ため)。
- **点(ドット)**:1マス = 丸(半径 0.43 マス)。
- **# の 形**:QR の 中に 大きな「#」が うかぶ ように、# に 重なる 点 を **緑 `#1F8F37`**、ほかは **黒 `#0B0C0D`**(どちらも 濃い 色 なので 読める)。
  - # の 場所(QR の 幅を 1 と して):たて棒 x 0.27〜0.40 と 0.60〜0.73(y 0.08〜0.92)・ よこ棒 y 0.27〜0.40 と 0.60〜0.73(x 0.08〜0.92)。
- **3つの 角の 目(ファインダー)= レンズ**:外 7 × 7 マス(角丸 **1マス まで** ・ これ 以上 丸く すると 読めなく なる)・ 中の 白 5 × 5 ・ まんなか **丸い レンズ**(半径 1.62 マス)+ 左上に 黄緑の 光の 点(半径 0.38)。
- **まんなか**:アプリアイコン(黄緑の 角丸 22.4% ・ 黒い # ・ レンズ)7.6 マス。アイコンの 下の 点は 描かない(まわり 0.4 マス も あける)。
- 外側の 白い ふち(quiet zone)は **4マス 以上**(窓の 余白 + 1マス)。
- 作り方(iOS):
  ```swift
  // 1) マトリクス:CIFilter.qrCodeGenerator(message: data, correctionLevel: "H") の 出力を 1px = 1マス で 読む(まわりの 白い ふちは 取りのぞく)
  // 2) Canvas で 描く:各マス → 丸(r = 0.43 マス)・ # の 中は 緑。角の 3つは 自前の 形(上の 値)。まんなかに アイコン
  // 3) テスト:描いた 画像を Vision(VNDetectBarcodesRequest)で 読んで、URL が 同じ ことを たしかめる(Unit テスト)
  ```

## 4. 動き(`M32`)
| 時間 | 動き | バイブ |
|---|---|---|
| 0 〜 0.62秒 | チェキが 上から 落ちて くる(上 70 ・ -9° ・ 0.92倍 → 8 下 ・ -1° → 止まる)・ `timingCurve(.3,1.2,.4,1)` | `pop` |
| 0.3 〜 0.76秒 | アイコンが ポン(0 → 1.12 → 1)| — |
| 0.2 〜 0.4秒 | 3つの 目が 出る(0.6 → 1)| — |
| 0.26 〜 1.04秒 | **点が まんなか から 外へ 現像 される ように 出る**(1つ 0.26秒 ・ まんなか からの 距離で ずらす)| 0.38 / 0.56 / 0.74秒 に `tick` |
| 0.38秒 〜 | 下の 5つが 下から 順に(50ms ずらし)| — |

- **なぞると かたむく**(左右 ±7° ・ 上下 ±5°)+ 光が 動く(つや)。
- **チェキを タップ = うらがえる**(Y 軸 180° ・ 0.55秒):うら = **自分の 写真 + 自分の タグ 3つ(シール)+ 名前 + `LATTAG ・ SINCE 2026`**。もう1回で QR に もどる。バイブ `pop` / `sel`。
- Reduce Motion:落ちて こない ・ 点は すぐ 出る ・ かたむかない。

## 5. 下の 5つ
| ボタン | 動き |
|---|---|
| コピー | URL を コピー → チェキの 下に **`✓ コピーしました`**(ガラスの カプセル ・ 1.8秒)・ `success` |
| LINE | `line://msg/text/?<URL を エンコード>` を ひらく(`LSApplicationQueriesSchemes` に `line`)。LINE が ない 時は 共有シート |
| メッセージ | `MFMessageComposeViewController`(本文 = `Lattag で つながろう <URL>` ・ チェキの 画像を 添付)|
| 保存 | **チェキ ぜんぶを 画像に**(`ImageRenderer` ・ 3倍 ・ うしろは 透明 か 黒)→ 写真に 保存(`PHPhotoLibrary` 追加 だけ)・ チェキが 少し 沈む + 白い フラッシュ + `shutter` + `チェキを 写真に 保存しました` |
| その他 | `ShareLink`(画像 + URL)|

- 右上の **QR を 読む** = いまの 読み取りカメラ(v85)。
- LINE ・ メッセージの 丸は **アプリの ロゴを 描かない**(色 + 吹き出しの 絵 だけ)。
