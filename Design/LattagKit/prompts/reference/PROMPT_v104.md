## 2. サインイン画面(O04)
### 2-1. 見た目(モック `サインイン(Apple だけ)`)
- 上の 写真 ・ ロゴ ・ `FILM FOR TOMORROW` は 今の まま。
- 見出し:`昨日を` / `共有する SNS`(2行 ・ `Later Mincho` ・ 46pt ・ 行間 1.08 ・ `SNS` だけ ライム `#C8F25A`)。
- ボタンは **1つ**:白い 丸(88pt)+ まんなかに **黒い Apple の ロゴ**(42pt)。下に「Apple で つづける」(16pt ・ 太字 ・ 白)。
- 丸の まわりの 動き(**丸の 外だけ** で 動かす):
  - 点線の 輪(丸より 9pt 外 ・ ライム 70% ・ 14秒で 1回転)
  - 波紋 2つ(ライム 55% の 線 ・ 1 → 1.62倍 ・ 2.8秒 ・ 半分 ずらす)
  - 出てくる 時:0.6 → 1倍 + 不透明に(0.7秒 ・ ばね)
  - 押す:0.93倍(`scaleEffect`)
  - 待つ 間:点線の 輪が 速く(1.1秒で 1回転)+ ライムの 弧が まわる ・ ロゴは 35%
  - 入れた:丸の まわりに ライムの 光(4pt + ぼかし)→ 0.46秒 後に Name へ
- **Apple の きまり**:丸の 中(白い 面 ・ 黒い ロゴ)は **かえない**(色を ぬらない ・ ロゴを 動かさない ・ 光を 通さない)。ロゴは **Apple が 配って いる 形**を 使う(SF Symbol `apple.logo` か Apple Design Resources)。字「Apple で つづける」を **かならず となりに** 置く。
- 押せる 大きさ:丸 全体(88pt)。VoiceOver:「Apple で つづける、ボタン」。
- Reduce Motion:輪 ・ 波紋を 止める(出てくる 時の 動きも なし)。

### 2-2. メールを かくす スイッチ

## 3. Name(はじめての 設定 01/04)
見本:モックの デモ `サインイン(Apple だけ)` → Apple → Name。

### 3-1. 何が わるかった か
- キーボードが 出ると 「アイコンの 写真」が かくれて、写真を えらべる ことが わからない。
- 「0 / 12」が「つぎへ」に かさなって いた。

### 3-2. あたらしい 並び(上から)
| | キーボード なし | キーボード あり |
|---|---|---|
| `01 / 04 YOU` | 上 | 上 |
| チェキ(見本)| 0.84倍 | **0.4倍**(小さく 上へ)|
| `Name` + 説明 | 64pt | 38pt |
| **アイコンの 写真の 行** | 丸 76pt | **丸 60pt ・ かくさない** |
| なまえの 入力 | 高さ 60 | 高さ 50 |
| つぎへ | 下 | **キーボードの すぐ 上** |

- アイコンの 写真の 行は **行 ぜんぶが ボタン**(うすい 面 `白 5%` ・ 角丸 18 ・ 中の 余白 8/10)。字:「**アイコンの 写真**」/「タップして えらぶ ・ あとで かえられます」。
- 「2 / 12」の 字数は **入力の 線の 中の 右下**(11pt ・ Space Mono ・ 白 40%)。キーボード 中も 出す。
- 作り方:`VStack` で 並べる(`offset` ・ 決めうちの 位置を 使わない)。キーボードは `safeAreaInset(.bottom)` + `@FocusState` で 上を 小さく(v95 の きまり)。チェキの 大きさは `scaleEffect` だけで 変える。

## 4. ID を かえる シート(空白を なくす)
- 今:シートが 画面の 上まで のびて、ルールの 3行と「保存」の 間に 大きな 空白。
- あたらしい:**シートの 高さ = 中身の 高さ**。中身は 上から `ID` + とじる ・ 「いま @…」・ 入力 ・ 判定の 1行 ・ ルール 3行 ・ **保存(ルールの すぐ 下 ・ 間 16pt)**。
- キーボードが 出たら **シートごと キーボードの すぐ 上**(間 8pt)。シートの 上は うすく 暗い 背景。
- 作り方:`Spacer()` を 消す → 中身の 高さを `onGeometryChange` で はかる → `.presentationDetents([.height(h)])`。キーボードで シートが 上がるのは システムに まかせる。
- 見本:モックの デモ `ID シート`(キーボードつき)。

## 5. 招待されて、来ましたか?(高さを 半分くらい)
- 今:シートが 画面 ぜんぶ ・ 3行と「ちがいます ・ このまま はじめる」の 間が 空白。
- あたらしい:**中身の 高さ**(とじた 状態で 画面の **約 48%** ≒ 400pt)。「ちがいます ・ このまま はじめる」は 3行の **すぐ 下**(間 6pt)。
- 行を ひらく(ペースト ・ コード ・ @ID)→ シートが その ぶん のびる(`.height(h)` を 毎回 はかりなおす ・ 動きは `.smooth`)。最大は `.large`。
- **ほかは かえない**(字 ・ 色 ・ 行の 中身は 今の まま)。見本:モックの デモ `招待シート`。

## 6. ウィジェット:先に えらぶ → ホームで 置く 案内 → 自動で たしかめる
### 6-1. できない こと(iOS の きまり)
- アプリから **ホーム画面へ 自動で 行く** ことは できない。
- アプリから **ウィジェットを 自動で 置く** ことも できない。
- だから:**アプリの 中の 動く 絵**で やり方を 見せる → 本人が ホームへ 行って 置く → **もどった 時に アプリが 自動で 気づく**。

### 6-2. 出す 場所
- はじめての 説明(v99)の **さいごに 1回 だけ**(v96 6章 と 同じ 場所)。
- ~~設定 › ウィジェット~~ → **v105 で 設定の 行は 消した**。設定 > サポート > **使いかた** の 中の「ウィジェット」から ひらく(PROMPT_v105 3章)。今の 3つの ステップの 画面は 消す。

### 6-3. シート「ウィジェット、置きますか?」(モック `ウィジェット(えらぶ)`)
- 説明:「ホーム画面に 置くと、撮りたくなる ・ 待ちたくなる。 1つ えらんで ください。」
- 4つから **1つ** えらぶ(ラジオ):`レンズ`(押すと すぐ 撮れる)・ `9:00 まで`(現像が ひらくまで)・ `友だちの 1枚`(きのうの 友だちを 1枚ずつ)・ `Mondo`(世界の きのうの お題)。左に 小さな 見本(52pt ・ 角丸 15)。初期は `レンズ`。
- えらんだ 行:ライムの ふち 2pt + うすい ライムの 面 + チェック。`sel` の バイブ。
- ボタン:**`ホームで 置く`**(ライム)/ `あとで ・ 設定から できます`(はじめての 時)・ `とじる`(設定から 来た 時)。
- 高さ = 中身(4章と 同じ 作り方)。

### 6-4. 案内(モック `ウィジェット(ホームで 置く)`)
- 全画面の **アプリの 中の 絵**(ホーム画面に にせた 黒い 画面 ・ アイコンは 灰色の 角丸 ・ Lattag だけ ライムの `#`)。**本物の ホーム画面と まちがえない** ように、上に 番号と 説明、下に ボタンを つねに 出す。
- 5つの 場面を 自動で 流す(合計 約 11秒 ・ 最後で 止まる):
  1. 「下から 上へ スワイプ」(白い 線が 上へ + ライムの 矢印)
  2. 「空いている 所を 長押し」(ライムの 丸が しぼむ → アイコンが ゆれる ・ 1秒で `thud`)
  3. 「左上の『+』を 押す」(`+` が ライムの 波紋)
  4. 「『Lattag』を さがす」(下から ギャラリー ・ 検索欄に `Lattag` が 1文字ずつ(`tick`)・ **えらんだ ウィジェット** が 大きく 出る)
  5. 「『ウィジェットを 追加』」(ボタンが 押される → ギャラリーが さがる → ホームの 左上に えらんだ ウィジェットが のる(4つの アイコンが 消える)・ `success`)
- 上:`1 / 5` ・ 説明(21pt 太字)・ 1行の 補足 ・ 5本の 線(すすんだ ぶん ライム)。
- 下:**`Lattag に もどる`**(ライム)・ `もういちど`(最初から)。
- Reduce Motion:自動で 流さない。場面ごとに 止まった 絵 +「つぎへ」。
- 作り方:SwiftUI の `PhaseAnimator`(場面 = enum)か `TimelineView`。動きは `offset` ・ `scaleEffect` ・ `opacity` ・ `rotationEffect` だけ。

### 6-5. 自動で たしかめる
- 案内を 出した あと、`scenePhase` が `.active` に もどった 時に `WidgetCenter.shared.getCurrentConfigurations` を よぶ。
  - Lattag の ウィジェットが 1つ 以上 ふえた → トースト「ウィジェットを 置けました」+ `success`。案内は とじる。
  - ふえて いない → 何も 出さない(しつこく しない)。案内の 画面に いれば「Lattag に もどる」で とじるだけ。
- 「Lattag に もどる」を 押した 時も 同じ 確認を する(置けて いない → トースト「あとで 設定 › ウィジェット から できます」)。
- 案内を 出すのは **はじめての 時 1回 だけ**(`@AppStorage("widgetOfferShown")`)。設定からは 何度でも。
- 置いた ウィジェットの 数 ・ 種類は **サーバーに おくらない**。

- 新しい 色を 作らない(ライム `#C8F25A` ・ 白 ・ 黒 ・ グレー だけ)。UI の 緑は 使わない。

## 8. 確かめる こと(実機で)
1. O04 に ボタンは Apple だけ。Google ・ メールの 字 ・ 画面が どこにも ない(`grep`)。
2. メールを かくす オン → Apple の 画面に メールの 選択が 出ない / オフ → 出る。
3. Apple で 入る → はじめて = Name / 前から いる = おかえり。Apple の 画面を とじる → 何も 出ない。
4. Name で キーボードを 出しても アイコンの 写真の 行が 見えて 押せる。字数が つぎへ に かさならない。
5. ID シート:保存が ルールの すぐ 下 ・ シートが キーボードの すぐ 上 ・ 上に 白い 空白が ない。
6. 招待シート:とじた 状態で 画面の 半分くらい。行を ひらくと のびる。
7. ウィジェット:えらぶ → 案内 → ホームで 本当に 置く → アプリに もどる → 「置けました」。置かずに もどる → 何も 出ない。
8. VoiceOver ・ Reduce Motion ・ 小さい 画面(iPhone SE)で 字が 切れない。
9. 単体テスト:メールの スイッチ → `requestedScopes` / ウィジェットの 確認(`WidgetCenter` を 差しかえて テスト)。
