# Lattag v64 ・ Home の カメラカードを「ぼかした 写真 + ガラス」に 作りなおす プロンプト

> アプリの 名前は **Lattag(レイタグ)**。`#` は つけません。
> これは **v63 の Home カード部分の 置きかえ** です。v63 の「黒い 台紙 + シール」(点の 模様 ・ 白い 丸の ボタン ・ キャラ ・ 紙の タグ)は **使いません**。
> **v63 の うち、そのまま 使う もの**:四すみ 4つ 固定の ルール、まんなかの 役わり(3枚 撮る まで Shoot)、横スライド、Home の 下の **Friends カード**(§12)、**PULL の ひもを 消す**(§12)、名前の ルール。
> ヘッダー ・「消灯まで」ピル ・ 下の 写真 ・「今日を撮る」の 月ボタン ・ ほかの 画面は さわりません。

---

## 0. ゴール と ルール

**ゴール**: 実機を `lattag_v61.html`(モック)と **見た目 ・ 動き ・ バイブ まで 同じ** にする。

**方針**(迷ったら ここに もどる)

- **壮大さは 文字の 大きさで 出さない**。写真の 空気 ・ 奥行き ・ 光で 出す(巨大な 文字は 使わない)。
- カードの 背景は **「みんなの 今日」= 友だちが 今日 撮った 写真を 大きく ぼかした もの**。まだ ひらかない 写真なので、**ぼかしに 意味が ある**(見えそうで 見えない)。
- ボタン ・ 四すみ ・ ピル ・ 目次は **すりガラス**(うしろの 写真が すけて 見える)に そろえる。
- **やらない こと**:色の グラデーションだけで 作った 光(AI っぽく 見える)、回る 文字、点の 模様、キャラ、黒い ふちの シール。光は **写真から 来る 色だけ**。フィルムの 粒子を のせて「本物の 写真」の 質感に する。
- 基調の 色は 今の まま(黒 `#0D0D0E` / 緑 `#24A03C` / ライム `#C8F25A` / 白)。ライムは **目次の 選択中** と **ピルの 点** だけ。

**ルール**

- モックと 見た目が 違ったら モックが 正解。数字は この 文章の 値を そのまま 使う。
- すでに 動いている 機能(撮影 ・ Yesterday ・ Mondo ・ Friends ・ Trip ・ 申請)は 壊さない。
- 書体:Inter / Instrument Serif / Space Mono(+ 日本語の 手書きは Klee One)。
- 先に 全部 読んで から 手を 動かす。わからない 所は `MockReference/mock/src/v61.js` と `v61.css` を 見る。

**見本(正解の 画像)**: `MockReference/screens/HomeMain/`

## 2. 作る もの の 構造(SwiftUI)

```
HomeMainBlock                       // 幅 = 画面の 幅(w)、高さ 600pt
 ├─ AmbientGlow                     // カードの 外へ にじむ 色(カードの うしろ)
 ├─ HomePager (横スライド)           // 5ページ
 │    ├─ Page0: CameraCard          // ← 主役
 │    └─ Page1〜4: Friends / Trip / Mondo / Yesterday(背景だけ 変える)
 └─ PageDock (目次)
```

**CameraCard(下から 順に 重ねる)**

1. `PhotoBackdrop`(ぼかした 写真 ×3、入れかえ)
2. `LightLeak`(右上の あたたかい 光の もれ)
3. `Vignette`(四すみと 上下の 影)
4. `Grain`(フィルムの 粒子)
5. `Flash`(撮る ときの 白い 光。ふだんは 透明)
6. タイトルと `Stickers`
7. `GlassShutter`(すりガラスの ボタン)
8. `GlassPill`(下の ピル)
9. `CornerButtons`(すりガラス ×4)

**座標の ルール**: 幅 390pt の 値。**ボタンの 中心 (w/2, 300) を 基準**。左右の 端に 合わせる 物は 端から の 距離。座標は **ブロックの 左上 = (0, 0)、390 × 600pt**。ブロックの 上は ピルの 下端 − 10pt。

## 3. PhotoBackdrop(ぼかした みんなの 今日)

**位置**: カードと 同じ(x 10、y 46、幅 w − 20、高さ 508、角丸 40)。中身は はみ出さない(クリップ)。地の 色 `#0D0D0E`。

**写真**

| 項目 | 値 |
|---|---|
| どの 写真 | **友だちが 今日 撮った 写真**(新しい 順に 3枚)。0人 / 0枚の ときは 自分の きのうの 写真 → それも ない ときは 地の 色 + 粒子だけ |
| 大きさ | カードより **16% ずつ 大きく**(ぼかしの ふちが 見えない ように) |
| ぼかし | **15pt**、彩度 **1.35倍**、明るさ **0.66** |
| 入れかえ | **7秒ごと** に 次の 写真へ。**1.8秒** かけて じわっと 重ねて 入れかえる(クロスフェード) |
| ゆっくり 動く | 1枚ずつ **18秒** かけて 拡大 1.04 → 1.18 + 少し 横へ(±2.5%)、行って もどる。3枚は 6秒ずつ ずらす |
| 押している 間 | ぼかし **15 → 5pt**、明るさ **0.76**(0.55秒、`cubic-bezier(.3,.7,.3,1)`)。**ピントが よる が、ひらく ほどは 見えない** |
| 3枚 撮りおわった | 写真が **ひらいた きのうの 3枚** に 変わる。ぼかし **9pt**、明るさ **0.62** |

> **大事(しくみ)**: まだ ひらかない 友だちの 写真は、**元の 写真を 端末に 送らない**。サーバー(Cloud Functions)で **幅 48px の 小さな サムネ**を 作って それだけ 渡し、端末で 引きのばして ぼかす。押して ぼかしが 弱まっても **48px より 細かくは 見えない**(9:00 前に 中身が わからない)。ひらいた あとは ふつうの サムネを 使う。

**重ねる もの**

| 部品 | 値 |
|---|---|
| `LightLeak` | 右上(カードの 外 34% 右 ・ 30% 上 から、幅 90% ・ 高さ 76% の だ円)。色 `#FFB070` 50% → 透明。**スクリーン 合成**。不透明度 0.18 ↔ 0.42 を **13秒** で ゆっくり 行き来、少し 左下へ ずれる |
| `Vignette` | だ円の 影(中心 50% ・ 42%、35〜38% まで 透明 → ふちで 黒 50%)+ 上 24% と 下 36% に 黒の グラデ(上 38% / 下 55%)。文字と 目次を 読ませる ため |
| `Grain` | フィルムの 粒子(ノイズ 160px の くり返し)。**オーバーレイ 合成、17%**。**0.9秒で 4コマ** だけ 位置を ずらす(パラパラ) |
| ふち | 内側に 白 16% の 線 1pt + 上に 白 18% の 線 1.5pt |

| 右上 | Trip | `TRIP` | ページ 2 へ スライド |
| 左下 | Mondo | `MONDO` | ページ 3 へ スライド |

- 位置(丸の 中心):

| 位置 | x | y |
|---|---|---|
| 左上 | **62**(左端から) | **154** |
| 右上 | **w − 62**(右端から) | **154** |
| 左下 | **62** | **436** |
| 右下 | **w − 62** | **436** |

- ラベルの 上端 = 丸の 下端 + 6pt(左上・右上は y 191、左下・右下は y 473)。

**状態**

| 状態 | 見た目 |
|---|---|
| ふつう | 上の とおり(白い 丸) |

**タップ**

1. 押した 瞬間: 丸が 小さく なる + バイブ `click`。
2. 離した とき: アイコンだけ **scale 1 → 0.84 → 1.1 → 1**(**0.38秒**、`cubic-bezier(.3, 1.6, .4, 1)`)。
3. **0.12秒 後** に そのページへ スライド(§9)。
4. **ロック中の Yesterday / Mondo を 押した とき も 同じ**(スライド する)。その ページが「ぼかした 中身 + 鍵 + **Shoot first** ボタン」を 見せる ので、なにを すれば ひらくかが その場で わかる。警告の バイブや トーストは 出さない。

**登場の 動き(Home に 入った とき)**: 4つが **レンズの 中心 から 外へ ポンと 飛び出す**。

- 途中(70% 地点): 席に 着く 手前で **scale 1.14、+8°**、見えている。
- 終わり: 元の 形(回転 0、scale 1)。
- 長さ **0.76秒**、カーブ `cubic-bezier(.3, 1.1, .4, 1)`。順番は 左上 → 右上 → 左下 → 右下 で、**0.18秒 後から 0.09秒 ずつ ずらす**。
- 席に 着く 直前(各 ボタンの 開始から 0.52秒 後)に バイブ `tick`(ポン)。

## 9. 横スライド(いちばん 大事な 仕組み)

**ページ(左から 順に)**: `0 Camera` → `1 Friends` → `2 Trip` → `3 Mondo` → `4 Yesterday`。

**ふるまい**

- 指で **横に はらう** と 次の ページへ。**縦に スクロール すると 今まで どおり 下の 写真へ**(縦と 横を 取りちがえない)。
- 横と みなす 条件: **横に 8pt 以上 動き、かつ 横が 縦の 1.2倍 より 大きい**。縦に 10pt 先に 動いたら 横は あきらめる。
- 端(0 と 4)を こえて ひっぱる と **ゴムの ように 重く なる**(動きの 35% だけ 進む)。端で はなすと バイブ `soft`。
- はなした とき の きまり方: `次の ページ = round(−(今の 位置 + 速さ × 160) / 幅)`。ただし **1回で 動けるのは ±1ページ まで**。
- ばね の 動き: 硬さ **0.0009**、減衰 **0.05**(モックの 物理)。SwiftUI なら `.spring(response: 0.42, dampingFraction: 0.82)` を 目安に、モックと 並べて 合わせる。
- 速さ(フリック)が あれば その 勢いを 引きつぐ。

**3D の 見え方(動いて いる 間)**

- 中心から の 距離 `d`(ページ数)に 対して:
  - 回転: **Y軸 −d × 14°**(`perspective 900`)
  - 拡大: `1 − 0.08 × min(1, |d|)`
  - 透明度: `1 − 0.45 × min(1, |d|)`
- 止まったら すべて 元の 形(回転 0、scale 1、透明度 1)。

**ページが 変わった とき**

- バイブ `sel`(コツッ)。
- ナビピルの 光る ボタンが うつる(§10)。
- 新しい ページの 中身が **下から ふわっと 入る**:各 パーツ `translateY 18pt → 0`、透明度 0 → 1、**0.48秒**、`cubic-bezier(.3, 1.35, .5, 1)`、**120ms 後から 60ms ずつ ずらす**。入り始めの 260ms 後に バイブ `tick`。
- カメラ(ページ 0)に もどる ときは この 入場 アニメは しない。

**実装の メモ**

- `ScrollView(.horizontal)` + `.scrollTargetBehavior(.paging)` + `.scrollTransition` で 3D を つける のが 簡単。足りない ときは `DragGesture` で 自作して よい(モックの 数値に 合わせる)。
- 親の 縦 `ScrollView` と ぶつかる ので、`simultaneousGesture` を 使い、**方向の 判定は 上の 条件**で そろえる。
- 「ほかの ページに いる 間 は、カメラの 位置を 測りなおさない」(四すみボタンの 位置が ずれる 原因)。
- 外の 縦スクロールの 動き(カードが 上へ 流れて 薄く なる 視差)は **ページ 全体に かける**(いままでの 動きを 引きつぐ)。

## 16. 実装メモ(重さ ・ 安全 ・ 小さい 端末 ・ アクセシビリティ)

- **ぼかしは 重い**。うしろの 写真は **48px の サムネを 端末で 1回だけ ぼかして 画像に する**(`CIGaussianBlur` を 縮めた 画像に かけて キャッシュ)。毎フレーム ぼかさない。押した 間の「ピントが よる」は、**ぼかし 15 と 5 の 2枚を 先に 作って クロスフェード** する。
- **ガラス**:iOS 26 は `.glassEffect()`(`GlassEffectContainer` で 四すみ ・ ピル ・ ボタンを まとめる)、iOS 18 以前は `.ultraThinMaterial` + 白 10〜14% + 上の 白い 線。
- **安全**:ひらく 前の 友だちの 写真は **48px の サムネしか 端末に 来ない**(§3)。Storage の ルールで、元の 写真は 9:00 まで 読めない ことを 必ず 守る。
- **粒子**:ノイズの 画像 1枚(160px)を くり返し 貼り、`TimelineView(.periodic(by: 0.225))` で 4か所 だけ ずらす。
- **外へ にじむ 色**:同じ サムネを ぼかし 40 で。Home の 昼の 白い 地の 上で 濃すぎない こと(不透明度 0.62)。
- **ページ外 ・ 背面**:くり返しの アニメ(入れかえ ・ 寄る ・ 光 ・ 粒子 ・ すじ)を 止める。入れかえは ページ 0 に いる ときだけ。
- **小さい 端末**(幅 375):ボタン(215)は 固定。四すみ ・ ステッカーは 端から の 距離。ピルは 四すみの 丸の 間に 収める(字 16pt まで 下げて よい)。
- **Dynamic Type**:ラベル ・ ボタン ・ ピルの 文字は 固定の 大きさ。
- **VoiceOver**:まんなかは「撮る。あと N 枚」/「Yesterday を ひらく」。ピルは「あした 9 時に ひらきます」/「N 枚 現像中。現像を 見る」。うしろの 写真 ・ 粒子 ・ 光 ・ ステッカーは 読まない。
- **Reduce Motion**:入れかえ ・ 寄る ・ 光の もれ ・ 粒子の 動き ・ 光の すじ ・ ふわふわ ・ 3D の かたむきを 止める(写真は 1枚目で 止める)。押した ときの 縮みと ピントは 残す。
- **透明度を 下げる**(Reduce Transparency)が オン:ガラスを **黒 70%** の 不透明に、うしろの 写真の 明るさを 0.5 に。
