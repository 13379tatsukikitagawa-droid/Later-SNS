## 2. 暗室(Home を 下に スクロール)の ACTIVE

### Trip の カード

- 大きさ: 196 × 248 ・ 角丸 24(今の ACTIVE カードと 同じ)。
- 表紙の 写真を 全面に 敷き、下に 向かって 黒く(上 45% → 0 → 下 92%)。
- 上から 順に:
  - `DAY 2 / 3`(Space Mono 8.5pt)。右上に 未読 数(赤い 丸)。
  - 下に よせて 行き先 `Kyoto`(Instrument Serif 36pt)
  - `京都 2泊3日`(Space Mono 9pt)
  - **23こまの フィルム**(こまの 高さ 18、番号は 出さない)
  - `7/23`(数字は Instrument Serif 22pt)
- 押すと Trip の チャット(部屋)へ。

### New trip の カード

- 大きさ: 幅 170 ・ #0E0E0F ・ 細い 線の 枠。
- 真ん中に 旅の 写真 3枚を チェキの 扇に 小さく 重ねる。下に 紙色の 丸い `+`。
- その下に `New trip`(Instrument Serif 24pt)と `旅行 ・ 合宿 ・ イベント`。
- 白い 丸だけの 古い `+` カードは やめる。

## 3. Today の カードの 位置(モックの 不具合を 直した)

- 暗室の `Today 0/3` の カードは、緑 → 黒の グラデの 中に 置く。その **下に** ACTIVE が 続く(重ならない)。
- 横スライドの ページの 文字と、名前(クラス名・View 名)が ぶつからない ように する。モックでは Trip ページの 文字に Today の カードと 同じ 名前を つけてしまい、Today の カードが ずれていた。

## 4. 完了の 条件

- 上の 6つの 入口の どれから 押しても、v58 の New trip 画面が 開く。古い グループ作成の 画面は もう 出ない。
- 暗室の ACTIVE に、Trip が 表紙 ・ 行き先 ・ フィルム ・ `7/23` の 形で 並び、最後が 新しい `New trip` の カードに なっている。
- Today の カードと ACTIVE が 重ならない。
