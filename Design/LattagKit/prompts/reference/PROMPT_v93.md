### 3-5. バイブ(**だんだん 細かく 強く**)
- `CHHapticEngine` で **1つの パターンを 作って 1回 再生**(毎コマ 鳴らさない):
  ```swift
  // continuous:長さ = 現像の 秒数。強さ 0.15 → 0.75 ・ するどさ 0.2 → 0.6(CHHapticParameterCurve)
  // transient:間かくを 230ms → 60ms に だんだん つめる。強さ 0.35 → 0.8(前半 tick ・ 後半 sel 相当)
  // おわり:heart(2回 ドクン)→ 0.16秒 後 success
  // 横に めくった / 画面を とじた → player.stop(atTime: CHHapticTimeImmediate)
  ```
- モックの `hap('tick')` → `hap('sel')` → `hap('heart')` → `hap('success')` と 同じ 順。
- `CHHapticEngine` が 使えない 端末:`UIImpactFeedbackGenerator(style: .light)` を **1つ だけ 作って** prepare して 使う。
