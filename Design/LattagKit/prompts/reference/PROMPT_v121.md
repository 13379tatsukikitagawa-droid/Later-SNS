## 0. 考え方
- 「ポップ」= 色 ・ 丸 ・ チェキ。「おしゃれ」= **平らな 色 ・ そろった 形 ・ 動きは 押した 時 だけ**。
- つや(グラデーション ・ 光の だ円)と、ずっと うごく 動き は やめる(子どもっぽく 見える + 電池を 使う)。
- 押せる 物は ぜんぶ 同じ 手ざわり:**下に 色の 段(だん)が あり、押すと 4〜5pt しずむ**(`offset` + 段の 高さ)。バイブ `pop`。

## 1. Home の 丸 3つ(v120 1章を 上書き)
- 丸 72pt ・ **平らな 色**(友だち `#FF9CC8` ・ Trip `#7CCBFF` ・ きのう `#FFD84D`)・ 上の ふちに 白い 線(内がわ 2pt ・ 白 50%)。
- ふち ミルク `#FAFAF7` 3.5pt。その 下に **色の 段 7pt**(その 色 + 黒 34%)。やわらかい 影 `0 22 26 -12 / 75%`。
- かたむき なし ・ うく 動き なし。**押すと 5pt しずむ**(段 7 → 2pt ・ 0.16秒 ・ ばね)。
- 絵 30pt(線 2.2)・ 名前 13.5pt 太字 `#E9E9EC`(丸の 16pt 下)。バッジ 24pt ・ ミルクの ふち 3pt。
- 小さな 列(v120 2章)の 丸も 同じ 形(46pt ・ 段 4pt ・ 押すと 3pt)。

## 2. Today(v119 2章の 3枠 と 大きさを 上書き)
- カード:内がわ 22 / 20pt ・ `Today` 38pt ・ `1/3` 36 / 21pt ・ 状態の 行 13pt。
- **3枠は 高さ 126pt ・ 間 14pt**(前は たて長 178pt で すかすか だった)。
  - **撮った 枠 = チェキ**:ミルクの 紙(角丸 7)・ 写真は 上 6 / 横 6 / 下 24 の 内がわ ・ 下の 白い 所の 左に 時間(10pt 太字 ・ 黒)、右に 現像の %(10pt ・ 灰色)。少し かたむける(-2.2° / +1.6° / -1.2°)。現像の ぼかし ・ 白い まくは 今の まま(写真の 所 だけ)。
  - **次の 枠 = ライムの ボタン**(角丸 20 ・ 高さ 120 ・ 段 6pt `#97C235`)。`+`(30pt ・ 黒 ・ 線 2.6)+「撮る」15pt 太字 黒。押すと 4pt しずむ → 撮影へ。**Today の かたまりの ライムは これ 1つ**。
  - **空きの 枠**:点線(1.5pt ・ 白 16%)+ まんなかに うすい セリフの 数字(`2` `3` ・ 30pt ・ 白 16%)。
- 進みの 線:太さ 6pt ・ 角丸 ・ つまみ 14pt(まわりに カードの 色の ふち 3pt)。上の 間 24pt。
- 下の 字 12.5pt(「09:12 に 撮った」/「あと 20h 40m で ひらく」)。

## 3. Friends の まんなか = マイカード(v119 3章の「まんなか 2つ」を 上書き)
- 参考に した 形:Instagram の「プロフィールを シェア」、Snapchat の 自分の コード、BeReal の 招待リンク = **自分の 名前 + コード + 送る ボタンが 1枚に まとまって いる**。
- 1枚の カード(角丸 28 ・ `#202024 → #17171A` の ななめ グラデーション ・ ふち 白 7% ・ 内がわ 16)。横に 2つ:
  - 左(128pt):**QR の チェキ**(-2.5° ・ 上に ピンクの テープ)。下の 白い 所に「タップで 大きく」11.5pt 灰色。押すと 自分の QR 画面。
  - 右:上に **自分の 丸い 写真(40pt ・ ミルクの ふち 2pt)+ 名前(16pt 太字)+ @ID(12pt 灰色)**。下に **ライムの ボタン「リンクを 送る」**(高さ 52 ・ 角丸 26 ・ 共有の 絵 19pt ・ 15.5pt 太字 ・ 段 5pt `#97C235`)。その 下に「LINE ・ AirDrop ・ インスタ」11.5pt 灰色。
- 申請の 行(上)と「QR を 読む」「ID で さがす」(下)は v119 の まま。
- 名前 ・ @ID は 1行(長い 時は `…`)。行き先は 今と 同じ(v95)。
