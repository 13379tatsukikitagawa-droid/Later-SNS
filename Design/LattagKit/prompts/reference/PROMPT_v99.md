## 4. Swift の 作り方(目安)
- `IntroStoryView(kind:)` 1つ + `IntroScene` の 配列(`label` ・ `line` ・ `view` ・ `haptics: [(TimeInterval, HapticKind)]`)。3つの 説明は **データを 変える だけ**。
- 場面の 動きは `PhaseAnimator` / `keyframeAnimator`(`scaleEffect` ・ `offset` ・ `opacity` ・ `rotationEffect` だけ)。裏がえしは `rotation3DEffect` で よいが、**表 / 裏の 入れかえは 不透明度で**(`backface` に たよらない)。
- 進み具合と 自動送りは **1つの `TimelineView(.animation)`** の 時間から 計算(場面ごとの タイマーを 作らない)。一時停止は その 時計を 止める だけ。
- 写真は 見本の 6枚 を アセットに(本番の 友だち写真は 使わない ・ 説明は いつも 同じ 絵)。人は 名前の 1文字 + 色の 丸。
- `fullScreenCover`(下へ スワイプ = `.interactiveDismissDisabled(false)`)。最後の ボタンは `dismiss` → 0.28秒 後に 行き先へ。
- 重さ:地球の 点は 1枚の 画像を 横に 動かす(`Canvas` で 毎コマ 描かない)。ぼかしは 1回 作った 画像を 使う(v68 / v93)。
