## 2. 地球(点で できた 球)

- 位置:カードの 左上 から (112, 128) に **310 × 310pt** の 描画 範囲。地球の 半径 **124pt**、中心は (267, 283)。**右は カードの 外へ はみ出して 切れる**(大きさを 感じさせる)。
- 描き方(SwiftUI は `Canvas` + `TimelineView(.animation)`、または Metal):
  - **球の 地**:放射グラデ(左上 `#13301F` → `#050A07`)+ ふちに 緑の 線(`#7EE08F` 45%、1pt)。
  - **大気**:球の 外側 92% → 118% に 緑の 光(`rgba(80,220,120)` 42% → 0)。ふちだけ。
  - **点**:球の 表面に 約 2,800 点(フィボナッチ球)。陸か 海かは **本物の 海岸線データ**(Natural Earth 110m など)で 決める(モックは 計算で 作った 形)。
    - 昼の 陸:**紙色 `#F5F3EC`**、大きさ 2.7pt、明るさ = 0.35 + 太陽の 当たり × 0.6。
    - 夜の 陸:暗い 点(13%)。**街の 灯り**(陸の 約 17%)は **ライム `#C8F25A`** 2pt。
    - 海:1pt の とても うすい 点(昼 7% / 夜 3.5%)。
    - 奥に 行く ほど うすく(手前 100% → ふち 35%)。
  - 傾き 0.38 rad。太陽は 画面に 対して 固定(正面 やや 右)。**地球だけが 回る**(1周 約 65秒)。
- **9:00 の 線**:その 場所の 時刻が **朝 9:00** に なる 経線。太陽の 位置 − 45°。**ライムの 点線**(1.6pt、点 2 ・ 間 4)+ ライムの 光(ぼかし 8)。地球が 回るので、街が この 線を **横切って いく**。
- **街の 点**:12都市(東京 ・ ソウル ・ シドニー ・ ドバイ ・ パリ ・ ロンドン ・ ラゴス ・ サンパウロ ・ ニューヨーク ・ メキシコシティ ・ ロサンゼルス ・ ホノルル)。白い 点 2pt。**9:00 の 線の 上(±5°)に いる 街は ライム 3.2pt + 輪が 広がる**(1.4秒ごと、3 → 17pt、消える)。
- **浮かぶ チェキ**:4都市(東京 ・ パリ ・ サンパウロ ・ ニューヨーク)の 上に、きのうの 写真の 小さな チェキ(**34 × 40pt**、紙色の ふち、下に 細い 白い 糸)。地球に ついて 動き、手前ほど 大きく(0.62 〜 1.12倍)、裏側では 消える。左右の 位置で 少し 傾く(±8°)。
  - **撮る まえ**:写真は **ぼかし 3.5pt + 彩度 0.6**(ひらく 前は 見えない)。サーバーの **48px サムネ** だけ 使う(v64 の ルール)。
- **地球を タップ**:ぐるっと 速く 回って ゆっくり 戻る(速さ +0.06 → 毎フレーム 95% に)。バイブ `soft`。
- **このページを 見て いない とき は 描かない**(電池)。Reduce Motion:回さない(止まった 地球)。

## 3. 人気の タグ(左)

- 幅 **184pt**、3行、間 8pt、サブの 下 22pt。地球に 少し 重なる(ガラスなので すける)。
- 1行:高さ **44**、角丸 16、**すりガラス**(白 8% + ぼかし 14pt、内側に 白 14% の 線 + 上に 白 18% の 線)。1位だけ ライム 16% + ライム 45% の 線。
  - 左:順位 `01` `02` `03`(Instrument Serif 24pt、1位は ライム、ほかは 白 55%)。
  - まん中:タグ(Inter 800 15pt、白)。
  - 右:**光の 強さ**(5本の 細い 棒 3pt、高さ 5 / 8 / 11 / 14 / 11pt、ライム。1位 5本 ・ 2位 4本 ・ 3位 3本 が 光る)。**数字は 出さない**。
  - 光の すじが 4.8秒ごとに 行の 上を 通る(行ごとに 0.25秒 ずらす)。
- **撮る まえ**:タグの 字を **ぼかし 5pt**、棒の かわりに 小さな 鍵(14pt)。

## 4. いま 9:00 の 街

- タグの 下。高さ **32**、角丸 16、黒 35% + ぼかし 12pt、ライム 35% の 線。
- 「● **NOW 9:00** · LONDON」(Space Mono 700 10pt、字間 0.12em。NOW 9:00 は ライム、街の 名前は 白)。点は 2.2秒ごとに 輪が 広がる。
- 9:00 の 線に いちばん 近い 街が 変わったら、名前が 下から ふわっと 入れかわる(0.5秒)+ バイブ `tick`(このページを 見て いる とき だけ、0.4秒 以内は 鳴らさない)。
- 実機では、街の 名前は **実際に 今 9:00 を むかえた 都市**(タイムゾーンの 一覧から)。
