## 0. なぜ 直すか(v118 を 見て 気づいた こと)
1. 「リンクを 送る」が カードから はみ出して いた。
2. かざりが 多すぎた(テープ ・ 星 ・ かたむき ・ 明朝 ・ ライム ・ ピンク が 1か所に)。
3. Today の カードが すけて、うしろの 丸い ボタンが 見えて いた。
4. Home の 下に **むかしの 緑** と **Mondo**(v110 で なくした)が のこって いた。
5. 小さな 字が 英語と 日本語で まざって いた。
6. Friends は カード、Trip は カードの 外に 見出し、と 形が そろって いなかった。

## 1. 6つの きまり(アプリ ぜんぶに 使う)
1. **セリフ(明朝)は タイトル ・ 名前 ・ 大きな 数字 だけ**。押す 物(ボタン ・ カードの 名前)の 字は ゴシックの 太字。
2. **かたむけて いいのは 写真(チェキ)と 紙(NEXT)と Home の 丸 だけ**。ボタンと カードは まっすぐ。
3. **ライムの 面は 1つの かたまりに 1つ**(いちばん 押して ほしい 物)。
4. **かざり(テープ ・ ステッカー)は 1つの かたまりに 1つ まで**。
5. **大きな タイトルは 英語**(Today / Friends / Trip / Yesterday / New trip)、**説明と 小さな 字は 日本語**。日付の 大きな 字(`Nov 20`)は 英語の まま、小さな 日付は `11/20`。
6. **かたまりは 同じ 形**:カード(`#111113` ・ 角丸 32 ・ ふち 白 7%)の 中に、左に タイトル(36pt セリフ)+ 下に 説明 1行(12.5pt)、右に 丸い → (44pt ・ `#1F1F23`)か 数。中の 部品は 角丸 22〜28 ・ `#1A1A1D`。字は ぜんぶ 1行。

## 2. Today の カード
- 背景は **すけない**(`#121014` ・ ぼかし なし)。角丸 32。
- `Today` 36pt セリフ ・ 右の `1/3` も セリフ(34 / 20pt)。
- むかしの 緑(点 ・ 線 ・ 「ひらく」の 字)→ **ライム**。
- 字:`DEVELOPING · NOV 21` → `現像中 ・ 11/21`(0枚は `まだ 0枚 ・ 11/21`)・ `SHOOT` → `撮る` ・ `09:12 shot` → `09:12 に 撮った` ・ `opens 9:00 · 3h 30m` → `あと 3h 30m で ひらく` ・ `lights out · 24:00` → `消灯 24:00`。

## 3. Friends の かたまり(v118 3章を 上書き)
- 上:`Friends` 36pt + 説明 1行 + 右に 丸い →。
- 申請の 行(高さ 60 ・ 角丸 22 ・ `#1A1A1D`):丸い 写真(34pt ・ 重ねる)・ 名前(14.5pt 太字)+「友だちに なりたい」・ 右に **ピンクの ボタン「確認」**(高さ 40)。
- まんなか 2つ(同じ 幅 ・ 間 12 ・ 高さは そろえる):
  - **リンクを 送る**:ライムの カード(**まっすぐ** ・ 角丸 28)。左上に 黒い 丸(48)+ 共有の 絵、右上に 小さな →、下に「リンクを 送る」(**19pt ゴシック 太字** ・ 1行)+「LINE ・ AirDrop」。テープ ・ 星は なし。
  - **QR を 見せる**:白い チェキ(+2° ・ 上に ピンクの テープ 1つ)。中に 本物の QR、下に「QR を 見せる」13pt。
- 下 2つ(同じ 幅 ・ 高さ 56 ・ 角丸 22):「QR を 読む」・「ID で さがす」。
- はじめて 出る 時:下から 14pt + ふわっと(60ms ずつ)。押すと 0.94〜0.97 → ばね。

## 4. Trip の かたまり(v118 4章を 上書き)
- Friends と **同じ 形の カード**:`Trip` 36pt + 「旅行 ・ 合宿 ・ イベントを みんなで」+ 右に 丸い →(Trip の ページへ)。斜体 ・ 色つきの 字は やめる。
- 0件:カードの 中に New trip の 行(高さ 112 ・ 角丸 24 ・ `#1A1A1D`)。左に チェキ 3枚、`New trip` 28pt セリフ +「2〜7日の アルバムを つくる」、右に 空色の + の 丸(46)。
- ある 時:カードの 中で 横スクロール(今の カード)。

## 5. きのう ・ アルバム ・ この日
- 小さな 見出し:`YESTERDAY` → `きのう` ・ `FRI` → `金曜日` ・ `ALBUMS` → `アルバム` ・ `7 DAYS · RECAP ›` → `7日で 消える ・ まとめ ›` ・ `ON THIS DAY` → `この日` ・ `1 MONTH AGO` → `1か月 前`。12.5pt 太字 ・ 灰色(等幅の 字 ・ 広い 字の 間は やめる)。
- きのうの カード:`Moments` → `枚` ・ `6d / Left` → `6日 / のこり` ・ `People ›` → `人 ›` ・ 小さな 日付 `NOV 20` → `11/20` ・ `you.` → `わたし.`。
- **`Mondo` の ボタン → 「きのうを ひらく」**(きのうの 画面へ)。**MONDO の 列(TOP 5)は 消す**(v110 の とりこぼし)。
- アルバムの 行:`6D LEFT · FRI` → `あと 6日 ・ 金` ・ `GOES TOMORROW` → `あした 消える` ・ `335 days left` → `あと 335日`。緑 → ライム。
