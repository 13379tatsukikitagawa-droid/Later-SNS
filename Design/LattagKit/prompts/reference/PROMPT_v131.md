## 0. なぜ
- 「撮る」が いちばん 大事なのに、いちばん 大きな # の レンズが 押せなかった。→ **レンズ = 撮る ボタン**。
- アイコンの ボタンは「押すと 何が あるか」が わからない。→ **中身(写真 ・ 申請 ・ Trip の 日 ・ 9:00)が 見える カード**に(Instagram の ストーリーの 考え方)。

## 1. # の レンズ
- 大きさ **1.14 倍**(230 → 262pt)・ 18pt 下へ。押すと **撮影へ**(`shutter` の バイブ)・ 押して いる 間 1.09 倍。
- レンズの 下(NEXT の 上)に ライムの 小さな 札 **「タップで 撮る」**(11.5pt 太字 ・ 黒い ふち 3pt)。
- NEXT は 上から 454pt(レンズと 重ならない)。

## 2. 写真の カード 3枚(NEXT の 下)
- 3列 ・ 間 10 ・ 左右 16。1枚 **約 113×120pt ・ 角丸 24**・ ふち 白 12%(1pt)。いま ひらいて いる ページの カードは その 色の ふち 2pt。
- 中は **写真(全面)+ 下に 向かって 黒く**(25% → 82%)。
- 左下に **英語の 大きな 字(セリフ ・ Instrument Serif)**、その 下に 色の 点 + 日本語 1行(10.5pt 太字)。字は 1行に おさめる(入らない 時は 16pt まで 小さく)。

| カード | 写真 | 大きな 字 | 1行 | 左上 / 右上 |
|---|---|---|---|---|
| 友だち(ピンク) | 友だちの アイコン写真(いなければ 見本)+ ピンクを うすく 重ねる | **Friends**(34pt) | 「2人 から 申請」/「3人 撮った」/「まだ だれも」/「よんで みよう」 | 申請した 人 か 友だちの 丸(24pt ・ 3人)/ 申請の 数(赤) |
| Trip(空色) | いまの Trip の 表紙(なければ 見本) | **Trip**(46pt) | 「大阪 ・ いま」/「つくる」 | — / `DAY 3 / 3`(黒い 札 ・ 空色の 字) |
| きのう(黄色) | きのうの 1枚 | **Yesterday**(30pt) | 「ひらいた」/「9:00 に ひらく」 | 9:00 まえ は **ぼかし + まんなかに 鍵** |
- **9:00 まえに 友だちの 本物の 写真を はっきり 出さない**(きのうの カードは ぼかし ・ 友だちの カードは アイコン写真 だけ)。
- 行き先:Friends = 友だちの ページ ・ Trip = Trip の ページ ・ Yesterday = きのうの 画面(今の 3つの ボタンと 同じ)。押すと 0.95 → ばね ・ `pop`。
- 写真の サムネは 1回 作って キャッシュ(毎回 読みこまない)。

## 3. スクロール した 時
- 150pt より 下で カード 3枚は 消え、下に 小さな 列(v120)。小さな 列の 丸は **黒(`#1C1C1F` ・ 白 12% の ふち)+ その 色の 絵**(オーラは 使わない)。

## 4. 作らない もの
- オーラ ・ タイル ・ ニュース などの ほかの 案(モックの デモ だけ)。
