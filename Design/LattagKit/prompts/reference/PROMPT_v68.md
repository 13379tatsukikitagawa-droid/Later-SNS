## 3. Shake モード(`openShake` ・ `#shk`)

**入り方**:Friends の ふる カード / Add シートの Shake / **Friends 画面で 本当に スマホを ふる**。全画面 ・ 黒。

### 3-1. 画面(390 × 844)

- 地:黒 + 緑の 光(`radial 60%×42% at 50% 40% rgba(36,160,60,.42)`)+ 左下に 黄緑 14% + 粒子。
- 左上:× の ガラスの 丸 44(x18 ・ y58)。上の まんなか:`Shake`(Instrument Serif Italic 24 ・ y66)。
- まんなか(x195 ・ y330):輪 4本(直径 190 / 290 / 390 / 500 ・ 白 12% → 5%)。**自分の 写真の 丸 116**(白い ふち 3)。黄緑の 輪が 丸から 4.2倍に ひろがる(2.6秒 ・ 3本を ずらす)。丸は ゆっくり 息を する(1 ↔ 1.04 ・ 2.6秒)。
- y478:スマホの 印(44 ・ ぶるっと ゆれる)。y560:「**スマホを ふって**」(Inter 900 30)+「となりの 友だちも いっしょに」(15 ・ 白72%)。
- 下:「ふった 人 どうし だけに 見えます」(12 ・ 白50% ・ 下から 112)。いちばん 下に `QR で つながる` / `ID で さがす`(高さ 50 ・ ガラス ・ 下から 44)。

### 3-2. 5つの 状態

| 状態 | 画面 | 時間 | バイブ |
|---|---|---|---|
| `idle` ふる まえ | 3-1 | — | 入る とき `sel` |
| `seek` さがす | 字「さがして います…」「そのまま ちかくに」。丸が こまかく ふるえる(±5pt ・ ±7° ・ 0.16秒)。輪は 0.9秒に 速く。**黄緑の レーダー**(conic ・ 1.1秒で 1回転) | 約 1.5秒 | `buzz` → `tick` ×6(だんだん 速く:140 / 300 / 440 / 560 / 660 / 740ms) |
| `found` 見つけた | 相手の 写真の 丸が **上から 落ちて きて**(-470pt ・ 0.7倍 → 位置)自分の 丸の 左に 重なる(中心の 間 88pt ・ 28pt 重なる。2つの 丸は 58pt 上へ = 中心 y272)。0.43秒後に **白い 光 22%**(0.42秒)+ **白い 波紋**(0.9 → 6倍 ・ 0.9秒)+ 丸 ぜんたいが 1 → 1.08 → 1。うしろが 相手の 写真の ぼかし(30 ・ 明るさ 0.46)に 変わる。字「**見つけた**」(34)「ちかくで いっしょに ふった 人」。下から **カード**(ガラス ・ 角丸 38 ・ 0.7秒 ばね):名前(Noto Serif JP Bold 40)・ `@id`(Space Mono 11)・ ハッシュタグの シール 2〜3枚(ぽん と 出る)・ **つながる**(黄緑 ・ 高さ 58)・ `ちがう人` ・ 「ふたりとも『つながる』を 押すと 友だちに なります」 | 丸 0.75秒 ばね `(.3,1.35,.4,1)` | 0.43秒 `thud` → 0.62秒 `success` |

| `none` 見つからない | 「見つからなかった」「もう いちど、いっしょに ふって みて」。2.6秒で `idle` へ | 8秒 待って だめなら | `warn` |

- 見本:`K01〜K06`、コマ割り `motion/M15_shake_connect.png`。モックでは まんなかの 丸を 押すと「ふった」ことに なる(**実機に 作らない**:`DEMO` の 字 ・ 丸の タップ)。

### 3-3. 本物の しくみ(実機)

1. **ふった ことを 知る**:`CMMotionManager` の 加速度(50Hz)。大きさが 2.2G を 0.65秒 以内に 2回 こえたら「ふった」。Shake モードの 間 だけ 動かす(とじたら 止める)。Friends 画面では UIKit の `motionEnded(.motionShake)` でも 入口に する。
2. **ちかくに いる ことを 確かめる**(位置情報は 使わない):Shake モードの 間 だけ `MultipeerConnectivity`(サービス名 `lattag-shake`)で **1回きりの 合言葉**(乱数 16バイト。ユーザー ID は 流さない)を 出す + 聞く。
3. **サーバーで 合わせる**(Cloud Functions `shakeMatch`):ふった 時刻 ・ 自分の 合言葉 ・ 聞こえた 合言葉を 送る。**2秒 以内に ふった 2人で、おたがいの 合言葉が 聞こえて いる** ときだけ 相手の 名前 ・ ID ・ 写真の サムネ ・ タグを 返す。記録は 10秒で 消す。
4. **ふたりとも「つながる」**(`shakeConfirm`):60秒 以内に 両方 押したら、申請を とばして 友だちに する。片方 だけ → ふつうの 申請として 残す。
5. **安全**:もう 友だち →「もう 友だち です」。ブロックした 人は 出さない。3人 以上が 同時 → 丸を 5つまで 並べて「だれと つながる?」。10分に 20回まで。ふって いない 人には 何も 見えない。
6. **許可**:`NSLocalNetworkUsageDescription`「ちかくで いっしょに ふった 友だちを 見つける ために 使います」・ `NSBonjourServices`(`_lattag-shake._tcp`)・ `NSBluetoothAlwaysUsageDescription`。ことわられたら「QR で つながる」を 大きく 出す(位置情報での 代わりは 作らない)。
7. サーバーが まだ の 間:画面と 動き だけ 作り、DEBUG の 状態メニューで 見本の 相手を 出す。

| `contentTransition(.numericText())` | 「きょう 2人が 撮った」の 数字 | そのまま |

## 5. 重く しない ための 決まり(P11 と 同じ ・ 必ず 守る)

- **ぼかしは 毎フレーム 計算しない**。うしろの 写真は **48〜96px に 縮めて 1回だけ ぼかした 画像** を 作って 保存し、引きのばして 出す。`.blur(radius:)` を 大きな 画像に かけて 動かさない。
- ガラス(うしろを ぼかす 部品)は **1画面 8枚まで**。重なる ものは `GlassEffectContainer` に まとめる。
- くり返す 動き(輪 ・ 息 ・ レーダー ・ 写真の 入れかえ)は、**画面に 出て いない とき ・ アプリが 裏の とき ・ 低電力モード ・ Reduce Motion で 止める**。
- 傾きの 光は 光の 部品 だけ 作り直す(Home ぜんたいを 作り直さない)。
- Shake の `CMMotionManager` と `MultipeerConnectivity` は **モードを とじたら 必ず 止める**。
- 直す 前と 後で Instruments(Time Profiler ・ Animation Hitches)の 数字を `PERF.md` に 書く。

## 6. 確かめる こと

1. `H01` `H04` `H06` `H09` `H11〜H17` と 見比べる(カードの 枠が 無い ・ ヘッダーが 白い 字 ・ 月が 緑の ガラス)。
