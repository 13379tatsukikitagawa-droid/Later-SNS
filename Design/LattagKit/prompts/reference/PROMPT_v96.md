## 4. ライブ アクティビティ ・ Dynamic Island(**→ `PROMPT_v97.md` で 置きかえ。この 章は 古い**)(`LIVE_activity` `ISLAND_compact_minimal` `W03` `W04`)
- **いつ**:消灯の **1時間 前(23:00)** に まだ 3枚 撮って いない 時。24:00 か 3枚 撮ったら 終わる。
  - アプリが 起動中 なら アプリから、ほかは **サーバーの push-to-start**(iOS 17.2〜)。設定で オフに できる。
- **ロック画面の 形**(v93 の ライブ パネルと 同じ):黒 88% + ぼかし ・ 角丸 26。上:アイコン ・ `● LIVE`(ライム)・ 時刻。まんなか:`消灯まで` + **大きな 残り 46 太**(秒は ライム 小さく)・ 右に 今日の 3こま(撮った = 写真 + `DEV`)。下:**1日の バー**(0:00〜9:00 OPEN ・ 24:00 の 赤い 線 ・ 白い 今の 丸 + ライムの 光)。
- **Dynamic Island**:
  - 小:左 = アプリアイコン ・ 右 = **ライムの 残り時間**
  - 最小:アイコン だけ
  - 長押しで ひらく:アイコン ・ `Lattag` ・ `● LIVE` ・ 大きな 残り ・ バー ・ `あとで`(終わらせる)/ ライムの **`撮る`**(`lattag://shoot`)
- `ActivityAttributes`:`LightsOutAttributes { shotsTaken, lightsOutAt }`。数字は `Text(timerInterval: now...lightsOutAt, countsDown: true)`。

## 5. データ と 更新(大事)
- **App Group**(`group.<bundle>.shared`)に `WidgetSnapshot.json` + 小さな 画像:
  ```swift
  struct WidgetSnapshot: Codable {
    var shots: Int; var lightsOutAt: Date; var opensAt: Date
    var friends: [FriendRing]         // name, initial, color, shotsToday, thumbPath(300px)
    var yesterday: [YPhoto]           // ひらいた 後 だけ 本物の サムネ(300px JPEG)
    var lockedPreview: String?        // ひらく 前は「1回 ぼかした 画像」だけ 置く(本物は 置かない)
    var mondoTag: String?; var mondoCount: Int?; var trip: TripSnap?; var next: NextItem?
  }
  ```
- **写真の ルール**:9:00 まえ ・ 自分が 撮って いない 時は **本物の 写真を App Group に 置かない**(ぼかした 物だけ)。
- タイムラインの 予約:**今 ・ 21:00(S2 が 黒へ)・ 24:00(消灯)・ 9:00(ひらく)**。秒は `Text(.timer)` で 動く(エントリーを ふやさない)。
- 9:00 の 瞬間:サーバーの **静かな push** → アプリが サムネを 取る → `WidgetCenter.shared.reloadAllTimelines()`。届かなくても 9:00 の エントリーで 「ひらいた」に 切りかえる(写真は 次の 更新で)。
- アプリで 撮った / 友だちが 撮った(push)→ スナップショットを 書いて `reloadTimelines(ofKind:)`。
- `つつく`:`PokeFriendIntent(friendID)` → Cloud Functions(トークンは 共有 Keychain)。失敗 → `lattag://friends`。
- 画像は **表示する 大きさの 2倍 まで**(ウィジェットの メモリは 小さい)。
