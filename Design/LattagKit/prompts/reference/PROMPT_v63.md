# Lattag v63 ・ Home の カメラカード と Friends カードを 作りなおす プロンプト

> アプリの 名前は **Lattag(レイタグ)**。`#` は つけません(名前の 変更は `lattag_v62_rename_prompt.md`)。
> これは **v61 の 置きかえ** です。v61(緑の 帯 ・ 赤と ベージュの ひも ・ ガラスの レンズ)は **使いません**。
> 範囲は 3つ:**① Home の まんなかの 黒い カード** / **② Home を 下へ スクロール した 所の Friends カード** / **③ いちばん 下の「PULL」の ひもを 消す**。
> ヘッダー ・「消灯まで」ピル ・ 下の 写真 ・「今日を撮る」の 月ボタン ・ ほかの 画面は さわりません。

## 0. ゴール と ルール

**ゴール**: 実機を `lattag_v60.html`(モック)と **見た目 ・ 動き ・ バイブ まで 同じ** にする。

**なぜ 作りなおすか**(方針。迷ったら ここに もどる)

- 前の カードは **「写ルンです」に 似すぎて いた**(黒い 本体 + 緑の ラベルの 帯 + 赤と ベージュの ひも + 「FILM FOR TOMORROW」+ 「28mm 1:1.4」の 刻印)。→ **全部 やめる**。
- 前の カードは **AI が 作った ように 見えた**(ぼかした 光 ・ ガラスの グラデーション ・ 意味の ない 回る 文字)。→ **ぼかし ・ 発光 ・ グラデーションの 立体を 使わない**。
- 新しい 言葉は **「黒い 台紙 + ポップな シール」**。部品は すべて **平らな 色 + 黒い ふち(2.2〜2.8pt)+ かたい 影(ぼかし 0)**。
- 動きは **意味が ある ものだけ**(のこり 枚数 ・ 押した 手ごたえ ・ キャラの 反応)。
- 基調の 色は 今の まま:黒 `#0D0D0E` / 緑 `#24A03C` / ライム `#C8F25A` / 白 `#FFFFFF` / 紙 `#F6F3EC` / 赤い 点 `#D8262C`。

**ルール**

- モックと 見た目が 違ったら、モックが 正解。アレンジ ・ 省略 ・「それっぽく」は しない。
- 数字は この 文章の 値を そのまま 使う。色は `MockReference/spec/TOKENS.md` と この 文章に ある 値だけ。
- すでに 動いている 機能(撮影 ・ Yesterday ・ Mondo ・ Friends ・ Trip ・ 申請)は 壊さない。つなぎ先は そのまま。
- 書体:Inter / Instrument Serif / Space Mono / Caveat(手書き ・ 英字)/ Klee One(手書き ・ 日本語)。
- 先に **全部 読んで から** 手を 動かす。わからない 所は 推測せず、モックの コード(`MockReference/mock/src/v60.js` と `v60.css`)を 見る。

## 2. 作る もの の 構造(SwiftUI)

```
HomeMainBlock                       // 幅 = 画面の 幅(w)、高さ 600pt
 ├─ HomePager (横スライド)           // 5ページ。1ページ = 幅 w
 │    ├─ Page0: CameraCard          // ← 主役
 │    ├─ Page1: FriendsCard
 │    ├─ Page2: TripCard
 │    ├─ Page3: MondoCard
 │    └─ Page4: YesterdayCard
 └─ PageDock (ナビピル)             // 5つの ボタン。ページの 上に 重ねる
```

**CameraCard の 中身(下から 順に 重ねる)**

1. `CardBody`(黒い カード)
2. `DotHalo`(点の 模様)
3. `Mascot`(キャラの 体。ボタンの **うしろ**)
4. `TagString`(ボタン から タグへ のびる 点線の 糸)
5. `ShootButton`(白い 丸 + 緑の 3こま + 黒い レンズ)
6. `MascotHands`(キャラの 手。ボタンの **まえ**。ふちを つかんで いる)
7. `PaperTag`(紙の タグ)
8. タイトルと `Stickers`(4つ)
9. `CornerButtons`(四すみ ×4)

**座標の ルール(大事)**

- モックは **幅 390pt**。実機は 393 / 402 / 375 も あるので、**ボタンの 中心 (w/2, 300) を 基準** に 置く。
- 左右の 端に 合わせる 物(四すみ ・ ステッカー)は 端から の 距離、まんなかの 物は 中心 から の 距離。
- 下に 書く 座標は すべて **ブロックの 左上 = (0, 0)、390 × 600pt** の 値。
- ブロックの 上は、ピルの 下端 − 10pt。(カードの 上端は ピルの 下端 + 36pt)

## 3. CardBody(黒い カード)

- 位置: x = 10、y = 46、幅 = w − 20(390 なら 370)、高さ **508pt**。角丸 **40pt**。
- 背景: 縦の グラデーション `#171718`(上)→ `#0D0D0E`(下)。**帯は なし**。
- 影: 下に 黒 60%(y 30、ぼかし 50、広がり −26)+ 内側に 白 8% の 細い 線(1.5pt、全周)。
- 昼でも 夜でも カードは 同じ。

## 4. DotHalo(点の 模様)

- **400 × 400pt**、中心 = ボタンの 中心。丸い 範囲。
- 中身: 緑 `#2CB24B` の 点(直径 **3.4pt**)が **13pt の 格子** で 並ぶ。全体の 不透明度 85%。
- 外へ むかって 消える: 中心 から 半径の 48% まで は そのまま、72% で 45%、96% で 0。
- **波**: ライム `#C8F25A` の 点(直径 4pt、同じ 格子)が、**輪の 形で 外へ 広がる**。輪の 位置は 半径の 44% → 98%、輪の 太さは 半径の ±9%。**5.2秒**ごと、`cubic-bezier(.3,.6,.4,1)`、はじめと おわりで 透明。
- **ぼかしは 使わない**。SwiftUI は `Canvas` で 点を 打つ(1回 描いて、波だけ 動かす)。
- Reduce Motion: 波を 止める。

## 7. Mascot(キャラ)と PaperTag(紙の タグ)

### キャラ(ボタンの うしろ から のぞく)

- すでに ある **緑の キャラ**(Friend 画面の キャラと 同じ 絵)を 使う。色 `#61D278`、黒い ふち 2.2pt、目(黒い だ円)、口(弧)、ほお(ピンク `#FF7FAE` 75%)。
- 置き方: ボタンの 中心で **14° 右に かたむけた 向き**の、ボタンの ふちの 上。体は ボタンの **うしろ**、手(2つの 小さな 丸 12 × 10pt)は ボタンの **まえ** に 出して、ふちを つかんで いる ように 見せる。
- 大きさ: 体の 幅 **42pt**。目の 高さは ボタンの ふち から **約 23pt 上**。体の 下は ボタンに かくれる。
- 見える 範囲: x 180〜259、y 151〜210(390 幅の とき)。

| いつ | キャラの 動き | 時間 |
|---|---|---|
| いつも | 上下に ふわふわ(3pt) | 3.2秒、ease-in-out、くり返し |
| いつも | **まばたき**(目が たてに つぶれる) | 4.4秒ごとに 約 0.13秒 |
| ボタンを 押している 間 | **下に かくれる**(24pt 下がる。手は そのまま) | 0.2秒 `(.3,1.6,.5,1)` |
| はなした | ぴょこっと もどる | 0.09秒 おくれて 0.2秒 |
| 四すみを 押した | **目が その 方向を 見る**(2.2pt 動く)。0.9秒 後に もどる | 0.25秒 |
| 撮って Home に もどった | **はねる**(14pt 上 + −6° → もどる) | 0.62秒(0.42秒 おくれ) |
| 3枚 撮りおわった | **ねむる**(目が 弧の 線に なる。右上に `z z` が ふわっと 上がって 消える。ふわふわは 5秒に) | `z z` は 2.8秒ごと |
| Home に 入った | おくれて **下から 顔を 出す**(46pt 下 → 6pt 上 → 0) | 0.56秒(0.76秒 おくれ)。出た とき バイブ `tick` |

- `z z` は Caveat 700 15pt、白。
- Reduce Motion: ふわふわ ・ まばたき ・ `z z` を 止める(ねむった 顔は 出す)。
- VoiceOver では 読まない(飾り)。

### 紙の タグ(下)

- 位置: 中央、上端 y **428**。高さ **34pt**。**3° 左に かたむける**。
- 形: 紙 `#F6F3EC`、角丸 左 9 / 右 17。黒い ふち 2.2pt + 下に 黒い 影 **4pt**(ぼかし 0)。左に **穴**(直径 9pt、中は 黒、まわりに ライムの 輪)。
- 中身(左から): 穴 → **手書きの 字**(Caveat 700 **17.5pt**、黒)→ 小さい 字(Space Mono 700 8pt、字間 0.14em、緑 `#24A03C`)→ 矢印(13pt)。間は 8pt、左右の 余白 10 / 12pt。
- **糸**: ボタンの 左下(156, 388)から タグの 穴へ、ゆるい 曲線の **点線**(紙の 色、太さ 1.4pt、点 1 ・ 間 4、70%)。

| 今日 撮った 枚数 | 手書きの 字 | 小さい 字 | 矢印 | 押すと |
|---|---|---|---|---|
| 0 | `opens tomorrow 9:00` | なし | ↓(1.8秒で 2.5pt 上下) | 下の **Today** まで なめらかに スクロール |
| 1 ・ 2 | `1 developing…` / `2 developing…` | `2 LEFT` / `1 LEFT` | ›(止まる) | **現像の 画面** を ひらく(いちばん 新しい 1枚) |
| 3 | `see you at 9:00` | `3 / 3` | › | 現像の 画面を ひらく |

- 押した 手ごたえ: 3pt 沈む(影 4 → 1pt)、バイブ `click`。動いた とき は `sel`(スクロール)か `pop`(現像)。
- 英語 / 日本語の 切りかえ: 日本語の とき は `あした 9:00 に ひらく` / `1枚 現像中…` / `また あした 9:00`(Klee One 600 14pt)。
- Home に 入った とき: 上から ひらりと 落ちて くる(30pt 上 + 10° → 3pt 下 − 2° → 0)。0.52秒、0.98秒 おくれ。
- 撮って もどった とき: ポンと ふくらむ(scale 1 → 1.12 → 1)。0.42秒、0.7秒 おくれ。

## 8. CornerButtons(四すみの ボタン)

| 位置 | 名前 | ラベル | つなぎ先 |
|---|---|---|---|
| 左上 | Yesterday | `YESTERDAY` | ページ 4 へ スライド |
| 右上 | Trip | `TRIP` | ページ 2 へ スライド |
| 左下 | Mondo | `MONDO` | ページ 3 へ スライド |
| 右下 | Friends | `FRIENDS` | ページ 1 へ スライド |

- **Chat は 四すみに 置かない**。チャットは Friends の 中(友だちの カード・Friends ページ)から ひらく。
- 実機に ある「New group」の ボタンは **消す**。グループは Trip に 一本化(`lattag_v59` の ルール どおり、つくる 入口は すべて「New trip」)。

- 横の 面: 緑 `#1F8F36` を **4.5pt 下** に ずらし、その まわりに 黒い ふち 2.4pt(ぼかし 0)。黒い カードの 上でも 立体に 見せる ため。やわらかい 影は 使わない。
- タップできる 範囲は 丸より **12pt ずつ 大きく**(直径 86pt)。
- ラベル: 丸の **8pt 下**、角丸 6pt の 黒い 札 `#121212`、白い 字、Space Mono 700 **7.5pt**、字間 0.16em、内側 余白 3pt × 7pt、白 10% の 細い ふち。
- 位置(丸の 中心):

## 9. 横スライド(いちばん 大事な 仕組み)

**ページ(左から 順に)**: `0 Camera` → `1 Friends` → `2 Trip` → `3 Mondo` → `4 Yesterday`。

**ふるまい**

- 指で **横に はらう** と 次の ページへ。**縦に スクロール すると 今まで どおり 下の 写真へ**(縦と 横を 取りちがえない)。
- 横と みなす 条件: **横に 8pt 以上 動き、かつ 横が 縦の 1.2倍 より 大きい**。縦に 10pt 先に 動いたら 横は あきらめる。
- 端(0 と 4)を こえて ひっぱる と **ゴムの ように 重く なる**(動きの 35% だけ 進む)。端で はなすと バイブ `soft`。
- はなした とき の きまり方: `次の ページ = round(−(今の 位置 + 速さ × 160) / 幅)`。ただし **1回で 動けるのは ±1ページ まで**。
- ばね の 動き: 硬さ **0.0009**、減衰 **0.05**(モックの 物理)。SwiftUI なら `.spring(response: 0.42, dampingFraction: 0.82)` を 目安に、モックと 並べて 合わせる。
- 速さ(フリック)が あれば その 勢いを 引きつぐ。

**3D の 見え方(動いて いる 間)**

- 中心から の 距離 `d`(ページ数)に 対して:
  - 回転: **Y軸 −d × 14°**(`perspective 900`)
  - 拡大: `1 − 0.08 × min(1, |d|)`
  - 透明度: `1 − 0.45 × min(1, |d|)`
- 止まったら すべて 元の 形(回転 0、scale 1、透明度 1)。

**ページが 変わった とき**

- バイブ `sel`(コツッ)。
- ナビピルの 光る ボタンが うつる(§10)。
- 新しい ページの 中身が **下から ふわっと 入る**:各 パーツ `translateY 18pt → 0`、透明度 0 → 1、**0.48秒**、`cubic-bezier(.3, 1.35, .5, 1)`、**120ms 後から 60ms ずつ ずらす**。入り始めの 260ms 後に バイブ `tick`。
- カメラ(ページ 0)に もどる ときは この 入場 アニメは しない。

**実装の メモ**

- `ScrollView(.horizontal)` + `.scrollTargetBehavior(.paging)` + `.scrollTransition` で 3D を つける のが 簡単。足りない ときは `DragGesture` で 自作して よい(モックの 数値に 合わせる)。
- 親の 縦 `ScrollView` と ぶつかる ので、`simultaneousGesture` を 使い、**方向の 判定は 上の 条件**で そろえる。
- 「ほかの ページに いる 間 は、カメラの 位置を 測りなおさない」(四すみボタンの 位置が ずれる 原因)。
- 外の 縦スクロールの 動き(カードが 上へ 流れて 薄く なる 視差)は **ページ 全体に かける**(いままでの 動きを 引きつぐ)。

## 16. 実装メモ(重さ ・ 小さい 端末 ・ アクセシビリティ)

- **重さ**: ぼかしを 使わない ので 軽い。点の 模様は `Canvas` で **1回 描いて 絵に する**(`drawingGroup()`)。波は ライムの 点の 層の マスクだけ 動かす。
- **形は すべて ベクター**(`Circle` / `Path` + `stroke`)。画像は キャラも 含めて 使わない(色を 状態で 変える ため)。
- **ページ外**: 見えて いない ページ ・ Home が 背面の ときは、くり返しの アニメを 止める。
- **小さい 端末**(幅 375): 四すみ ・ ステッカーは 端から の 距離で 置く。ボタン(193)と 点の 模様(400)は **固定の 大きさ**(縮めない)。紙の タグは 四すみの 丸の 間(幅 w − 186)に 収める。入らない ときは 字を 16pt に。
- **大きい 端末**(幅 402): カードの 幅だけ のびる。
- **Dynamic Type**: ラベル ・ ボタン ・ タグの 文字は 固定の 大きさ。
- **VoiceOver**: 四すみは「Yesterday」「Trip」「Mondo」「Friends」+ 状態(ロック中 / 申請 N 件)。まんなかは「撮る。あと N 枚」/「Yesterday を ひらく」。タグは「あした 9 時に ひらきます」/「N 枚 現像中。現像を 見る」。キャラ ・ ステッカー ・ 点は 読まない。Friends カードの チェキは「あや、今日 3 枚、17 時 5 分」/「そら、まだ。つつく」。
- **Reduce Motion**: 点の 波 ・ レンズの まばたき ・ キャラの 動き ・ ふわふわ ・ チェキの ゆれ ・ 3D の かたむきを 止める。押した ときの 沈みは 残す。
- **ダークモード**: この カードは 昼夜 とも 同じ 色。

## 17. 進め方 と 完了の 条件

**手順(1つ ずつ 実機で 確かめる)**

1. 古い 部品を 消す:緑の 帯 ・ 左の 帯 ・ 光 ・ 波紋 ・ 回る 文字 ・ 円盤 ・ 弧 ・ 刻印 ・ バッジ ・「TODAY ↓」・ PULL の ひも。
2. `CardBody` + `DotHalo` + タイトル(日付)+ ステッカー → `M01_target.png` と 並べる。
3. `ShootButton`(静止)→ 3こまの 色 → 押した 動き ・ はじける 線 ・ まばたき。
4. `Mascot`(体と 手を 別の 層に)→ 4つの 反応(かくれる ・ 見る ・ はねる ・ ねむる)。
5. `PaperTag` と 糸 → 3つの 状態と 押した 先。
6. 四すみ(4つ 固定 ・ 緑の 横の 面 ・ ロック ・ 赤い 点)。
7. `PageDock` と 横スライド(5ページ)。4ページの 左の 帯を 消す。
8. Home の 下の Friends カード(だれも いない / 友だちが いる / 申請あり)。
9. バイブを 全部 つける。
10. Reduce Motion ・ 小さい 端末 ・ VoiceOver の 確認。

**完了の 条件(すべて 満たす まで 終わらない)**

- シミュレータ(iPhone 16 Pro)の スクショを `tools/compare.py` で `M01_target.png` と 比べて、**カード ・ ボタン ・ 四すみ ・ タグ ・ ピルの 位置が 2pt 以内**。
- カードの 中に **緑の 帯 ・ 赤 / ベージュの 線 ・ ぼかした 光 ・ 回る 文字 ・「FILM FOR TOMORROW」・「28mm」が 1つも ない**。
- 0 / 1 / 2 / 3 枚の 4つの 状態が `M02_states.png` と 同じ(こまの 色 ・ 文字 ・ タグ ・ キャラ)。
- 四すみが **どの 状態でも 同じ 4つ**。まんなかは 3枚 撮りおわる まで Shoot。
- 押すと 沈む ・ キャラが かくれる ・ 線が はじける。バイブが 表の とおり(実機)。
- 横に はらうと 5ページ 動く。縦スクロールの 邪魔を しない。
- Friends カード:だれも いない とき は 3つの 方法、いる とき は チェキの 列。**12個の 丸の 輪が 残って いない**。人数は 出ない。
- PULL の ひもが ない。
- 画面の どこにも「Later」「Lattag」が ない(名前は **Lattag**)。
- 実機の スクショ(ビフォー / アフター)を 見せて 完了。
