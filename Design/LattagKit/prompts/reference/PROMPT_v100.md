# PROMPT v100 ・ さわって 楽しい バイブ(モック `lattag_v92.html`)

> **いちばん 新しい 指示**。正解:モック `mock/lattag_v92.html`、元コード `mock/src/v90.css` `v90.js`(関数は `h9…`)。
> 見本:`screens/V01〜V03` ・ 波形 `spec/HAPTICS_patterns.png` ・ Swift の 形 `prompts/reference/swift/Haptics_v100_example.swift`。
> モックの デモボタン:`9:00 の 10秒前` `24:00 の 10秒前` `設定(バイブ)`。画面の 上の 波形(`#hw`)と 字(`#hn`)で、どの バイブが 鳴ったか 見える。

---

## 0. きまり(いちばん 大事)
1. **意味の ある バイブ だけ**。「区切り」「かぎ」「はじ」「時間」が 指で わかる こと。飾りで 鳴らさない。
2. **3段の 強さ**
   - さわる(`notch` `tick` `soft` `edge` `stretch` `knock`)
   - できごと(`sel` `pop` `click` `land`)
   - 大事な 瞬間(`success` `shutter` `heart` `thud` `sig`)
3. **鳴らしすぎない**
   - 全体で **40ms に 1回 まで**(続けて 鳴る パターンの 中は のぞく)。
   - `notch` は **55ms に 1回 まで**。
   - **はやい スクロール(2400pt/秒 より 上)では `notch` を 鳴らさない**。ゆっくりに なると また 鳴る。これで 慣性で 止まる 感じが 出る。
4. **鳴らさない 時**
   - アプリが うしろに いる 時。
   - **動画の 録画中**(マイクに 振動の 音が 入る)。
   - 設定が `オフ` の 時。
   - 端末が バイブ 非対応の 時(`CHHapticEngine.capabilitiesForHardware().supportsHaptics == false`)。
5. **設定 → 表示 → バイブ:`しっかり` / `ひかえめ` / `オフ`**(`V01`)
   - `ひかえめ` = さわる 段(`tick` `soft` `notch` `edge` `stretch` `knock`)を 鳴らさない。
   - 選んだ 時に 見本を 1回 鳴らす。
   - `UserDefaults` の `hapticLevel` に 保存する。
6. **キーボードの 打鍵には 足さない**(iOS が 自分で 鳴らす。2重に なる)。

## 1. 新しい バイブ 5つ(全部で 20種類 ・ `spec/HAPTICS.md`)
| 名前 | 感じ | Core Haptics |
|---|---|---|
| `notch` | カリッ(きざみ)| transient 強さ 0.22 / 鋭さ 0.9 |
| `edge` | コン(はじに 当たる)| transient 0.45 / 0.1 |
| `stretch` | ググッ(のびる)| transient 0.3 / 0.2(1段ごとに 1回)|
| `knock` | コツコツ(かぎの 場所)| transient 0.4 / 0.8 を 0ms と 70ms |
| `sig` | ラ・タッ・グ(Lattag の サイン)| transient 0.7 / 0.35 → 110ms 0.5 / 0.8 → 180ms 0.8 / 0.3 |

## 2. スクロール(どの 画面でも 同じ しくみ)
| できごと | バイブ | 場所 |
|---|---|---|
| 区切り(セクション ・ 友だち ・ 行)の 上の はしが **画面の 35% の 線**を こえた | `notch` | Home の 下(Today / Friends / Active / Yesterday / グループ / Mondo / Albums / On this day)・ yesterday(友だち ごと)・ Friends の 一覧 ・ Trip の チャット ・ 設定 |
| こえた 区切りが **かぎ付き**(撮る まえの Yesterday ・ Mondo など)| `knock`(コツコツ)| 同じ |
| よこ スクロールで 物が **まんなか**を こえた | `notch` | Mondo の 列 ・ 横の カード |
| よこ スクロールが 止まった(スナップ)| `sel` | 同じ |
| いちばん 上 / 下に **当たった**(はやさ 0.45pt/ms 以上)| `edge` | ぜんぶ。もう一度 鳴るのは 24pt 以上 はなれて から |
| はじを こえて **ひっぱる** | 30pt ・ 60pt ・ 90pt で `stretch`(3回 まで)→ はなすと `soft` | ぜんぶ |
| 上の まとまりが 小さく なる(今 ある)| `tick` | Home ・ yesterday |
- 1つの しくみ(`ScrollHaptics`)で どの 画面にも つける。区切りの 位置は `onGeometryChange` で 集め、線は `onScrollGeometryChange`(iOS 18)。iOS 17 は `PreferenceKey`。
- **すでに 自分の バイブが ある スクロール**(今日の フィルムの 1こま `sel` など)には つけない。

## 3. Home の 横スライド
- 指で 引いて いる 間、**半分を こえたら `sel`**(「はなすと Friends へ」)。もどって 半分を こえても `sel`。
- 指を はなした 後は 今 まで どおり(`hpGo`)。

## 4. Mondo の 地球を 指で まわす
- 地球の 上を 横に なぞると 回る(1pt = 0.0065 rad)。**地球の 上 だけ**は ページの 横スライドより 優先。
- **15° ごとに `notch`**。はなすと 指の はやさで 回りつづけ、だんだん ゆっくり(毎コマ ×0.95)。**止まるに つれて カリッ の 間が 広がる**。
- 回して いる 間は 「9:00 の 街が かわった」の `tick` を 止める(うるさく なる ため)。
- タップは 今 まで どおり(ふわっと 回る)。

## 5. 「ひらくまで」を 長押し = 時間を さわる(`V02`)
- 0.45秒 押すと `pop` + カプセルの ふちが ライム(2pt)。
- **はなすまで、1秒ごとに `tick`**(秒の ちょうどに あわせる)。**分が かわる 時は `click`**。毎回 カプセルが 1.035倍 ぽこっ。
- はなすと `soft`。この 長押しの あとは ライブ パネルを ひらかない(タップ だけで ひらく)。

## 6. 9:00 と 24:00 の 10秒 前(`V03`)
- Home を 見て いる 時 だけ。
- 10 → 4 は `tick`、3 → 1 は `click`。まんなかに 数字の 丸(176 ・ 黒 80% + ぼかし ・ 3 から 下は ライムの ふち)。
- **9:00 = `heart` → 0.26秒 後 `success`**(ひらいた)。
- **24:00 = `thud`**(消灯)。
- 数字の 丸は Reduce Motion では 動かさない(バイブは そのまま)。

## 7. Lattag の 字を タップ = サイン
- Home の 左上の 「Lattag」を タップすると **`sig`(ラ・タッ・グ)** + 字が 1.06 → 0.98 → 1.03 → 1 で はずむ(0.42秒)。
- オープニングの さいご(字が 出た 瞬間)にも 同じ `sig` を 使って よい(アプリの 合図に なる)。

## 8. ボタン ぜんぶに 手ごたえ
- バイブが 書かれて いない ボタン(`Button` ・ `NavigationLink` ・ タップできる 行)は **押した 時に `tick`**。
- 作り方:共通の `LGButtonStyle` / `.lgTap()` で 鳴らす。**その ボタンが 自分で 鳴らす 時は 鳴らさない**(2重に しない)。

## 9. 実機 だけ(モックには ない ・ 同じ きまりで)
| できごと | バイブ |
|---|---|
| シートの 高さ(detent)が かわった | `notch` |
| 下へ 引いて 閉じる 線を こえた / もどった | `sel` |
| 閉じた | `soft` |
| 写真の ピンチ:いちばん 大きい / 小さい に 当たった | `edge` |
| 入力の エラー(ID が 使えない など)| `warn`(今 ある)|
| 長押しの メニュー | iOS の まま(足さない)|

## 10. Swift の 作り方(`Haptics_v100_example.swift`)
- `enum HapticKind`(20こ)+ `Haptics.play(_:)` 1か所。
  - `CHHapticEngine` は 1つ(`playsHapticsOnly = true` ・ `isAutoShutdownEnabled = true` ・ `resetHandler` で 再起動)。
  - パターンは 起動時に 1回 作って `CHHapticPatternPlayer` を 使いまわす。
- 間を あける きまり(全体 40ms ・ 種類ごとの `gap`)と `hapticLevel` も `play` の 中で。
- **モックの `hap('名前', …)` と 1対1**。名前を 変えない。
- テスト:`HapticsTests` で 「ひかえめ で notch が 鳴らない」「40ms 以内の 2回目は 鳴らない」を 確かめる(エンジンは モックに 差しかえ)。

## 11. 確かめる こと
1. 実機で Home を ゆっくり / はやく スクロール:ゆっくり = 区切りごとに カリッ ・ かぎで コツコツ ・ はやい = 静か → 止まりぎわに カリッ。
2. 上 / 下で コン、ひっぱると ググッ。
3. 横スライドの 半分で コツッ。地球を 回すと 15° ごとに カリッ(だんだん ゆっくり)。
4. 「ひらくまで」長押しで 1秒ごと。8:59:50 に Home を ひらいて おくと カウントダウン → 9:00 に ドクン。
5. 設定 `ひかえめ` / `オフ` が すぐ きく。動画の 録画中に 鳴らない。
6. 5分 使って **うるさく ないか**(だれかに さわって もらう)。うるさい 所は `gap` を 広げる。
