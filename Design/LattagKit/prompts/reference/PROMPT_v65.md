# Lattag v65 ・ Home の 仕上げ(バランス ・ 読みやすさ ・ 小さい ボタン ・ Liquid Glass)

> **v64(ぼかした 写真 + ガラス)を 実装した あとに 重ねる 差分** です。v64 の 内容は そのまま 生かし、**ここに 書いた 所だけ 変えます**。
> 見本:モック `lattag_v62.html`、画像 `MockReference/screens/HomeMain/`(`M01` 正解 / `M02` 4つの 状態 / `M03` 前と あと / `M04` 4ページ / `M07` 寸法つき)。
> 元コード:`MockReference/mock/src/v62.js` と `v62.css`。

---

## 0. ねらい

1. **バランス**:上が 空いて 下が 混んで いた。下の 2つの 丸と ピルを **同じ 高さ** に そろえ、上に「だれが 撮ったか」を 置いて 上下の 重さを そろえる。
2. **読みやすさ**:写真の 上の **小さい 文字(7.5〜8.6pt)を 9.5pt 以上** に。
3. **押しやすさ**:押せる 物は **すべて 44 × 44pt 以上**(Apple の 最小)。
4. **最新の 見た目**:iOS 26 の **Liquid Glass**(ガラスの ふちの 光 ・ 押すと ふくらむ ・ 選んだ 印が 液体の ように 動く)。
5. **ムダを 消す**:カードの 中の「Lattag」は ヘッダーと 同じ なので 消す。ぶつかる ステッカーを 整理。

## 2. 上の チップ(だれが 今日 撮ったか)

- 位置:中央、上端 y **62**、高さ **40**、角丸 20。押せる 範囲は 上下 6pt 広げる(= 52pt)。
- ガラス:白 14% + うしろを ぼかす 18pt(彩度 1.6)+ §6 の ふち。影 黒 70%(y12、ぼかし26、広がり −14)。
- 中身(左から、間 8pt、左の 余白 6 / 右 15):
  - **写真の 丸** 28pt(白 85% の ふち 2pt、9pt ずつ 重ねる)。今日 撮った 友だちを 撮った 枚数の 多い 順に 3人。4人 以上は 4つ目に「+N」(Space Mono 700 10pt)。
  - **字**:Inter 700 **13.5pt**、白。1人 → `あや が 撮った` / 2人 以上 → `2人 が 撮った`。
  - **ライムの 点** 7pt(2.2秒ごとに 輪が 広がる)。
- だれも 撮って いない:写真 なしで `まだ だれも 撮って いない`(左の 余白 14)。
- 友だちが 0人:`友だちを よぶ` + `ADD ›`(Space Mono 10pt、白 72%)。押すと Add friends の シート。
- 押すと:scale **1.06**(ふくらむ)+ 白 24% に。バイブ `sel`。**Friends ページ(横スライドの 1)へ**。
- Home に 入った とき:10pt 上 + scale .9 から 出る(0.52秒、0.56秒 おくれ、`(.3,1.4,.5,1)`)。
- 友だちが 撮ったら(通知が 来たら)その場で 中身を 更新。

## 3. まんなかの ボタン

- 直径 **201pt**(中心 (w/2, 300) は 同じ)。押している 間 **192pt**。
- 文字:カメラの 絵 **21pt** /「Shoot」Instrument Serif **40pt** /「3 LEFT」Space Mono 700 **9.7pt**、字間 0.3em、**白 100%**、上との 間 6.5pt。
- 3枚 撮りおわり:「Yesterday」**30pt**。
- 3本の 弧:太さ **5.2pt**(半径 93.5pt)。目盛り ・ 光の すじ ・ 動きは v64 の まま。

## 4. 四すみ と ピル

- 四すみの 丸の 中心:**上 (62, 154) ・ (w−62, 154) / 下 (62, 428) ・ (w−62, 428)**。
- 下の ピル:上端 **410**、高さ 36(中心 428)。字 Instrument Serif 斜体 **17.5pt**、小さい 字 **9.5pt**。押せる 範囲は 上下 6pt ・ 左右 4pt 広げる。
- 四すみの ラベル:丸の **8pt 下**、Space Mono 700 **9.5pt**、字間 0.16em、**白 100%**(ロック中 60%)、影 黒 55%(ぼかし 8)。
- 四すみの 鍵:**22pt**。赤い 点:**16pt**。
- **押した とき**:丸が **scale 1.1 に ふくらむ** + 白 28% に 明るく(Liquid Glass の interactive。iOS 26 は `.glassEffect(.regular.interactive())`)。ロック中は 1.04。0.16秒 `(.3,1.5,.5,1)`。

## 5. 目次(ナビピル)

| 項目 | 値 |
|---|---|
| 全体 | 高さ **52**、角丸 26、内側 余白 4、ボタンの 間 4。下から **56pt**(= y 492)、中央。幅は 中身しだい(約 300) |
| ボタン | **44 × 44pt**(角丸 22)。アイコン **20pt**、白 78% |
| 選んで いる ボタン | 字が 出る(Space Mono 700 **10pt**、字間 0.12em、大文字、アイコンの 7pt 右)。左 13 / 右 16 の 余白。字の 色 `#111` |
| **選んだ 印** | ライム `#C8F25A` の カプセル(高さ 44)。**ボタンとは 別の 1つの 部品** で、選んだ ボタンの うしろへ **すべって 動く** |
| 印の 動き | 0.44秒、`(.3,1.25,.4,1)`。動く 途中(42% 地点)で **今の 位置 から 次の 位置まで いっぱいに 伸びて**、それから 縮む(液体の ような 動き)。印の 上に 白 55% の 線 1.5pt と、下に ライムの 影 |
| 押した とき | ボタンが scale 1.08 |

- SwiftUI:`GlassEffectContainer` の 中で 印に `.glassEffectID("dock", in: ns)` を つけ、`withAnimation(.spring(response: 0.44, dampingFraction: 0.72))` で 動かす。iOS 26 より 前は `matchedGeometryEffect`。
- 横スライドの 途中でも、いちばん 近い ページの ボタンへ 印が 動く(v64 の とおり)。

## 6. ガラスの ふち(Liquid Glass の 光)

- 四すみ ・ ピル ・ チップ ・ 目次 ・ まんなかの ボタンに **同じ ふち** を つける。
- ふち:太さ **1.2pt**(まんなかの ボタンは 2pt)。**角度の グラデーション**:光の 向き(`la`)から 白 95% → 22% 地点 18% → 45% 地点 8% → 52% 地点 55%(反対側の 小さな 照りかえし)→ 72% 地点 12% → 白 95%。
- ふちの 内側に **やわらかい 照り**(光の 向きに 寄せた 白 28% の だ円、ソフトライト 合成)。
- **光の 向き**:
  - 端末の かたむき(Core Motion の `attitude.roll` と `pitch`)を −1〜1 に して、なめらかに 追う(毎フレーム 8% ずつ 近づける)。角度 = 210° + 横の かたむき × 70°。
  - 指で 画面を なぞって いる 間は、指の 位置で 動かす。
  - 2.5秒 触って いない ときは、ゆっくり 自動で 揺れる(横 0.35Hz ・ 縦 0.27Hz の 正弦)。
- iOS 26 では `.glassEffect()` が 自動で 光を 出すので、**同じ 見え方に なる ように** 調整するだけで よい(自作の ふちは iOS 18 以前の ため)。
- Reduce Motion:光は 動かさない(210° で 止める)。

## 7. ステッカー

- **星**:(24, 58)、34pt。**波線**:右から 24、y 72、46pt。
- **点**:**消す**(目次と ぶつかる ため)。
- **花**:**ガラスの ボタンの 右上(1時の 位置)に 貼る**。左上 (244, 186)、36pt、影 黒 35%(y4、ぼかし6)、ボタンより 前。ふわふわは 7秒の まま。

## 8. ヘッダーの today / yesterday(切りかえ ボタン)

- ロゴの **10pt 右**。高さ **38**、角丸 19、地 黒 6%、内側 余白 3。
- 2つの ボタン:高さ **32**、左右 12、角丸 16。字 Instrument Serif 斜体 **16.5pt**。
- 選んで いる 方:**白 + 黒い 字 + 小さな 影**(黒 12% y1 ぼかし3 + 黒 6% の 線 0.5pt)。もう 片方:`#8E8E93`。
- 押すと yesterday(Lattag yesterday)を ひらく(今と 同じ)。
- 暗い 背景(下へ スクロール して ヘッダーが 黒く なった とき):地 白 10%、選んだ 方 白 18% + 白い 字。

## 9. 読みやすさ ・ アクセシビリティ

- **最小の 文字**:写真の 上は **9.5pt 以上**、白 100%(ロック中だけ 60%)、影 黒 55%。
- **押せる 範囲**:すべて 44pt 以上(四すみ 86 / ピル 48×171 / チップ 52 / 目次 44 / today・yesterday 38+上下 3)。
- **透明度を 下げる**(Reduce Transparency):ガラスを **黒 88% の 不透明** に。
- **コントラストを 上げる**(Increase Contrast):写真の 上に 黒 45% を 足し、白い 字に 濃い 影。
- **Reduce Motion**:光の 向き ・ チップの 点 ・ 印の 伸び を 止める(印は すぐ 移る)。
- **VoiceOver**:チップは「今日 撮った 友だち、2人。Friends を ひらく」。目次は「ページ、2 / 5、Friends」。today / yesterday は「Today、選択中」。

- 下の 2つの 丸と ピルの **中心が 同じ 高さ**。
- 押せる 物が **すべて 44pt 以上**(Xcode の Accessibility Inspector で 確認)。
- 写真の 上の 文字が **9.5pt 以上**。
