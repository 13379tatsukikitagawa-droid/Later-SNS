## 0. 決まり
- **アイコン = 自分の プロフィール写真**。1つの 値 `profile.photo`(Firebase の ユーザー ドキュメント ・ 画像は Storage)を ぜんぶの 場所で 使う。
- 写真が ない 時は **名前の 1文字 + 色**(緑 `#61D278` → ピンク `#EE5E9C` の 斜め グラデーション ・ 白 900)。CLAUDE.md の「キャラクター 禁止」の まま。
- 変えたら **その場で 全部の 場所が 変わる**(Home の アバター ・ yesterday の 右上 ・ プロフィールの チェキ ・ 設定の 行 ・ 友だちから 見える 丸)。

## 1. yesterday の 右上 = 自分の アイコン(`Y02`)
- v79 の「録画の 点」の 丸を やめて **自分の アイコン 40pt**(黒 2pt + 黄緑 1.5pt の 二重の ふち)。小さく なった 帯では ふち 1pt。
- **1回 タップ → プロフィール**(0.4秒 待って 2回目が なければ)。**2回 タップ → 今日へ**(v79 の まま)。

## 3. 写真を 設定 できる 場所
| 場所 | 入口 |
|---|---|
| **プロフィール**(`F08` `F12`)| チェキの 写真の 右下に `📷 写真` の ピル ・ 設定の いちばん 上に `アイコンの 写真`(小さな 丸 + 字)の 行 |
| **はじめての 設定**(`O07`)| `Name` の 画面:見出しの 下に **アイコンの 丸 76**(＋の 黄緑の 印)+ `アイコンの 写真` / `あとで プロフィールでも 変えられます`。`じぶんを、タグで。` の 画面の 📷 も 同じ シートを ひらく。**とばしても よい**(1文字 + 色) |
| Home | アバターを 押す → プロフィール(今まで どおり)|

- プロフィールの チェキは、写真が ある 時は **写真を 大きく**(1文字は 隠す)、ない 時は 今までの 1文字 + 色。

## 4. 確かめる こと
1. はじめての 設定で 写真を えらぶ → Home ・ yesterday ・ プロフィール 全部に 出る。
2. プロフィールで 写真を 消す → 全部 1文字 + 色に もどる(`F12`)。
3. yesterday の 右上:1回 → プロフィール、2回 → 今日。
4. 写真の 保存は 小さく(512 × 512 ・ JPEG 0.8)。サムネは 96 × 96 も 作る(一覧の 丸 用)。
