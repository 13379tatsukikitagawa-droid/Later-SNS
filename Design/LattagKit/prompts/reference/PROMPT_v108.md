## 1. 相互フォロー(承認 = フォローバック)
### 1-1. きまり
- A が B に **申請** → B に 通知 + お知らせ。B が **承認** → **2人とも 友だち(相互)**。承認は「フォローバック」と 同じ 意味(ボタンの 字は「承認」)。
- **A も B に 申請 して いた 時**(おたがいに 申請)→ その 場で 相互(承認 いらない)。
- 相互に なったら **両方に 通知**:
  - 承認した 人(B):画面で すぐ「友だちに なりました」(行が ライムに なる)。通知は 出さない。
  - 申請した 人(A):push「B が 承認しました」。
- 片方 だけ の「フォロー」状態は **作らない**(写真は 相互の 人 だけ 見える ・ v103 の きまり)。
- 申請を 消す:相手には 知らせない。7日 たった 申請は 自動で 消える(D1 の 期限)。
### 1-2. 置き場所(v103 と 同じ)
- **Cloudflare の Worker + D1**(`friend_requests` ・ `friendships` ・ `notifications`)。本人確認は Firebase の ID トークン。**CloudKit の 公開DB には 書かない**。
- R2(写真)は まだ 無くて よい(D1 と Worker は カード 登録 なしで 使える)→ **P46 の A(友だち ・ 申請)を この P52 で 先に やる**。
- 今 CloudKit に ある テストの 申請は 移さない(テスト用 だけ ・ v103 0-7 の 答え)。

## 4. 通知(push)
| できごと | だれに | タイトル | 本文 |
|---|---|---|---|
| 申請が 来た | 相手 | `りこ(@riko_6982)から 友だち申請` | `承認すると、あしたの 9:00 から 写真を 見せあえます` |
| 承認された | 申請した 人 | `りこ が 承認しました` | `友だちに なりました ・ あしたの 9:00 に 見せあえます` |

- 押す → お知らせ(その タブ)。アプリを 開いて いる 時は 上に 小さな 帯(モックの 見本)+ `sig`。

- 端末の トークンは Worker の D1 に(ログイン中の `uid` に ひもづけ ・ ログアウトで 消す)。
- 通知の 設定(設定 > お知らせ の「友だち」)が オフ なら 送らない。

## 5. LINE などで 送る リンク
### 5-1. リンクの 形
| しゅるい | リンク |
|---|---|
| 友だち | `https://later-app-f2606.firebaseapp.com/u/<ID>?openExternalBrowser=1` |
| Trip | `https://later-app-f2606.firebaseapp.com/t/<招待トークン>?openExternalBrowser=1`(トークンは Worker で 作る ・ 24時間 ・ v103 A2)|
- `openExternalBrowser=1`:**LINE の 中の ブラウザで 止まらない** ため(LINE で 押すと 外の ブラウザ ・ アプリへ)。
- 今の `/g/*`(グループの 招待)と 古い リンクは **ひらける まま**(Trip の 招待へ つなぐ)。
- ドメインと App Store の URL は `AppLinks` 1か所に まとめる(あとで 独自ドメインに かえる 時に そこだけ)。
### 5-2. 送る 文(モック デモ `送る 文(友だち / Trip)`)
- 友だち:
  ```
  ゆい(@yui_0612)から Lattag の 友だち申請です

  ↓ タップで ひらく(アプリが ひらきます)
  https://later-app-f2606.firebaseapp.com/u/yui_0612?openExternalBrowser=1

  アプリが ない 時は、ひらいた ページから 入れられます
  ```
- Trip:
  ```
  たつき から Trip の 招待です
  『大阪』11/21〜11/23 ・ 3人 参加中

  ↓ タップで 参加(アプリが ひらきます)
  https://later-app-f2606.firebaseapp.com/t/<トークン>?openExternalBrowser=1

  KEY:#maple24(アプリの「KEY で 入る」でも OK ・ 24時間)
  ```
- 絵文字は 使わない。名前 ・ ID ・ Trip 名は 実データ。
### 5-3. リンクの 見え方(OGP)・ ページ
- `hosting/` を Firebase Hosting に 足す(**今の `firebase.json` ・ `/g/*` を こわさない ように 合わせる**):
  - `u.html` `t.html`(`/u/**` `/t/**` を rewrite)・ `og/friend.png` `og/trip.png`(1200 × 630)・ AASA に `/u/*` `/t/*` を 足す(`/g/*` は のこす)。
  - 見出し:友だち「Lattag で 友だちに なろう」/ Trip「Trip に 招待されました」。説明は 1行。
- ページの 中身:Lattag の ロゴ ・ だれ から(ID)・ 説明 ・ **アプリで ひらく**(URL scheme)・ **App Store で 入れる** ・ 入れた あとの 3ステップ ・ **リンクを コピー**。LINE の 中で ひらいた 時は「ブラウザで 開く」の 案内を 上に 出す。
- App Store で まだ 公開 して いない 間は、`AppLinks.storeURL` を TestFlight の 公開リンク(あれば)に。
### 5-4. アプリで 受け取る
- `/u/<ID>`:その 人の カード(v105)を ひらき、**申請 ボタン**。相手から もう 申請が 来て いれば **承認 ボタン**(押すと すぐ 相互)。自分の ID なら 自分の QR。
- `/t/<トークン>`:Worker で 調べて、Trip の パス(表紙 ・ 名前 ・ 日にち ・ メンバー)を 見せて **参加**。期限切れ → 「リンクの 期限が 切れました ・ もう一度 送って もらって ください」。
- まだ ログイン して いない → はじめての 設定の あと に 同じ 画面へ(リンクを おぼえて おく)。
- 「招待されて 来ましたか?」の 貼りつけ:`/u/…` `/t/…` `/g/…` ぜんぶ 受け取る。

## 6. 守る こと
- 片方 だけ の フォローは 作らない。写真は 相互 だけ。
- 通知の 文に メール ・ 電話番号を 入れない。
- キー(.p8)・ トークンは チャット ・ ログに 出さない。
- 新しい 色を 作らない(モックの 送る 文の 見本 シート `f9sh` は **モック だけ**・ 実機に 作らない)。

3. Home:まんなかに Lattag ・ 左に ベルと 数 ・ 0件で 数が 消える。
4. Trip の 招待 → お知らせで 参加 → Home の Trip に 出る。
5. LINE で 友だちの リンクを 送る → 押す → アプリが ひらき その 人の カード。アプリ なしの 端末 → ページ → コピー → 入れて 貼りつけ → 同じ カード。
6. LINE の 見え方:画像 ・ 見出し ・ 説明が 出る(`og/*.png`)。
7. `/g/*` の 古い 招待も ひらける。
