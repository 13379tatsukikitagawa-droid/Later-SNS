## 3. ひらき方
1. **アプリ内ブラウザ**(`SFSafariViewController`)を 下から シートで ひらく。`WKWebView` で 自作しない(読みこみ ・ 失敗 ・ 戻る は システムに まかせる)。
2. 色:`preferredControlTintColor` = ライム `#C8F25A`、`preferredBarTintColor` = `#1C1C1E` 前後(モックの バーと 合わせる)。**新しい 色は 作らない**。
3. 上の バーは「完了」+ URL の ホスト名 + 外で ひらく(Safari)。`SFSafariViewController` の 標準で よい。
4. `SFSafariViewControllerDelegate.safariViewControllerDidFinish` で `tick`(閉じた 時)。ひらく 時は `soft`。ボタンの `tick` と **2重に しない**(v100)。
5. `Configuration`:`entersReaderIfAvailable = false` / `barCollapsingEnabled = true`。
6. **圏外 ・ 読みこめない 時**は システムの エラー画面に まかせる(アプリで 作らない)。

## 4. 2か所の つなぎ
### 4-1. サインイン画面(`O04`)
- 下の 字は 今の 見た目の まま(10〜10.5pt ・ グレー)。**「利用規約」と「プライバシー」だけ 下線つきの 押せる 字**。
- 押せる 大きさは **44 × 44pt 以上**(字の まわりに 余白の 当たり判定。**ほかの 部品と 重ねない** = `HStack` + `Button` + `contentShape`、はみ出す 時は `ViewThatFits`)。

- 英語の 時(言語が English):**ページは 日本語のみ**(今は 英語版が ない)。同じ URL を ひらく。→ たつきさんに「英語版が ほしいか」を 報告。
