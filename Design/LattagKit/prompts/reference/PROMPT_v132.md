## 0. なぜ
1. **Trip の 一覧**:同じ こと(いま の Trip)が 3回 出て いた ・ いちばん 大事な「いま の Trip」が 箱と ボタンの 下 ・ ライムが 2つ ・ 1枚の カードに かざりが 5つ。→ **搭乗パスの 束**(参加の 演出 = 搭乗ゲート と つながる)+ **ひらいた 写真**(押す 理由が 見える)。
2. **プロフィール**:自分の 写真が どこにも ない(下に 何も ない)・ 4つの ボタンが 同じ 大きさ で、ライムが QR(いちばん 大事 では ない)・ 小さな 字が 英語 + Space Mono(v118 で 使わない 書体)。→ **アーカイブ**(ひらいた 日が 1日 1マス 増える = 何回も ひらく 理由)。
3. **Today**:チェキ ・ 撮る ・ 枠 ・ 線が ばらばらの 部品 ・ 線の「26%」が 何か わからない ・ くり返しの 動き(光の すじ ・ 点の 点滅)が 2つ。→ **暗室の ひも**(写真 ・ 撮る ・ のこり ・ 時間 を 1つの 物に)。

### 1-2. パスの 束(`Boarding`)

- うしろの パスは **上に 56pt ずつ 頭だけ 見える**。k 枚目(0 = 前):`offset(y: (n-1-k) × 56)` ・ `scaleEffect(1 - k × 0.045)` ・ `rotation3DEffect(k × 7°, x軸, anchor: .top)` ・ 明るさ 0.86 ・ うしろの パスは 下半分(日付 ・ 足)を 消す。

## 2. プロフィール = アーカイブ

### 2-2. 数字 3つ(箱 なし)
- 3列 ・ 間に 縦の 線 1pt。数字 **セリフ 34pt**、下に 日本語 12pt:**日 れんぞく**(数字は ライムの 字)・ **枚 撮った** ・ **日 ひらいた**。
- 数字が かわる 所は `.contentTransition(.numericText())`。**友だちの 数は 出さない**(v103)。

### 2-3. ボタン(1行 ・ 高さ 48 ・ 角丸 16 ・ 下に 段 3pt ・ 押すと 3pt しずむ)
| ボタン | 見た目 | 行き先(v95 の きまり) |
|---|---|---|
| 編集 | 灰 `#1A1A1D` ・ 字 14pt | プロフィールの 編集 |
| **送る** | **ライム**(段 `#97C235`)・ 共有の 絵 + 「送る」・ 幅 1.35 倍 | 共有シート(自分の リンク) |
| QR | 灰の 正方形 48 | **自分の QR** の 画面 |
| 読む | 灰の 正方形 48 | **QR を 読む カメラ** |
- 3つの 画面は **プロフィールの 上に** ひらく(モックでは 下に かくれる バグが あった ・ 重なり順に 注意)。

### 2-4. タブ + 3列(下)
- タブ「▦ 毎日 13」「✈ Trip 2」(高さ 48 ・ えらんだ 方 = 白い 字 + 下に 白い 線 3pt)。**スクロール すると 上に くっつく**(`LazyVStack(pinnedViews: [.sectionHeaders])`)。
- **毎日**:3列 ・ 間 3 ・ 左右 12 ・ 正方形 ・ 角丸 6。1マス = **ひらいた 1日**(新しい 順)。表紙 = その日の 1枚目 ・ 右上に 枚数の 丸(20 ・ 黒 78%)・ 左下に 日付(11pt ・ きのう色 `#FFD84D`)。
  - いちばん 前 = **きょうの マス**:黒 + ライムの ふち 1.5pt(55%)・ 点 3つ(撮った 数 = ライム)+「きょう 2/3」「あした 9:00 に ひらく」。**写真は 出さない**。
  - **9:00 まえ** は きのうの マスも 鍵(ぼかし + 🔒 の 丸 30 +「9:00 に ひらく」)。
  - 押すと その 日の 写真(現像 画面)。
- **Trip**:入った Trip の 行(表紙 64 ・ 角丸 12 ・ 名前 ・ 日付 ・ 枚数)。押すと その Trip。
- **はじめての 日**(0日):きょうの マス 1つ +「ここに ひらいた 日が 並びます」「きょう 撮った 写真は、あしたの 9:00 に 友だちと いっしょに ひらきます」。
- データ:毎日 = **ME の 写真**(端末 + CloudKit の 自分用 DB の `me` ゾーン ・ v86)。表紙は サムネ だけ ・ 1回 作って キャッシュ。

## 3. Today の カード = 暗室の ひも

### 3-1. 上
| もの | 値 |
|---|---|
| カード | 今と 同じ 箱(Home の かたまりの 形)・ 中 20 |
| 左 | **Today**(セリフ 38pt)+ 1行(13pt 太字 ・ 灰):0枚 =「まだ 0枚 ・ **24:00** まで 撮れる」/ 1〜2枚 =「現像中 ・ のこり **2枚**」/ 3枚 =「3枚 そろった ・ **9:00** に ひらく」 |
| 右上 = **9:00 の 札** | 紙 `#F4F1EA` ・ 角丸 5 ・ **-4°** ・ 上に 穴(黒い 点 7)・ **9:00**(セリフ 30pt)+「ひらく ・ あと 21:20」(10.5pt heavy)。**3枚 そろったら 札が ライム**(=「撮る」が 消えるので ライムは いつも 1つ)・ 字「あと 11:30 で ひらく」 |

### 3-2. ひも と チェキ
- 高さ 196 の 場所に **ひも**(左はしの 釘 → 右へ ゆるい カーブ)。うすい 線(白 30% ・ 1.8pt)の 上に **白い 線(2.6pt)= 9:00 から いま まで**(Lattag の 1日 = 9:00 → あした 9:00 の 24時間 ・ 24:00 の 消灯 = 62.5% の 所)。「26%」の 字は 出さない。
- ひもに **3つの 枠**(幅 96 ・ 高さ 132)を クリップ(12×18 ・ 黒)で つるす:左から **撮った チェキ** → **ライムの「＋ 撮る / のこり 2」**(角丸 18 ・ 段 6pt)→ **点線の 枠 + 数字**(セリフ 30 ・ 白 22%)。撮るたびに「撮る」が 右へ 1つ ずれる。
- チェキ:紙 6 / 6 / 26 ・ 左下に 撮った 時刻(11pt heavy)・ 中の 写真の ぼかしは **今の 式の まま**(v93:ぼかし 1回 ・ 不透明度 だけ)。**時間が たつと 少しずつ 浮きでる**(9:00 で はっきり)。
- 押す:チェキ = 現像 画面(`pop`)・ 撮る = 撮影(`pop`)。
- 撮れない 時間(消灯 中)は「撮る」を 出さず 点線の 枠に する(**撮れる 時間は 今の アプリの きまりに したがう** ・ モックは 8:50 でも 出て いる が まね しない)。

### 3-3. 動き(くり返しは なし)
| いつ | 動き |
|---|---|
| カードが 画面に 入った 時(35% 見えたら ・ 1度 画面の 外へ 出たら また) | チェキが **ゆれて 止まる**:`rotate 9° → -6° → 3° → -1° → 0`(32% / 62% / 84% の 所 ・ クリップが 軸 = anchor .top)・ 1.1秒 ・ 1枚ずつ 0.09秒 ずらす。撮る ・ 枠は 上から 落ちる(-18pt ・ rotateX 28° → 0 ・ 0.62秒)。札は 上から 落ちて -4° に(0.56秒)。白い 線は 0 → いま まで のびる(0.9秒 ・ 0.2秒 あと) |
| 指で さわる(実機は 指 + ジャイロ) | チェキが **3D で 傾く**(±12°)+ 光の すじが 動く ・ はなすと ばねで もどる(0.6秒)・ さわった 時 `tick`(0.2秒に 1回 まで) |
| スクロール | 速さに あわせて チェキが 少し ゆれて 止まる(最大 ±2.2°) |
| Reduce Motion | ぜんぶ フェードに(傾き ・ ゆれ なし) |
- 小さな チェキの 傾きは **列(親)に 遠近**(`rotation3DEffect` の perspective 0.5 前後)を 付ける と 見える。動かすのは `rotation3DEffect` ・ `rotationEffect` ・ `offset` ・ `opacity` だけ。画面外では 止める。
