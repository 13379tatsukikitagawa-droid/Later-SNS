## 1. ぜんたい
- 地:単色 `#0B0C0D` + 上に 黄緑の かすかな 光(楕円 幅 80% ・ 高さ 30% ・ y 18% ・ 12%)+ 下から 緑(30%)。
- 上(52〜96):左 `×` / `‹`(44 丸 ・ ガラス)・ まんなか **4本の 線**(高さ 4 ・ すきま 5:おわった = 黄緑 50% ・ いま = 黄緑 + 光 ・ これから = 白 12%)・ 右 `1 / 4`(Inter 900 15 + `/ 4` は Mono 10)。
- その下に **パス(搭乗券)**(下の 2章)。パスは 4つの 質問の 間 ずっと 同じ 場所に あり、**答える たびに 中身が 書きかわる**。
- 質問の 題:**Noto Sans JP Black 30 ・ 字間 -0.04em**(タグ画面の お題と 同じ 形)。`どこへ 行く?` `いつ 行く?` `だれと 行く?` `表紙を えらぶ`。
- 下:ボタン(高さ 58 ・ 丸 29):ふだん 白 ・ 押せない 時 白 8% / 字 30% ・ さいご `Trip を つくる` は 黄緑 + 光。下に 向かって 地へ とける グラデの 上に 置く。
- 質問が 進む / もどる 時:中身が 横から 32 すべって 入る(0.42秒 ・ `timingCurve(.3,1.1,.4,1)`)。バイブ:つぎへ `click` ・ もどる `sel`。

## 2. パス(搭乗券 ・ 左右 16 ・ 高さ 148 ・ 角丸 22 ・ 地 `#F4EFE6`)
| 部品 | 値 |
|---|---|
| 左の 半券(幅 98)| 表紙の 写真(下に 黒の グラデ)+ 左下 `LATTAG`(Inter 900 11 ・ 白)|
| 切りとり線 | 半券の 右に 点線(2 ・ 黒 22%)+ 上下に 半円の 切りかき(18 ・ 地の 色)|
| 1行目 | `TRIP PASS`(Mono 8.5 ・ 字間 .18em)・ 右に `No.1074`(名前から 決まる 4けた)|
| 名前 | **Inter / Noto Sans 900 27**(1行 ・ はみ出しは …)。まだ ない 時は `どこへ?`(黒 24%)|
| 2行目 | `FROM 11/18 WED` → `TO 11/20 FRI` ・ 右に `DAYS 3`(数字 22)|
| 3行目 | メンバーの 丸(22 ・ 重ねる)+ `3人 ・ 1日 23枚`(Mono 9.5)|
| 右はし | 黄緑 / 緑の しましま(幅 8)|

- **名前が かわる 時は 1字ずつ めくれる**(空港の 案内板 の ように:上へ 92° たおれた 所から 起きる ・ 0.3秒 ・ 1字 32ms ずらし)。
- 人が 増えた 時:新しい 丸が 0 → 1.2 → 1 で ポンと 出る。表紙を 変えた 時:半券の 写真が 1.15倍 → 1 で 入れかわる。

## 3. ① どこへ 行く?(`T01` `T14` ・ `M30`)
- 入力(高さ 60 ・ 角丸 20 ・ 地 `#121315`):左に 黄緑の ピン ・ 字 900 20 ・ プレースホルダ `行き先 ・ イベント`。えらんで いる 時は ふちが 黄緑。字が ある 時は 右に `×`(けす)。ひらいた 時に キーボードが 出る。
- その 下に **候補が 横に 流れる 2列**(タグ画面の「いま人気」と 同じ しくみ):
  | 列 | 中身 | 向き ・ 速さ |
  |---|---|---|
  | 1列目(行き先)| 黄緑の ピン + `京都` `沖縄` `大阪` `北海道` `福岡` `金沢` `箱根` `鎌倉` `名古屋` `広島` `横浜` `長野` `ディズニー` `USJ` `ソウル` `台湾` `ハワイ` | 左へ ・ 1周 46秒 |
  | 2列目(イベント)| ピンクの 星 + `修学旅行` `卒業旅行` `合宿` `ライブ遠征` `部活の 遠征` `文化祭` `体育祭` `夏祭り` `花火大会` `誕生日` `クリスマス` `卒業式` `テスト明け` `いつメン旅` | 右へ ・ 1周 54秒 |
  - チップ:高さ 44 ・ 丸 22 ・ 地 `#17181B` ・ 字 800 15。列の 左右の はしは とけて 消える(mask 9%)。
  - **長押し = その 列が 止まる**(`tick`)・ はなすと また 流れる。
  - **タップ** = チップの 写しが **パスの 名前の 所へ 飛んで いく**(0.52秒 ・ 弧を えがいて 少し 回り、小さく なって 消える)→ 名前が 1字ずつ めくれる + 入力にも 入る + その チップが 黄緑に。バイブ `sel`(つまむ)→ `pop`(はる)。パスが 少し しずんで もどる。
  - 同じ 物を もう1回 = `warn`。
  - 自分で 書いても よい(書いた 字は すぐ パスに 出る)。
  - 候補の リストは `TripSuggestions.json`(あとで サーバーから 季節で 変えられる ように)。
- Reduce Motion:流れない(横に スクロール できる 列)。飛ぶ 動き なし。

## 4. ② いつ 行く?(`T02`)
- **日数の 切りかえ**(高さ 44 ・ 4つ):`日帰り` `1泊2日` `2泊3日` `3泊4日`。黄緑の つまみが すべる(0.34秒)。カレンダーで 4日 以上 えらんだ 時は つまみ なし。
- カレンダー(角丸 22 ・ 地 `#121315`):今日から 4週間。はじまり と おわり = 黄緑の 丸(40)・ 間 = 黄緑 16% の 帯。今日 = 下に 黄緑の 点。月の 1日に `12月`(黄緑 Mono 8)。
- 下に 小さく `はじまり → おわり の 順に タップ`(えらび中は `おわりの 日を タップ`)。
- パスの FROM / TO / DAYS が その場で かわる。

## 5. ③ だれと 行く?(`T10`)
- **4列の 丸**(60 ・ 下に 名前 800 12.5):友だち + `リンク`(点線の 黄緑の 丸 + 鎖)。
- タップ = 入る / 出る:入ると **黄緑の 輪** + 右下に ✓(22 ・ ポンと 出る)。パスの 丸が 1つ ふえる。バイブ `pop` / `soft`。
- 下:`4人 ・ 1日 23枚を みんなで 撮る`。

## 6. ④ 表紙を えらぶ(`T11`)
- 写真を **横に スナップ**(118 × 157 ・ 角丸 18)。えらんだ 物は 黄緑の 輪 + 4 上がる + 右上に ✓。
- その 下に まとめ(角丸 22 の 箱):`[ピン] 大阪 / [カレンダー] 11/18 → 11/20 ・ 3日 / [星] 4人`(絵は 黄緑の 線の アイコン)+ 右に `変える`(押すと その 質問へ もどる)。
- `Trip を つくる`:パスが 少し 沈んで 上へ はねる(0.8秒)+ `projector` → `success` → **パス(T03)** へ(v83 の まま)。

## 7. iOS への おきかえ
| モック | iOS |
|---|---|
| 流れる 2列(CSS `mq`)| `TimelineView(.animation)` で `offset` を 時間で 動かす(2つ 並べて つなぐ)。長押しは `.onLongPressGesture(minimumDuration: 0.15, pressing:)` で 止める。**ScrollView の たての スクロールを うばわない**(列は 横の 動き だけ)|
| チップが パスへ 飛ぶ | `matchedGeometryEffect` か、チップの 位置(`GeometryReader`)→ パスの 名前の 位置へ `withAnimation(.timingCurve(.4,0,.2,1, duration:.52))` で 動く 写し(overlay)|
| 1字ずつ めくれる | `ForEach(Array(name.enumerated()))` + `.rotation3DEffect(.degrees(-92 → 0), axis: (1,0,0), anchor: .center, perspective: 0.6)` を `delay(i * 0.032)` |
| 日数の つまみ | `matchedGeometryEffect` の 黄緑の カプセル |
| 表紙の スナップ | `ScrollView(.horizontal)` + `.scrollTargetBehavior(.viewAligned)` |

## 8. 確かめる こと
1. `T01` `T14` `T02` `T10` `T11` と 比べる。`M30` の 動き(飛ぶ → めくれる)。
2. 候補を 長押しで 止められる。タップで パスと 入力の 両方に 入る。
3. どの 質問でも パスの 中身が その場で かわる。
4. 小さい 端末(SE)で パス ・ 題 ・ 2列 ・ ボタンが 重ならない(質問の 所は たてに スクロール)。
5. Reduce Motion で 流れない ・ 飛ばない。
