# PROMPT v74 ・ Home の 地を「単色」に ・ ガラスは ボタン だけ(モック `lattag_v70.html`)

> **いちばん 新しい 指示**。v68 の「フルブリードの ぼかし写真」の 背景は **やめる**。
> 正解:モック `mock/lattag_v70.html`(上の ボタン「地:黒 / 深い 緑 / 黄緑」で 3案を 比べられる ・ はじめは 黒)、元コード `mock/src/v70.css` `v70.js`、比べ `screens/H00_background_options.png`、見本 `screens/H01〜H18` `L01〜L09`(v74 で 撮り直し済み ・ 黒)。

## 1. 決まり(ユーザーの 指示)

- **ガラス(Liquid Glass)で おしゃれに するのは ボタン だけ**。
- **背景は 単色**(写真 ・ ぼかし ・ グラデーション ・ 光の 層 なし)。色は Lattag の テーマカラー か 黒。

## 2. 地の 色

| 案 | 色 | 中身の 色 |
|---|---|---|
| **① 黒(採用)** | `#0B0C0D` | 今まで どおり(白い 字 ・ 白い ガラス) |
| ② 深い 緑 | `#0F2A16` | 今まで どおり |
| ③ 黄緑 | `#C8F25A` | 字 ・ 線 ・ アイコン = 黒 `#0B0C0D`。ボタンの ガラス = 白 34% + ふち 白 75%。下の ピルの 選んだ 所 = 黒 地に 黄緑の 字。時計の 輪 ・ こま = 黒(モックの `[data-hb="L"]` の ルール) |

- **黒に した 理由**:オープニング(黒い 地)から そのまま つながる。黄緑の レンズ ・ ボタンが いちばん 目立つ。ガラスの ふちの 光も 黒の 上で いちばん きれいに 見える。
- 色は `Theme.homeBackground` 1か所で 持つ(あとで ② ③ に 変え られる ように)。③ に する 場合の 色の 入れかえも 同じ 所に まとめる。

## 3. 消す もの ・ 残す もの

| 消す(単色に する) | 残す |
|---|---|
| 全面の ぼかし写真(カメラ ・ Friends ・ Trip ・ Yesterday の ページ ごとの 写真)・ その 入れかわり ・ ゆっくり 動く Ken Burns | Mondo の ページの 地球(中身) |
| 写真の 上の 暗い ふち(vignette)・ ページの 暗い 帯 | 下の 緑の 弧(「今日を 撮る」の ドーム)= ボタン なので 今まで どおり |
| スクロール した 時の 上の ガラスの 帯 → **地と 同じ 単色の 帯**(下へ 28% で 透明に なる マスクは 残す) | 3分割の 線 ・ AF の 枠 ・ かぎ ・ シール |
| 写真を 読む ための 48px の ぼかし画像の 準備(Home の 背景 用 だけ) | 写真の 中身(友だちの ぼかし写真 ・ Trip の チェキ ・ きのうの 写真 ・ レンズの 中の 写真) |

## 4. ガラスに する もの(ボタン だけ)

- 上の HUD(押すと ライブパネル)・ 四すみの 4つ ・ 「友だちを よぶ」・ 「tomorrow, 9:00」・ 下の ページの ピル ・ 各ページの 丸い ボタン(QR など)。
- **ボタン でない 物は ガラスに しない**:見出し ・ カードの 地(Friends カードは 単色 `#111214` の まま)・ 上の 帯。
- 単色の 上の ガラスは 透けて 見える 物が 無い ので、**ふちの 白い 線(内側 1.2pt)と 上の 光(v62 の かたむきの 光)** で ガラスに 見せる。

## 5. 軽く なる

- 全面の 写真 ・ ぼかし ・ 入れかわりが 無く なる ので、Home は かなり 軽く なる。P11 の 計測(PERF.md)に 前 → 後 を 書く。

## 6. 確かめる こと

1. `H01` `H04` `H09` `H11` `H13` `L09` と 見比べる(地が 単色 `#0B0C0D`)。
2. ガラスが ボタン だけに なって いるか(画面の ガラスを 数えて 報告)。
3. スクロール した 時の 上の 帯が 単色か(`M19`)。
