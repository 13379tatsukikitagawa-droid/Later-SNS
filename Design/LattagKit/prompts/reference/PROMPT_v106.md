## 1. はじめての 設定:とちゅうで Home に 行かない
### 1-1. きまり
- 「はじめての 設定が 終わった」は **さいごの ながおし(はじめる)で だけ** 立てる。それ まで Home を 出さない。
- 進み具合を のこす:`@AppStorage("onboardingStep")`(`name` ・ `id` ・ `tag` ・ `friends` ・ `notice` ・ `go`)。アプリを 消して 開いても **その ページから** つづける(入力 済みの 名前 ・ ID ・ 写真も のこす)。
- サーバー(`UserDirectory`)には `onboardedAt`(日時)を 足し、**さいごに だけ** 書く。おかえり の 判定は `firebaseUID` が あって **かつ `onboardedAt` が ある 人 だけ**。`onboardedAt` が ない 人 → つづきの ページへ(2台目でも 同じ)。
- 途中で 書く もの(ID の 予約 ・ 写真)は 書いて よい が、それで Home に 行かない。**`UserDirectory` への 公開は さいごの ながおしの あと**(Name の 時点では 書かない)。
- **前から いる 人(`onboardedAt` が まだ 無い 人)を こわさない**:名前が 入った 記録が **この 版より 前に 作られて いれば** 終わった 人 と して あつかい、`onboardedAt` を あとから 書く。
- 完了の フラグは **ながおしが 終わった 時**に 書く(ながおしを 始めた 時では ない)。
- 通知の 許可 画面の あと、アプリが 前に もどっても(`scenePhase`)ページを 進めすぎない。
### 1-2. テスト
- UI テスト:各 ページで アプリを 終わらせて 開く → 同じ ページ。さいごまで 行く → Home。2回目の 起動 → Home。
- Unit テスト:`OnboardingRouter`(状態 → 出す 画面)の 表を そのまま テスト。

## 2. Name:「なまえ」と「0 / 12」が かさならない
- 入力の 字 ・ 「なまえ」(見本の 字)は **まんなか**(`multilineTextAlignment(.center)` ・ 見本は `prompt:` で)。
- 字数「0 / 12」は **線の 下 ・ 右**(上から 4pt ・ 11pt ・ Space Mono ・ 白 40%)。線の 中には 置かない。
- 線と つぎへ の 間は 20pt 以上(字数が かからない)。
- 見本:モック デモ `Name(字数)`(キーボード あり / なし)。

## 3. Friends:フィードの さいご
### 3-1. 灰色の 面の バグ
- 投稿の カードは **4つの 状態**の どれか だけ:読みこみ中(光が 流れる 面 ・ 1回 だけ 作った グラデーション を 動かす)/ ひらく まえ(ぼかした 写真 + 鍵 +「あした 9:00 に ひらく」)/ ひらいた(写真)/ 失敗(「もう一度」ボタン)。**何も 出ない 面は 作らない**。
### 3-2. さいごの 絵(モック デモ `Friends:フィードの さいご`)
- いちばん 下の 投稿の 下に **「きょうの フィルムは ここまで」**:
  - 絵:フィルムの 帯(穴 つき ・ さいごの 1こま だけ ライム)が **フィルムの 缶**(ライムの ラベルに `#`)へ 入る。帯が 6秒で ゆっくり 行き来 ・ 缶が 少し ゆれる ・ ライムの 小さな 点が 3つ 光る。**人 ・ 顔の 絵は 使わない**。SwiftUI の `Shape` で かく(画像に しない)か、ベクター の 画像 1枚 + 動かす 部分 だけ 別。
  - `END OF TODAY'S ROLL`(Space Mono 10 ・ ライム)/「きょうの フィルムは ここまで」(20 太字)/「あしたの 9:00 に、みんなの 1枚が ひらきます」/ 9:00 までの カウント(Space Mono 20 ・ ライム ・ `Text(timerInterval:)`)。
  - ボタン 2つ:`友だちを ふやす`(さがす 画面)・ `今日の 1枚を 撮る`(ライム ・ もう 撮った 日は 出さない)。
- 出る 動き:画面に 入ったら 下から 24pt + フェード(0.6秒)・ `soft` 1回。Reduce Motion:止まった 絵。
- 友だちが 0人 ・ 投稿が 0の 日も、この 絵を まんなかに 出す(字は「友だちを ふやすと、ここに ならびます」)。

## 4. Trip の 中
### 4-1. 右上の ボタンを わかりやすく
- 丸 2つ(QR ・ …)→ **字つきの カプセル 2つ**:`[QR] 招待` ・ `[歯車] 設定`(高さ 44 ・ 左右 12/14 ・ 13pt 太字 ・ 今と 同じ 黒い ガラス)。
- 招待 → パス(QR と KEY)。設定 → 5章の シート。
- 「TRIP ・ DAY 1」の 字が せまい 時は 字の ほうを 小さく(`minimumScaleFactor`)。ボタンは 小さく しない。
### 4-2. グループの チャットを もどす
- 入口:右下の **チャットの 丸**(未読の 数)+ その 左の **さいごの 1行の カプセル**(「れな あと そらだけ。はよ 撮って」)。どちらを 押しても チャット。
- チャットの 画面:モックの「グループの 部屋(チャット)」(`openRoom` ・ デモ `Trip の 中` → 右下の 丸)の とおり。上:Trip 名 ・「あと 2人で そろう」・ メンバーの 丸 ・ きのうの フィルム(撮ると ひらく)。下:`#` + メッセージ。
- 置き場所:**Trip の 共有ゾーン(CKShare)の 中**。メンバー だけ 読める。公開DB には 置かない。
  - 型は **今 ある `GroupChatMessage`**(`Later.ckdb` ・ `GroupChatStore.send` ・ `CKSyncEngine`)を そのまま 使う。**新しい 型は 作らない**(0 の 報告で わかった)。チャットの 画面も 今の `GroupChatRoomView` を 使い、**さいごの 1行の カプセル(`chatLine`)を つなぐ**。
  - 読みこみ:さいごの 50件 + 上へ スクロールで 前の 50件。新しい ものは `CKDatabaseSubscription`(共有DB)の 静かな push → 差分。
- **古い チャットの 画面が のこって いれば 消して、この 1つに する**。

## 5. Trip の 設定(1枚の シート ・ モック デモ `Trip の 設定`)
- 今の「TRIP SETTINGS」の 4ページ(Cover だけ の 画面 など)は **やめる**。下から 出る **全画面 シート 1枚**に まとめる。
- 上:とじる ・「Trip の 設定」・ **保存**(変えた 時 だけ ライム)。
- **パスの 見本**(幅 250 ・ 高さ 330 ・ -2° ・ 角丸 22):表紙 ・ `TRIP PASS` ・ 名前(Instrument Serif 40)・ 日にち ・ メンバー ・ 右に KEY(たて書き)。**下の 項目を 変えると すぐ 変わる**(0.32秒 ・ 0.97 → 1.02 → 1倍)。
- 項目(上から):
  | 項目 | 中身 |
  |---|---|
  | 表紙 | よこに ならぶ:`写真を えらぶ`(カメラロール ・ `PhotosPicker`)+ この Trip の 写真(新しい 順)。えらんだ 物は ライムの ふち + 3pt 上へ |
  | 名前 | 入力(角丸 16)+ 右に `7 / 16` |
  | 日にち | はじまり → おわり ・ 右に `−` `3日` `+`(1〜14日)。はじまりは 今日より 前に しない |
  | メンバー | 丸 40 + 名前 ・ 右上の ✕ で はずす(作った 人 だけ)・ さいごに `+ よぶ`(パス)|
  | お知らせ | `Trip の チャット`(スイッチ)|
  | 赤い 所 | `Trip を ぬける`(あなた だけ)・ `Trip を おわる`(みんな ・ **作った 人 だけ 出す**)|
- 保存:`success` ・ トースト「Trip を 更新しました」。保存しないで とじる → そのまま(きく 画面は 出さない)。

## 6. ぬける / おわる(モック デモ `Trip を ぬける` `Trip を おわる`)
### 6-1. 確認の シート(下から ・ うく カード ・ 中身の 高さ)
- 上に **パスの 小さな 見本**(180 × 150)・ まんなかに **点線**(切り取り線)。
- 見出し:「『大阪』を / おわりますか?」(おわる)・「『大阪』を / ぬけますか?」(ぬける)。
- 説明 3行(アイコン つき ・ 赤い 線の アイコン):
  - おわる:みんなが 入れなく なる / 招待の リンク ・ QR ・ **KEY(`#maple24`)**が 使えなく なる / 写真は すぐには 消えない(撮ってから 7日で 消える)
  - ぬける:あなた だけ 外れる(みんなは つづける)/ もう一度 入る には 招待を もらいなおす / あなたが 撮った 写真は のこる(7日で 消える)
  - **「合言葉」の 字は 使わない**(v98 で KEY に なった)。
- ボタン:**`長押しで おわる` / `長押しで ぬける`**(赤 `#FF453A` が 左から たまる ・ 1.2秒)・ 下に `やめる`。
### 6-2. 長押しの 間
- 赤が 左から たまる(`scaleEffect(x:)` ・ 左が 軸)。
- パスの 見本が 点線から **左右に すこし ひらく**(左 -3° ・ 右 +3° ・ 4pt)。
- バイブ:`tick` が だんだん 速く(220ms → 60ms)・ 70% から `buzz`。はなす → 0 に もどる(0.3秒)+ `soft`。
### 6-3. 終わった 時(Home へ)
1. `knock`。パスが **2つに やぶれて 落ちる**(左:左下へ -28° ・ 右:右下へ +32° ・ 0.62秒)。420ms で `thud`。
2. シート ・ 設定 ・ Trip の 画面が とじる(Trip の 画面は 下へ 40pt + 0.94倍 + フェード ・ 0.42秒)。
3. **Home の Trip ページ**を 出し、Trip の カードが 0.9倍 → 0.2倍 + 回って 消える(0.52秒)→ 「Take a trip」の 空の 状態が ふわっと 出る。
4. `success` + トースト「『大阪』を おわりました」/「『大阪』を ぬけました」。
- **Home には もう その Trip が のこらない**(ローカルの 一覧からも すぐ 消す ・ サーバーが おそくても 先に 消す ・ 失敗 したら もどして エラー)。
- Reduce Motion:やぶれる 動き なし ・ フェード だけ。
- 中身:おわる = 作った 人が 共有を やめる(`CKShare` を 消す)+ KEY を Worker で 無効に。ぬける = 自分の 共有の 参加を やめる(`CKShare` の 参加者から 外れる)。

## 7. 自分の アカウントが 重い(前の 版の データが たまって いる)
### 7-1. ふだんの 読みこみを 軽く(だれでも 効く)
- 起動時に 読むのは **今 つかって いる Trip(おわって いない もの)だけ**。おわった Trip ・ 古い グループは 一覧に 出さず、ひらいた 時に 読む。
- CloudKit は **差分 だけ**:`CKFetchDatabaseChangesOperation` / `CKFetchRecordZoneChangesOperation` + **変更トークン**を 保存。毎回 全部 読まない。
- 写真は 一覧で **サムネ だけ**(表示の 2倍 まで)。元の 写真は ひらいた 時。読んだ サムネは ディスクに キャッシュ(上限 200MB ・ 古い 順に 消す)。
- メインスレッドで デコード しない。`List` / `LazyVStack` で 画面外は 作らない。
- 1回の 問い合わせは 上限つき(`resultsLimit` 50)。
### 7-2. たまった 古い データの 片づけ(**DEBUG ビルド だけ** ・ たつきさん 用)
- 設定 > DEBUG の 状態メニューに **「データの 量」**:ゾーン ・ Trip ・ グループ ・ 写真の 数と 大きさ、いちばん 古い 日付。
- **「古い テストの データを 消す」**:一覧から えらんで 消す(自分が 作った ゾーン だけ ・ 他の 人の 共有には さわらない)。**自動では 消さない**。消す 前に 数を 出して 2回 確認。
- 端末の キャッシュ ・ SwiftData の 古い ストアを 消す ボタン(サーバーは さわらない)。
- リリース版には 出さない(`#if DEBUG`)。
### 7-3. 報告
- 前と 後で:起動 → Home の ms ・ メモリの 最大 ・ 読んだ レコード数。

## 8. 守る こと
- 新しい 色を 作らない(赤は 今の `#FF453A` だけ)。
- 部品を 重ねない ・ 押せる 物は 44pt 以上。古い 画面は 消す。
- **他の 人の データを 消す 処理は 作らない**(片づけは 自分の もの だけ)。

## 9. 確かめる こと(実機で)
1. はじめての 設定:各 ページで アプリを 終わらせて も、さいご まで 行かないと Home に ならない。2台目でも 同じ。
2. Name:キーボード あり / なし で「なまえ」と 字数が かさならない。
3. Friends:灰色の 面が 出ない。いちばん 下に フィルムの 絵 ・ 9:00 まで。
4. Trip:右上が 「招待」「設定」。チャットが ひらき、書くと みんなに とどく。
5. 設定:変える → パスの 見本が すぐ 変わる → 保存。
6. ぬける / おわる:長押し → やぶれる → Home の Trip ページで カードが 消える → もう 出ない(アプリを 開きなおしても)。
7. 自分の アカウントで 起動 → Home が はやく なった(数字)。
