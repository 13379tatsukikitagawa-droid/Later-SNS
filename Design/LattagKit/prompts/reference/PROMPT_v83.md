### A-2. 4つの 問い
1. **どこへ**(`T01`):大きな 入力(800 30 ・ 高さ 64 ・ 下に 黄緑の 線 ・ 空の 時の うすい 字 `どこへ?`)・ 候補の チップ(京都 ・ 沖縄 ・ 大阪 ・ 北海道 ・ 修学旅行 ・ 卒業旅行 ・ 合宿 ・ ライブ遠征 ・ 部活の 遠征)。チップを 押すと `京都 2泊3日` の ように 日数 つきで 入る。
2. **いつ?**(`T02`):日数の チップ(日帰り ・ 1泊2日 ・ 2泊3日 ・ 3泊4日)+ **3週間の カレンダー**(はじまり → おわり の 順に タップ ・ はじめ と おわりは 黄緑の 丸 ・ 間は 黄緑 16% の 帯)。下に `11/17(火)→ 11/19(木)・ 3日`。
3. **だれと?**(`T10`):友だちの 行(丸 44 ・ 名前 ・ 右に チェックの 丸 → 黄緑の ✓)・ `リンクで よぶ`(あとから QR ・ KEY でも 入れる)・ `3人 ・ 1日 23枚を みんなで 撮る`。
4. **表紙を えらぶ**(`T11`):3列の 写真(3:4 ・ えらぶと 黄緑の ふち ・ チケットの 表紙が ぷにっと 変わる)+ **確認の リスト**(どこへ ・ いつ ・ だれと ・ 右に `変える` = その 問いへ 戻る)。
- `Trip を つくる` → チケットが はねて(`projector`)→ パス(QR ・ KEY ・ `T03`)→ `Start the trip` → **Trip の ホーム**。
