## ねらい

- 前は 4つの ボタンが 小さく、しかも ふわふわ 動いていて **押しにくかった**。
- 今回は 次の 4つで 押しやすくする。
  - **大きく する**
  - **止める**
  - **親指の 近くに 持ってこられる**
  - **押すと 中身が 先に 見える**

## 1. 形と 位置

- 4つの ボタンは レンズの まわりの **レール**に のせる。レールは 角が まるい 四角(スーパー楕円 n=4、横の 半径 158pt・縦の 半径 168pt、中心は レンズの 中心)。
  ```swift
  func railPoint(_ deg: Double) -> CGPoint {   // 0° = 右、時計まわり
    let t = deg * .pi / 180, c = cos(t), s = sin(t)
    return CGPoint(x: 158 * copysign(pow(abs(c), 0.5), c),
                   y: 168 * copysign(pow(abs(s), 0.5), s))
  }
  ```
- 席は 4つ: 左上 225° / 右上 315° / 左下 135° / 右下 45°。
- レールは 白 34% の 点線(太さ 2・点の 間隔 7.6)。4つの 席には うすい 輪(半径 38・白 7%)。
- ボタン:
  - 白い 丸 **62pt**・黒 #121212 の ふち 2.4・下に 4pt の 平らな 影。アイコンは 26pt。
  - **押せる 範囲は 外側に 12pt 広げる**(タップの 判定は 約 96pt)。
  - 下に 札(Space Mono 7.5pt・字間 0.16em・黒地に 白・角丸 6)。
  - 前の版の ふわふわ 上下する 動き(`osf`)は **やめる**。押す 的は 動かさない。
- ロック中:
  - 灰色 #3A3A3C・アイコン #8E8E93。
  - 右下に 小さな 🔒 の 丸(20pt)。
- 通知:
  - 右上に 赤 #D8262C の 点(15pt)。
  - 点は 波紋が 1.8秒ごとに 広がる。

### READY の 席(右下 = 親指の いちばん 近く)

- 右下に 来た ボタンは **1.2倍**に なり、色が **黄緑 #C8F25A** に かわる。
- 札の 下に 中身の 数字(`0 / 12`、`OPENS 9:00`、`TOP 5` など、緑 #7EE08F)が 出る。
- 大きさは 角度で なめらかに 変える: `1 + 0.2 × max(0, cos(角度 − 45°))^10`。

## 2. まわす(ダイヤル)

- 次の どちらでも まわせる。
  - **レールの 上(レンズの 外 〜 ボタンの 少し 外)を 指で なぞる**
  - **ボタンを つかんで 9pt 以上 動かす**
- 指の 角度の 変化 = ダイヤルの 角度。
- 動きと バイブ:
  - つかんだ とき: `sel`
  - **15° ごと**: `tick`
  - **90° ごと**: `click`
  - レールが 緑 #7EE08F の 太い 点線に かわる。
  - 札は 半透明に する。
- はなした とき:
  - 速さ(直近 90ms)× 170ms 先を 予想して、一番 近い 90° へ **ばね**で 止める。
  - ばねの 値は stiffness 0.00062/ms²・damping 0.032/ms(少し 行きすぎて 戻る)。SwiftUI なら `.spring(response: 0.26, dampingFraction: 0.62)` が 近い。
  - 止まったら `soft`。
- まわすと、外の 文字の 輪(`LATTAG — TODAY — …`)は 同じ 角度で、レンズの 目盛りの 文字は 逆向きに 回る(フォーカスリングを 回している 感じ)。
- **並び順は 保存**して、次に 開いた ときも 同じに する(UserDefaults)。
- Home の 縦スクロールと ぶつからない ように する。
  - 最初の 動きが **円の 接線方向**(60% 以上)の ときだけ ダイヤルに する。
  - それ以外は ScrollView に ゆずる(`simultaneousGesture` で 判定)。

## 3. 1回 押す = カードが ひらく

- 押した 瞬間:
  - ボタンが 3.5pt 沈み、影が 消える。
  - `click` が 鳴る。
- はなすと、**その ボタンから カードが ひらく**。
  - 開き方: ボタンの 中心から 円が 広がる(半径 30 → 420)+ 0.92 → 1倍。520ms `cubic-bezier(.3,.9,.25,1)`。
  - 中身は 110ms 遅れて、55ms ずつ 下から 出る(`cubic-bezier(.3,1.4,.5,1)`)。
  - 押した ボタンは ぷるっと 回る(0 → −14° → 8° → 0、480ms)。
  - 鳴る バイブ: `pop`。
- カードが 開いて いる あいだの 後ろ:
  - レンズと 本体は **ぼかし 5・明るさ 0.72**。
  - 外側は 暗い 幕(中心 25% → 外 62%)。
  - 選んだ ボタン以外は 28% に うすく、色を ぬく。
  - 選んだ ボタンは カードの 上に 黄緑で 残る。
- カード:
  - 大きさ 258 × 262・角丸 28・紙色 #F4F1EA・黒の ふち 2.4・下に 6pt の 平らな 影。
  - 位置は レンズの 中心から ボタンの 方へ 横 14%・縦 10% ずらす。画面の 左右 14pt の 内側に おさめる。
  - 上の 列: 黒い 丸に 黄緑の アイコン(34pt)・**4つの 点**(今 どれか。今の 点だけ 横長 18pt)・✕(30pt)。
  - 見出し: Instrument Serif 38pt(`Yesterday` `New group` `Mondo` `Friends` `Shoot` `Develop` `Chat` `Join`)。
  - 下に **大きな GO ボタン**:
    - 高さ 50・黒・Inter 800 16pt。右に 緑 #3BD35A の 丸と →。
    - 文字: `Open` `Make one` `Explore` `Friends` `Shoot` `Develop` `Chat` `Join`。

| Mondo | ゆっくり 回る 地球(6秒で 1周)+ 人気タグ 3つ(1位は 黄緑)。ロック中は タグを ぼかし 3 + 🔒 |

| Shoot | フィルム 3こま(残りは 緑、使った こまは 灰)+ `2 left` |
| Develop | 今日の 写真 3枚(9:00 に 近づくほど ぼかしが 減る)+ 進行バー + `OPENS 9:00 · 17H 52M` |

- ロック中の GO は **`Shoot first`**(ベージュ地・黒い 丸に カメラ)。押すと 撮影へ 行く。開いた とき 360ms 後に `warn` が 鳴る。

### カードの 操作

- **GO** → 中身を 開く。
  - カードは 0.95 → 1.12 倍で 消える(300ms)。
  - `land` が 鳴り、170ms 後に 各画面へ 行く(今の 行き先と 同じ)。
- **同じ ボタンを もう一度 押す** → GO と 同じ。
- **カードを 左右に はらう**(44pt 以上):
  - ダイヤルが ±90° まわる。
  - となりの ボタンが 同じ 席に 来て、カードの 中身が 横に スライドして 入れかわる。
  - 鳴る バイブ: `pop`。
- **✕ / 幕を 押す / 下に はらう** → 閉じる。
  - 円が ボタンへ 縮む(300ms `cubic-bezier(.5,0,.7,.3)`)。
  - 鳴る バイブ: `soft`。

## 4. ながおし = 1動作で ひらく

- ボタンを **0.36秒 おさえる** → カードが 開く(`thud`)。
- 指を はなさずに **GO まで すべらせる**。
  - GO の 上に 乗った とき: `sel` が 鳴り、GO が 少し 沈み、→ が 右へ 出る。
- そこで はなすと すぐ 開く。GO 以外で はなした ときは、カードを 開いたまま に する。

## 5. 登場と ひまな とき

- Home に 入った とき:
  - レールが 線を 描くように 現れる(900ms)。
  - 4つの ボタンが **レンズの 中心から −160° 回りながら とびだして** 席に つく(760ms、90ms ずつ ずらす、少し 大きく なってから 戻る)。
  - 1つ 席に つく ごとに `tick`。
- 初めての 人には、次の 2つで 「回せる」ことを 見せる。
  - レールの 下に **`⟲ TURN`** の 小さな 札(黒地に 黄緑・Space Mono 8.5pt・上下に ゆれる)を 出す。
  - 1.7秒後に ダイヤルが 26° だけ 回って 戻る(説明の 文は 出さない)。
  - 一度 自分で 回したら 札は 消え、二度と 出さない。
- ひまな とき:
  - 9秒ごとに、**黄緑の 光の 点が レールを 1周**する(2秒)。
  - 光が 通った ボタンは 1.14倍に ぽよんと はねる。
  - バイブは 鳴らさない。カードが 開いている 時・まわしている 時・暗室に いる 時は 止める。
- 「視差効果を 減らす」が オンの ときは、とびだし・光の 1周・札の ゆれ・カードの 円の 開き方を やめて、フェードだけに する。
