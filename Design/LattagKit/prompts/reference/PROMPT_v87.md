## B. Home(`H01` `H19`)

### B-1. ロゴの 右上の `TODAY ⇄` を 消す → 切りかえは 右上の アイコン(`M28`)
- `Lattag` の 右上の `● TODAY ⇄`(v78 / v79)を **なくす**。
- 右上の アイコン(プロフィール写真)を **44 → 52pt**(右 18 ・ 上 49)。白い ふち 2pt は そのまま。
- アイコンの 左下に **小さな 印**(20pt の 黒い 丸 `#0B0C0D` + ふち 黄緑 1.5pt + 黄緑の `⇄` 11pt)= 「ここで 切りかえ」の 目じるし。
- **1回 タップ = プロフィール**(0.34秒 待って 2回目が なければ ひらく)。**2回 タップ = Lattag yesterday へ**。バイブ:1回目 `tick` ・ 2回目 `sel`。2回目で アイコンが 0.84 → 1.14 → 1倍(0.44秒)、印が 180° 回る。
- はじめて Home を 見た 時 だけ、1.8秒 後に アイコンの 下に `2回 タップで きのうへ` の 小さな 吹き出しを 2.6秒 出す。
- Lattag yesterday の 右上の アイコンも **同じ 大きさ(52)・ 同じ 印**。1回 = プロフィール ・ 2回 = 今日へ(v81 の まま)。
- スクロールして 上の 帯が 小さく なった 時(v80):アイコンは 0.77倍(40pt)。

### B-2. 時間の 帯:右はしまで 収める
- 実機は `のこり ■■■ 3 枚` が 右へ はみ出して いる。**左右に 内側の 余白**(左 9 ・ 右 16)を 取り、中身は 下の 順で 1行に 収める:
  `[輪 32] [ひらくまで / 消灯まで] [時刻 21pt] ……… [たて線] [■■■] [3 枚]`
- **`のこり` の 字は 出さない**(コマ 3つ + `3 枚` で 伝わる)。
- はみ出さない しくみ(SwiftUI):`HStack(spacing: 0)` + まんなかに `Spacer(minLength: 8)`。右の かたまり(コマ + 数字)は `.fixedSize()`、時刻は `.monospacedDigit()` `.lineLimit(1)` `.minimumScaleFactor(0.8)`。それでも 入らない 幅(小さい 端末 ・ 大きい 文字)では `ViewThatFits` で **ラベル(ひらくまで)を 先に 消す**。帯の 外へ はみ出す `offset` や 決めうちの 幅を 使わない。

### B-3. 「今日を撮る」= 地球儀(すける ガラスを やめる)
- 下の 半円は **中身の つまった 球**:地 = 上から `#1E6A33` → `#0E3A1B`(22%)→ `#07190C`(52%)→ `#040A06`。`backdrop blur` は 使わない。
- 上の ふち:黄緑の 線(1pt ・ 55%)+ 上へ 緑の 光(`rgba(59,211,90,.35)` ぼかし 60)。
- **経線 ・ 緯線**(黄緑 ・ 線 0.9pt ・ 20〜34%)が 球の 上に 見え、**ゆっくり 回る**(1秒に 約 3.6°)。北極は ふちの 少し 下(球を 手前へ 22° たおす)。緯線は 10° ごと(20°〜80°)、経線は 15° ごと。下へ 行く ほど うすく(100% → 12%)。
- 球の 上に **光る 点** 7つ(まちの あかり:まんなか 白っぽい 黄緑 2.2pt + まわりに ぼんやり 11〜17pt)。球と いっしょに 回る。
- 押した 瞬間 回る 速さが 一気に 上がって(約 27倍)、ゆっくり もどる。線が 明るく なる。
- カメラの 絵 + `今日を撮る` + コマ + `のこり 3こま` は そのまま(字の 下に 黒い 影 0 2 14 75% で 読みやすく)。
- iOS:`Canvas` + `TimelineView(.animation(minimumInterval: 1/30))`。画面の 外 / ほかの 画面の 下では 止める。Reduce Motion では 回さない(止まった 絵)。

### B-4. 大きな # の 上でも たてに スクロール できる
- 実機は # と レンズの 上を なぞっても 下へ 行かない。**どこを なぞっても Home 全体が たてに 動く** ように する。
- 原因の 多くは、レンズ / # に 付けた `DragGesture(minimumDistance: 0)` や `.highPriorityGesture` が スクロールを うばって いる こと。
  - レンズの「押している 間」は `Button` + `ButtonStyle` の `configuration.isPressed`、または `.onLongPressGesture(minimumDuration: 0, pressing:)` で 取る(`DragGesture(minimumDistance: 0)` を 使わない)。
  - 横スライド(4ページ)は `ScrollView(.horizontal)` + `.scrollTargetBehavior(.paging)` に して、たての `ScrollView` の 中に 置く。自前の `DragGesture` で 横を 取る 場合は `minimumDistance: 12` + 横の 動きが たての 2倍 以上の 時 だけ 反応。
  - # の 帯(かざり)は `.allowsHitTesting(false)`。
