# PROMPT v91 ・ オープニングを 黒に ・ 軽く(モック `mock/opening_v91.html`)

> **いちばん 新しい 指示**。v72 / v88 C / v89 B の オープニングの **背景と 動き** を 置きかえる(アイコン ・ 文字 ・ 9:00 の 形は そのまま)。
> 正解:動く 見本 `mock/opening_v91.html`(上の ボタンで L / Z / B を 切りかえ ・「ゆっくり ×4」)。コマ割り `motion/M31_opening_black_light.png`、1コマずつ `screens/opening_v91/L_*.png` `Z_*.png`。
> **作るのは L(軽い 版)**。Z(レンズへ ズーム)は ユーザーが えらんだ 時 だけ(下の 4章)。

---

## 1. 背景 = 黒
- オープニングの 地:**`#000000` の 単色**。緑の 光 ・ 黄緑の 光の 層(v72 の `gw`)は **なくす**。
- 起動画面(Launch Screen)の 色 `LaunchInk` も **`#000000`** に(0ms の 絵と 1px も 違わない ため)。`LaunchIcon` の 画像は そのまま(角丸 ・ うしろの 光 込み)。
- アイコンの 下の 光(影)は のこす:`rgba(200,242,90,.38)` ・ 78pt の 時 y 18 ・ ぼかし 40(大きさに 比例)。**影は 前もって 作った 画像**(毎コマ 計算しない)。

## 2. L:軽い 版(1.45秒)
| 時間 | 動き | 値 | バイブ |
|---|---|---|---|
| 0 〜 250ms | 起動画面と 同じ 絵で 止まる | — | — |
| 250 〜 700ms | アイコンが 左へ ・ 小さく(132 → 78)| **行きすぎ なし** ・ 450ms ・ `timingCurve(.22,1,.36,1)` | — |
| 330 〜 750ms | 「Lattag」が **1かたまりで** アイコンの うしろから 出る | 左 34pt → 0 ・ 不透明 0 → 1 ・ 420ms ・ 同じ カーブ。アイコンが 上(z)に いるので、うしろから 出て くる ように 見える(切り抜き なし)| 330ms `soft` |
| 640 〜 880ms | 右上に「9:00」 | 0.6倍 ・ 0 → 1倍 ・ 1 ・ 240ms ・ `timingCurve(.3,1.4,.5,1)`(左下 中心)| 640ms `pop` |
| 950 〜 1270ms | オープニングが ふわっと 消える | 不透明 1 → 0 ・ 1 → 1.03倍 ・ 320ms ・ `timingCurve(.4,0,.2,1)` | 950ms `land` |
| 990 〜 1470ms | **Home が 出る**(下に 先に 作って おく)| 1.04倍 → 1 ・ 不透明 0 → 1 ・ 480ms ・ `timingCurve(.2,.8,.2,1)` | — |
| 1470ms 〜 | Home の 入る 動き(ピント合わせ など)を ここから | — | — |

- **なくす 物**(重い ため):1字ずつの 動き ・ 文字の 切り抜き(mask の 幅を 変える)・ レンズの まばたき ・ シャッターの 光 ・ 丸く ひらく mask。
- 動かすのは **4つ だけ**(アイコン ・ 文字 ・ 9:00 ・ オープニング全体 / Home)、**`offset` ・ `scaleEffect` ・ `opacity` だけ**。
- アイコンは **132pt で 描いて `scaleEffect(78/132)`**(frame を 変えない)。文字は `Text` 1つ。
- 0.6秒 たったら タップで とばせる(すぐ 950ms へ)。通知 ・ リンクから 開いた 時は 250ms の あと すぐ 950ms へ。Reduce Motion:動かさず さいごの 組みを 0.5秒 → フェード。

## 3. なめらかに 動かす ため(v89 B の まま 守る)
- `Info.plist`:`CADisableMinimumFrameDurationOnPhone = YES`(120fps)。
- 1つの 時計:`keyframeAnimator`(または `PhaseAnimator`)で 表の 時間を そのまま。`DispatchQueue.main.asyncAfter` を 重ねない。
- オープニングの 間は 重い 仕事を しない(Firebase ・ 画像 ・ 地球儀 ・ カメラは 1.47秒 の あと か メイン スレッドの 外)。
- アイコン + 文字 + 9:00 の かたまりに `.drawingGroup()`。
- Instruments の Animation Hitches で **ヒッチ 0** を 確かめる。

## 4. (えらんだ 時 だけ)Z:レンズへ ズーム(1.65秒)
- 0 〜 880ms は L と 同じ。
- 880 〜 1080ms:レンズが まばたき(1 → 0.84 → 1 ・ 200ms)・ 900ms `shutter`。
- 980 〜 1500ms:**オープニング全体が アイコンの レンズの 中心を 軸に 大きく なる**(1 → 1.7 → 4.5 → 24倍 ・ 最後に 不透明 0)・ 520ms ・ `timingCurve(.45,0,.75,.4)`。
- 1220 〜 1660ms:Home が 1.25倍 → 1(軸 = Home の レンズの 中心)・ 不透明 0 → 1 ・ 440ms ・ `timingCurve(.16,1,.3,1)`。1300ms `land`。
- iOS:`scaleEffect(s, anchor: UnitPoint(x: lensX / width, y: lensY / height))`。大きく する 前に `.drawingGroup()`(大きく なると 少し ぼける が、動いて いる 間 なので よい)。

## 5. 確かめる こと
1. 起動画面 → オープニングで 色も 位置も 変わらない(黒 ・ チラつき なし)。
2. `screens/opening_v91/L_*.png` の 0 / 400 / 700 / 1100 / 1450ms と 見比べる(Slow Animations)。
3. 120Hz の 端末で ヒッチ 0。
4. 1.5秒 以内に Home。とばせる ・ 短い 版 ・ Reduce Motion。
