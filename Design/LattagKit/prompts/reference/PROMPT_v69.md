> **いちばん 新しい 指示**。Home の **ヘッダー ・ 四すみの ボタン ・ まんなかの レンズ** は この ファイルが 優先(v68 の フルブリードの 上に 足す)。
> 正解:モック `mock/lattag_v67.html`、元コード `mock/src/v66.css` `mock/src/v66.js`(約 150行)、見本 `screens/H01〜H18` `L01〜L11`(v69 で 撮り直し済み)、動き `motion/M17_home_camera_boot.png` `M18_iris_shutter.png` `M19_header_compact.png`。

## 0. ねらい

- Home ぜんたいを **カメラの ファインダー** に 見せる。ただし 写ルンですの 本体の 絵には しない(前に「写ルンですすぎる」と 言われた)。**今の カメラアプリの 画面の 言葉**(上の 表示 ・ 角の かぎ ・ 3分割の 線 ・ しぼり羽根 ・ 録画の 点)で 作る。
- 表示する 数字は **ぜんぶ 本物の 意味が ある もの** だけ(のこり 時間 ・ のこり こま ・ 今日の 進み)。ISO や f値 などの にせの 数字は 出さない。

## 1. ヘッダー = カメラの 上の 表示(HUD)

### 1-1. 形(390pt 幅)

| 部品 | 位置 ・ 大きさ | 見た目 |
|---|---|---|
| ロゴ `Lattag` | 左 22 ・ 上 56 ・ 高さ 40 | Inter 900 30pt ・ 字間 -0.065em ・ 白 |
| モード `TODAY ・ YESTERDAY` | 右から 78 ・ 上 61 ・ 高さ 30 | **カメラの PHOTO / VIDEO の 切りかえ** と 同じ 考え方。Space Mono Bold 10.5 ・ 字間 0.16em ・ 大文字。選んだ 側 = 黄緑 `#C8F25A` + 下に 4pt の 黄緑の 点(光る)、もう 片方 = 白 50%。地 ・ ふち なし。押すと Lattag yesterday へ(今までと 同じ) |
| アバター | 右 20 ・ 上 54 ・ 44pt | 自分の 写真 + 白い ふち 2pt。**まわりに 今日の 撮影の 進みの 輪**(半径 25〜26.6pt ・ 黄緑 = 撮った 割合 ・ 残りは 白 22%) |
| **HUD の ガラス** | 左 16 ・ 上 108 ・ 358 × 46 ・ 角丸 23 | ガラス(白 16% + ぼかし 18 ・ ふち 白 30%)。中身は 左から ↓ |

HUD の 中身(左から):
1. **輪 32pt**:今日の 進み(9:00 → 24:00。夜は 24:00 → 9:00)を 黄緑の 弧で。まんなかに **録画の ような 黄緑の 点 7pt**(2秒ごとに 波紋)。
2. ラベル `消灯まで`(夜 0:00〜9:00 は `ひらくまで`)・ Inter Bold 11.5 ・ 白 72%。
3. **時計 `8:07:12`**:Space Mono Bold 18 ・ 等幅数字。**秒まで 1秒ごとに 進む**(秒は 白 55%)。変わった 桁だけ 下から 入れかわる。
4. 区切りの 線(1 × 20 ・ 白 20%)。
5. **フィルムの のこり**:小さな こま 3つ(8 × 12 ・ 角丸 2)= のこりは 黄緑で 光る、使った 分は 枠 だけ +「**3**」(Inter 800 16)+ `EXP`(Space Mono 9 ・ 白 60%。カメラの 「のこり 枚数」の 言い方)。
6. 右端:下向きの 矢印の 丸 34(白 16%)。HUD を 押すと 今までの ライブパネルが 開く。

### 1-2. 下へ スクロールすると まとまる(新しい 技術)

- スクロール 60pt を こえたら、ヘッダーが **1つの 小さな ガラスに まとまって ダイナミックアイランドの すぐ 下へ** 動く(`M19`)。
  - ロゴ ・ モード:上へ 10pt + 0.86倍 + 消える(0.35秒)
  - HUD:左 97 ・ 上 54 ・ 196 × 38 に 縮む(0.55秒 ・ ばね `timingCurve(.3,1.15,.4,1)`)。ラベル ・ 矢印 ・ `EXP` を 隠し、時計を 15pt に。
  - アバター:0.73倍 ・ 上 52。
  - うしろの ぼかしの 帯は 高さ 108 に。
  - 切りかわる 瞬間に バイブ `tick`(0.3秒に 1回 まで)。
- 戻ると 逆の 動き。
- SwiftUI:iOS 26 は `GlassEffectContainer` + `glassEffectID` で **ガラスが 溶けて 形を 変える**(HUD と アバターを 同じ ID の なかまに)。iOS 25 以下は `matchedGeometryEffect`。スクロール位置は `onScrollGeometryChange`。
- 時計:`TimelineView(.periodic(from: .now, by: 1))` + `.contentTransition(.numericText(countsDown: true))`。画面が 出て いない ときは 止める。

### 1-3. Home に 入る ときの 動き(`M17`)

- HUD の ガラスが **左から 右へ ひらく**(clip で 0 → 100% ・ 0.7秒 ・ 0.26秒 おくれて)。

## 2. 四すみの ボタン:大きく ・ レンズから 飛び出す

### 2-1. 形

- **62pt の 丸 → 78 × 78pt の 角丸 26 の ガラス**(押せる 所が 1.6倍)。ラベルを **ボタンの 中**(下から 18pt)に 入れる:Space Mono Bold 8.5 ・ 字間 0.14em。アイコンは 28pt で 上に 寄せる。
- 中心の 位置(レンズの 中心から):左上 (-135, -141) ・ 右上 (135, -141) ・ 左下 (-135, 133) ・ 右下 (135, 133)。
- **角の かぎ**:それぞれの ボタンの **外側の 角** に、カメラの ファインダーの かぎ(20 × 20pt ・ 線 2pt ・ 角丸 9 ・ 白 85%)。ボタンの 角から 9pt 外。押すと 0.8倍に しまる。鍵の ボタンは 白 40%。
- 鍵の 印:24pt ・ ボタンの 右上(-6, -6)。赤い 点(Friends の 申請):18pt ・ 右上。
- 押した とき:0.92倍。

### 2-2. 出て くる 動き(Home に 入る たび)

1. 0.42秒 後から、4つの ボタンが **レンズの 中心から 飛び出して** それぞれの 角へ(0.28倍 → 1.08倍 → 1 ・ 0.72秒 ・ `timingCurve(.3,1.1,.4,1)` ・ 70ms ずつ ずらす)。
2. その 0.38秒 後に、かぎが 外から 14pt + 1.5倍 → ぴたっと 止まる(0.46秒 ・ ばね)= **ピントが 合った 合図**。
3. 1つ 止まる ごとに バイブ `tick`(4回)。
- Reduce Motion:飛び出さず、その場で フェード。

## 3. ファインダー

- **3分割の 線**:ファインダー(左 12 ・ 上 180 ・ 366 × 432pt)に 白 1pt の 線を たて 2本 ・ よこ 2本。ふだんは **白 7%**(ほとんど 見えない)、レンズを 押して いる 間は 20%。
- **AF の 枠**:レンズを 押して いる 間 と Home に 入った 直後 1.35秒、レンズの まわりに 黄緑の 角丸の 四角(230pt ・ 角丸 30 ・ 線 1.5 ・ 90% + 光)が 250 → 230 に しまって 出る。

## 4. レンズの しぼり羽根(新しい 技術 ・ `M18`)

- レンズの ガラスの 中(半径 117pt の 円で 切る)に **6枚の しぼり羽根**(濃い グラファイト `#2a2a2e → #0d0d0f` ・ 96% ・ ふち 白 22%)。ふだんは 円の 外に かくれて 見えない。
- **押して いる 間**:羽根が 内へ 入り、まんなかに **六角形の 穴**(羽根の 内側の 線が 中心から 72pt)。0.38秒 ・ ばね。羽根は 1枚ずつ -18° ねじれて いて、しまると 穴が 少し 回って 見える。
- **はなした 瞬間**(撮影へ):穴が 0 まで **一気に しまって**(0.09秒)→ ひらく(0.11秒 後)= シャッター。白い 光 ・ 線が はじける 動き(v61)と 同時。
- 指が はずれた ときは ゆっくり ひらく だけ。
- カメラの アイコンは 羽根より 上。
- SwiftUI:6枚を `ForEach` で 回して 置いた `Rectangle`、`offset(y:)` を 1つの 値(`aperture`)で 動かす。`Circle().clip`。押す 間は `.spring(response: 0.38, dampingFraction: 0.75)`、シャッターは `.easeIn(duration: 0.09)` → `.easeOut(duration: 0.16)`。バイブは 今までの `shutter`。
- 重さ:羽根は 6枚の 単純な 図形 だけ(ぼかし なし)。ふだんは 描かない(`opacity 0` ではなく 描画しない)。

## 5. 新しい 技術の まとめ

| 技術 | 使う 所 | 代わり(古い iOS) |
|---|---|---|
| Liquid Glass の 形が 変わる(`GlassEffectContainer` ・ `glassEffectID`) | ヘッダーが 1つに まとまる | `matchedGeometryEffect` + `.ultraThinMaterial` |
| `TimelineView` + `numericText` | 秒まで 進む 時計 ・ のこり こま | 1秒ごとの `Timer` |
| `onScrollGeometryChange`(iOS 18) | まとまる タイミング | `GeometryReader` + `PreferenceKey` |
| `keyframeAnimator` | 四すみが 飛び出す ・ かぎが 止まる | `withAnimation` を 時間差で |
| Canvas / Shape の アニメ | しぼり羽根 | そのまま(iOS 15〜) |
| `sensoryFeedback(.impact(weight: .light))` | かぎが 止まる ・ まとまる | `UIImpactFeedbackGenerator` |
| ガラスの 光が かたむきに ついて くる(v62) | HUD ・ 四すみ | 止まった 光 |

## 6. 守る こと

- **にせの カメラの 数字**(ISO ・ f値 ・ シャッター速度)は 出さない。
- 写ルンですの 本体 ・ 緑の 箱 ・ ダイヤルの 絵は 使わない。
- ガラスは 1画面 8枚まで(HUD 1 ・ 四すみ 4 ・ 上の チップ 1 ・ 下の ピル 1 ・ 目次 1 = 8)。
- 時計 ・ 波紋 ・ かぎの 動きは、Home が 見えて いない ときと Reduce Motion で 止める。
- 押せる 物は 44pt 以上(四すみ 78 ・ HUD 46 ・ モード 30 は **左右に 7pt ずつ 押せる 所を 足して 44**)。

## 7. 確かめる こと

1. `H01` `H04` `H06` `H07` `H09` `H11` `H13` `L01` と 見比べる(ヘッダー 2段 ・ 四すみの 角丸 ・ かぎ)。
2. 時計が 1秒ごとに 進むか、9:00 前は「ひらくまで」に なるか。撮ると こまが 1つ 枠に なり、アバターの 輪が 進むか。
3. 下へ スクロール 60pt で まとまり、戻すと 広がるか(`M19`)。
4. Home に 入ると 四すみが レンズから 出て、かぎが 止まるか(`M17`)。

6. iPhone SE(375)・ Pro Max(440)で ヘッダーの 字が 重ならないか(モードは アバターの 左に 寄せる)。
7. 重さ:Home で 何も しない とき CPU 15% 以下。
