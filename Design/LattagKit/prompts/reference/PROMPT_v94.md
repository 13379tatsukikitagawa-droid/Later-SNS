## B. ID(@ユーザー名)を アプリに 作る

### B-1. きまり

| かえる | **14日に 1回**。前の ID は **14日間 だれも とれない**(その 間 古い QR ・ リンクは 新しい ID へ 飛ぶ)|

### B-2. データ(Firebase)
```
users/{uid}
  handle: "yui_0612"            // 小文字
  handleChangedAt: Timestamp
  nameSearch: "ゆい"            // 名前を 小文字 + カタカナ → ひらがな に した もの(前方一致 用)
  discoverableByName: true      // 設定「名前で 見つかる」(はじめは オン)
usernames/{handle}              // ID の 予約(これで 同じ ID を ふせぐ)
  uid, createdAt, releasedAt?   // かえた 時は 古い doc に releasedAt(+14日)を 入れて のこす
```
- **ID を とる / かえる は Cloud Functions(callable `claimHandle`)の トランザクション 1回**で:`usernames/{new}` が 無い(か releasedAt を すぎた)→ 作る ・ `users/{uid}.handle` を 書く ・ 古い doc に `releasedAt`。クライアントが 直接 書かない(Security Rules で `usernames` は 書きこみ 禁止)。
- **空き確認** `checkHandle`(callable ・ 0.35秒 待って から 呼ぶ ・ 結果は キャッシュ)→ `ok` / `taken` / `invalid(理由)` + 候補 3つ。
- **いま ID が 無い 人**(すでに 使って いる 人):次に ひらいた 時に **ID を きめる シート**(とじられない ・ 候補を 入れて おく)。
- 名前の 変更 → `nameSearch` も 同じ 関数で 書きかえる。

### B-3. はじめての 設定:**Name の つぎに 1ページ**(`O12` `O13`)
- 流れ:サインイン → Name → **ID** → タグ → 友だち → 通知 → はじめる。上の 番号は Name と 同じ `01 / 04 YOU`。もどる = Name。
- 形:題 `ID`(Instrument Serif)+ `友だちが さがす ときに つかう ・ あとで かえられる` ・ 入力欄 ・ `つぎへ`。
- **はじめから 候補が 入って いる**(名前を ローマ字に + `_月日` など。例 ゆい → `yui_1118`)。すぐ `つぎへ` で よい。
- 入力欄(共通部品 `HandleField`):
  | 状態 | 見た目 |
  |---|---|
  | 入力中 | 右に くるくる(ライム)・ `たしかめて います…` |
  | つかえる | 右に **ライムの ✓** ・ `@yui_1118 は つかえます`(ライム)・ `tick` |
  | つかわれて いる | ふち 赤 ・ 右に `!` ・ `もう つかわれて います` ・ **候補の チップ 3つ**(ライム 10% ・ Mono)→ タップで 入る ・ `warn` |
  | きまり 違反 | ふち 赤 ・ 理由(例 `3文字 以上`)|
  - 高さ 56 ・ 角丸 18 ・ 左に ライムの `@`(Inter 800 20)・ 字は **Space Mono 19 太**。

### C-2. さがす(字を 入れると 下が 結果に かわる)
| 入れた 字 | 出る 物 |
|---|---|
| `@` か 英数字 | **ID が ぴったり**(大きな カード:アイコン 64 + ライムの 輪 ・ ふち ライム 45%)→ その 下に **`@… で はじまる ID`**(2文字 から ・ 6人 まで)|
| ひらがな ・ カタカナ ・ 漢字 | **名前**(先頭 から 一致 ・ ひらがな ⇄ カタカナ は 同じ)・ `共通の 友だち が 多い 順` ・ 8人 まで |

- 一致した 部分は **ライムの 字**。結果は 0.26秒 で 下から(28ms ずらし)。
- ボタンの 状態:`+ 追加`(ライム)→ 押す → `申請中`(灰)・ `承認`(白 = 相手から 来て いる)・ `チャット`(もう 友だち)。
- **プライバシー(大事)**:
  - **ID の ぴったり** は いつでも 出る(ブロック した / された 人は 出ない)。
  - **ID の 前方一致 と 名前** は `discoverableByName == true` の 人 だけ。
  - 検索は **callable `searchUsers`**(サーバー)で:返す のは `uid ・ name ・ handle ・ アイコン ・ 共通の 友だちの 数` だけ。1人 1分 30回 まで。クライアントから `users` を 自由に 読ませない。
  - 設定 › プライバシー に `名前で 見つかる`(オン / オフ)を 足す。
- おすすめの 理由:`共通の 友だち`(友だちの 友だち ・ サーバーで 数える)・ `あなたの リンクを ひらいた`(招待リンク)・ `連絡先`(**ゆるされた 時 だけ** ・ 電話番号 / メールは ハッシュで 照合 ・ 連絡先 そのものは 保存しない)。
