## 1. 撮る 近道を なくす ・ 丸を 下へ 大きく
- Home の 下の **地球 ・ # ・ チェキ ・ しまう バー ・ ドラッグ ・ スクロールで 自動** は ぜんぶ **消す**(View も 道も のこさない)。v116 ・ v117 の 案も 作らない。
- 撮る 入口は のこって いる 物で 足りる:NEXT カード(「撮ろう」)・ Home の 横スライドの Camera ・ Today カードの SHOOT ・ Friends 画面の「撮る」。
- 空いた 所は **色の 丸 3つを 大きく して 下へ**:
  - 黒い カプセル(ガラス)は 使わない(丸 だけ が うく)。
  - 丸 68pt ・ ふち ミルク `#FAFAF7` 3.5pt ・ 影 `0 12 24 / 55%`。中の 絵 30pt(線 2.1)。
  - 少し かたむける:友だち -6° ・ Trip +4° ・ きのう -3°。押すと 0° + 0.9 → ばねで もどる。
  - 1つの 押せる 所 96×104pt ・ 間 10pt ・ 名前 13.5pt Bold ・ 色 `#F4F1EA`。
  - 置く 高さ:NEXT の 点(ページ)の 下 40pt くらい。下の 安全領域に かからない。
  - 数の 丸(バッジ)22pt ・ 字 12pt。
  - **カメラ(写真)の 丸は 出さない**:Friends ・ Trip ・ きのう の ページに いる 時も、列は 友だち ・ Trip ・ きのう の 3つ だけ(前は ほかの ページで 左に ミルクの カメラの 丸が 出て いた → 消す)。カメラの ページへは 横スライドで 行く。

## 2. 字の 形(v115 を 上書き):見出し = 明朝 + セリフ(はじめの モックを 少し 変えた 物)
| 役 | 書体 | 変えた 所(はじめの モック から) |
|---|---|---|
| 見出し(英語)`Friends` `Trip` `Today` `New trip` `Nov 2026` ・ 統計の 数字 | **Instrument Serif** Regular(アクセントは Italic) | 字の 間を つめる -0.015em ・ アクセントは **1画面 1語 だけ** 斜体 + 色(`Tr`*`ip`* = 空色)|
| 見出し(日本語)名前 ・ Trip 名 ・「リンクを 送る」 | **Noto Serif JP Black**(名前は `Later Mincho` の まま ファイルを 差しかえ) | Bold → **Black**(小さな 画面でも つぶれない 強さ) |
| 本文 ・ ボタン ・ ラベル ・ 時計の 数字 | SF Pro + ヒラギノ角ゴ の 太字(v115 の まま) | はじめの Inter の 細字 ・ Space Mono は 使わない |
| ロゴ `Lattag` | 今の まま | — |

- どこが 見出し か:**はじめの モックで `Typo.title`(`--ttl` / `--disp`)を 使って いた 所 ぜんぶ** + ポップの 大きな 見出し(Friends ・ Trip の 画面の 名前 ・ プロフィールの 名前 ・ Trip の パスの 名前 ・ Today の 数)。リストは `mock/src/v104.css` の 下の `:is(...)`。
- Instrument Serif は **太字に しない**(にせの 太字 禁止 ・ `.bold()` を つけない)。日本語は Instrument Serif の 後ろに Noto Serif JP Black を つなぐ(`cascadeList`)。
- Noto Serif JP Black は OFL。**JIS 第1 ・ 第2水準 + かな だけに 切って** 入れる(大きさを 報告)。
- `Typo.title(size:)` 1か所から。チェキの 手書きの 字は 今の まま。

## 3. Home の Friends の かたまり(下に スクロール した 所)
- 上:`Friends`(40pt セリフ)・ その 下に 説明 1行(12pt ・ 灰色 ・ 長い 時は `…`)・ 右に 白い 丸の →(44pt)。撮った 人が いる 時は ライムの 点 +「3人 撮った ・ 9:00 に ひらく」。
- 申請の 帯:ピンク(`#FF9CC8` 12% の 面 + 55% の ふち)・「確認 ›」も ピンク。
- まんなか 2つ(横 1.12 : 1 ・ 間 12):
  - **リンクを 送る**:ライムの カード(高さ 168 ・ -1.6° ・ 角丸 26)・ 左上に ピンクの テープ ・ 黒い 角丸の 絵(46)・ 右上に 白い 星の ステッカー ・ 下に「リンクを 送る」(25pt 明朝 Black ・ 1行)+「LINE ・ AirDrop」。
  - **QR を 見せる**:**白い チェキ**(+2.4° ・ 中に 本物の QR を 大きく ・ 下の 白い 所に「QR を 見せる」13pt)。
- 下 2つ(高さ 54 の 丸い 帯):「QR を 読む」と「名前 か @ID」(さがす)。
- **字は 1行**(`lineLimit(1)`)。押すと 0.94 → ばね。はじめて 出る 時は 下から 順に(70ms ずつ)。
- ボタンの 行き先は 今と 同じ(v95 の きまり)。
