## 1. まんなか = 黄緑の シャッターボタン(撮れる とき だけ)

撮れる 状態(のこり 1〜3 こま)で、カメラの 絵の 代わりに 出す。**3枚 撮った あと(きのうの 写真が 見える 状態)は 今まで どおり**。

座標は レンズの 312 の 座標(表示は × 0.71)。中心 = レンズの 中心。

| 部品 | 値 |
|---|---|
| 外の 輪 | 半径 50 ・ 線 5 ・ 黄緑 `#C8F25A` ・ 光(`shadow` 黄緑 70% ・ 半径 7) |
| 外へ 広がる 波(呼吸) | 半径 50 ・ 線 2 ・ 黄緑。1 → 1.32倍 ・ 不透明 .55 → 0 ・ 2.8秒 くり返し(70% で 消えて 待つ)・ `timingCurve(.3,0,.3,1)` |
| ボタンの 影 | 半径 46 ・ 下に 5 ・ 黒 55% → 0(放射) |
| ボタン | 半径 40 ・ 放射グラデーション(中心 36% / 30%):`#EEFFB0` → `#C8F25A`(38%)→ `#8FCB2E`(85%)→ `#6FA622` ・ ふち 白 55% 1.2 |
| ボタンの # | アプリアイコンと 同じ # を **幅 37**(632 × 0.058)・ `#0B0C0D` |
| つや | だ円 30 × 14 ・ 中心 (-15, -21) ・ -28° ・ 白 55% |

- **押して いる 間**:ボタン 0.88倍(0.22秒 ・ `timingCurve(.3,1.5,.5,1)`)、外の 輪 1.08倍 + 不透明 .6、波は 止める。しぼりが しまる(v69)のは そのまま。
- **はなす**:今まで どおり シャッター(v69 ・ v71)。
- 3枚 撮りおわり ・ Reduce Motion では 波を 止める。
- SwiftUI:`ZStack { 波(Circle().stroke) ; 輪 ; ZStack { 影 ; Circle().fill(RadialGradient) ; HashShape().fill(.ink) ; つや } }`。# は アイコンと 同じ `HashShape`(4本の 角丸の 棒)を 使い回す。

## 2. レンズ全体を テーマカラーに

| 場所 | 前 | 後 |
|---|---|---|
| ガラスの 地(半径 113) | 青っぽい 黒 `#1B2433 → …` | **緑っぽい 黒**:`#1D2E16 → #070B06(45%)→ #020302(85%)→ #0C0F0B` |
| **字の 帯の ふち(半径 137.5)** | 白 14% 1pt | **黄緑 `#C8F25A` 90% ・ 3pt**(プロの レンズの「色の 輪」と 同じ 考え方)|
| 中の 輪(半径 92 / 70) | 青 10% / 黄緑 10% | **緑 `#3BD35A` 16% / 黄緑 18%** |
| 反射 1(左上) | 紫 42% | **黄緑 `rgba(200,242,90,.34)`** ・ 幅 56% ・ 高さ 34% ・ 左 14% ・ 上 10% ・ -18° |
| 反射 2(右下) | 黄緑 32% | **緑 `rgba(59,211,90,.34)`** |
| 回る 色の 帯 | 青 ・ 紫 14% | **黄緑 ・ 緑 16%** |
| しぼり羽根 | グラファイト `#2a2a2e → #0d0d0f` ・ ふち 白 16% | **緑がかった 黒 `#252B22 → #0A0D09`(97%)・ ふち 黄緑 22%** |

- 白い ハイライト ・ 小さな 光の 点 ・ 金属の ふち ・ ギザギザ ・ 刻印は v71 の まま。
