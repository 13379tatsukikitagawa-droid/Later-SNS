## 0. なぜ 作り直すか
- 今の 形は「ふつうの カウントダウン」+ 意味の わかりにくい バー(0:00 / 9:00 / 24:00 / 9:00 OPEN)。Lattag らしさ(フィルム ・ チェキ ・ # ・ 9:00 に ひらく)が 弱い。
- ライブ アクティビティで **自動で 動くのは 数字(`Text(timerInterval:)`)と 進みの 線(`ProgressView(timerInterval:)`)だけ**。この 2つを 主役に する(毎秒の 更新を 送らない)。
- ライブ アクティビティは **最長 8時間**。夜 23:00 から 朝 9:00 まで 1つで つなげない → **夜と 朝の 2幕** に 分ける。

## 1. 流れ
| 時間 | 形 | 始め方 / 終わり方 |
|---|---|---|
| 23:00 〜 23:50 | **A フィルム** | 3枚 撮って いない 人だけ。アプリ 起動中は アプリ から、ほかは **push-to-start**(iOS 17.2〜)|
| 23:50 〜 24:00 | **D ラストコール**(ライム)| サーバーが **更新の push**(`alert` なし ・ 音なし)で `phase = .lastCall` |
| 3枚 撮った 時 | 「今日の フィルム ・ 3/3 ・ 9:00 に ひらく」に して **すぐ 終了** | `dismissalPolicy: .after(+30分)` |
| 24:00 | 「現像に 入りました ・ 9:00 に ひらく」で 終了 | `.after(+1時間)` |
| 8:30 〜 9:00 | **E 朝の 部** | push-to-start(きのう 1枚 以上 撮った 人 だけ)|
| 9:00 | 「ひらいた ・ 見る」→ タップで きのう へ | `.after(+1時間)` |
- 設定 › 通知 に **「ライブ アクティビティ」**(夜 / 朝 を 別々に オン ・ オフ)。

## 6. データ
```swift
struct LattagLiveAttributes: ActivityAttributes {
  struct ContentState: Codable, Hashable {
    var phase: Phase            // .film, .lastCall, .done, .opening, .opened
    var shotsTaken: Int         // 0...3
    var endsAt: Date            // 24:00 か 9:00
    var frameThumbs: [String]   // App Group の ファイル名(ぼかし 画像)
    var friendCount: Int        // 朝の 部
    var devPercent: Int         // 現像 %
  }
  var dayKey: String            // "2026-11-18"
}
enum Phase: String, Codable { case film, lastCall, done, opening, opened }
```
- push-to-start の トークンは アプリ 起動時に サーバーへ(`Activity<LattagLiveAttributes>.pushToStartTokenUpdates`)。
- サーバー(Cloud Functions + APNs `liveactivity`):23:00 start / 23:50 update / 24:00 end / 8:30 start / 9:00 update → end。**ユーザーの 時間帯**で 送る。

## 7. 確かめる こと
1. 見本 `widgets/live/A_film` `D_lastcall` `E_opening`(+ `_island`)と 比べる(ロック画面 ・ 島の 小 ・ 最小 ・ ひらいた 形)。
2. 時計を 23:00 / 23:50 / 24:00 / 8:30 / 9:00 に して 切りかわる。3枚 撮ると すぐ 終わる。
3. 秒が 自動で 動く(アプリから 毎秒 送って いない)。
4. 友だちの 本物の 写真が ライブ アクティビティに 出ない。
5. 設定で 夜 / 朝 を オフに できる。
