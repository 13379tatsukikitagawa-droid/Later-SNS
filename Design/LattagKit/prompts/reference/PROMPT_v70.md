## 0. ねらい

- **キャラクターを 使わない**。人は いつも **本物の 写真の 丸**。
- **Shake は この カードに 置かない**(Friends 画面の 中には 残す)。
- だれもが 知って いる SNS の 形に そろえて、説明 なしで わかる ように する:
  - 友だち あり → **Instagram の ストーリーの 丸**(撮った 人は 色の 輪)
  - 申請 → **Instagram の「フォローリクエスト」の 1行**
  - だれも いない → **Instagram の「おすすめ」の 横に すべる カード**(申請して きた 人 + 招待の しかた)

## 1. カード ぜんたい

- 地 `#111214` ・ 角丸 30 ・ ふち 白 8% ・ 左右 14pt の 外の 余白(今の 位置の まま)。**高さは 中身に 合わせる**(固定しない)。上 18 ・ 下 20。
- 見出し(高さ 40 ・ 左 20):`Friends`(Instrument Serif 32 ・ 頭の **F だけ 緑 `#3BD35A` の 斜体**)+ 撮った 人が いれば `● 2 SHOT TODAY`(Space Mono 9.5 ・ 緑の 地 12% ・ 角丸 13)+ 右に ›(丸 40 ・ 白 8%)。見出しの どこを 押しても Friends 画面へ。

## 2. 友だち あり(`L09`)

### ストーリーの 丸(横に すべる)
- 左右 20 ・ すき間 14。1つ = 幅 68:**丸 68**(写真 58 + 黒い すき間 2.5 + 輪 2.5)+ 名前(12 Semibold ・ 白 88%)。
- **いちばん 左 = 自分**:自分の 写真 + 右下に 黄緑の **+**(24 ・ 黒い ふち 3)・ 名前「ふやす」。押すと 自分の QR / ID の シート。
- 友だち(撮った 人が 先):
  - 今日 撮った 人 = **黄緑 → 緑の 輪**(conic-gradient `#C8F25A → #3BD35A → #24A03C`)+ 輪の 下に 最後に 撮った 時刻(`17:05` ・ Space Mono 8.5 ・ 黄緑 ・ 黒い 地)。
  - まだの 人 = 灰色の 輪(白 18%)+ 右下に **つつく**(24 ・ 手の 印)。
  - 押すと 友だちの カード、つつくは 今までの 動き。

### 申請(ある とき だけ)
- 1行(左右 14 ・ 角丸 20 ・ 白 6%):写真の 丸 34 を 3つまで 重ねる + 赤い 点 9 + 「**りこ ほか1人**」(14.5 Bold)/「友だちに なりたい」(12 ・ 白 55%)+ 右に **白い ボタン「確認」**(高さ 36)。押すと Friends 画面の 申請へ。

## 3. だれも いない(`L08` ・ `L12`)

- 見出しの 下に 1行(13 ・ 白 60%):申請 あり =「友だちに なりたい 人が います。」/ なし =「つながると、毎朝 9:00 に きのうを 見せあえます。」
- **横に すべる カード**(幅 148 ・ 角丸 22 ・ 地 `#1b1c1f` ・ すき間 10 ・ 左右 20)。右の カードが 少し 見えて「すべれる」と わかる。
  1. **申請して きた 人**(ある だけ):写真の 丸 78(黄緑の 輪)・ 名前(15 Bold)・ `@id`(11.5 ・ 白 50%)・ `2h ・ 申請`(Space Mono 9 ・ 緑)・ **承認**(黄緑 ・ 高さ 38)・ 右上に ×(32 ・ あとで)。
  2. **リンクを 送る**(黄緑の 丸に 共有の 印)「LINE ・ AirDrop など」→ 白い ボタン「送る」→ 共有シート。
  3. **QR を 見せる**「となりの 友だちに」→「ひらく」→ 自分の QR シート。
  4. **ID で さがす**「@ID を 知って いる」→「さがす」→ ID 入力に カーソル。
- 承認すると、その カードが 少し ふくらんで 上へ 消え(0.42秒)→ 友だちが 1人に なり、カードが「友だち あり」の 形に 変わる。

## 4. 動き ・ バイブ

## 5. SwiftUI

- ストーリーの 列:`ScrollView(.horizontal)` + `LazyHStack(spacing: 14)` + `.scrollTargetBehavior(.viewAligned)` + `.contentMargins(.horizontal, 20)`。
- 輪:`Circle().strokeBorder(AngularGradient(...), lineWidth: 2.5)`。写真は 48〜96px の サムネ(`AsyncImage` ではなく キャッシュ 付きの 読みこみ)。
- 入って くる 動き:`onScrollVisibilityChange`(iOS 18)か `visualEffect` で 1回 だけ。
- カードの 高さは 中身 次第(`fixedSize(horizontal: false, vertical: true)`)。
